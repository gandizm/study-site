# DSP 全课重绘：后续批次

## 公开内容的边界

新入口 `site/dsp-course-redraw.html` 按第一章、第二章、第三章和未编号补充课件分组，默认第二章。它沿用第二章阅读体验，但独立脚本支持真实源文件的页区间，不改写任何旧学习记录。

已提供的课程材料是 14 份 PPT、506 个物理页：第一章 142 页、第二章 185 页、第三章 172 页、傅里叶表示补充 7 页。第三章前两节共享一份 64 页 PPT，分别对应 P1–17、P18–64，不重复计成 128 页。教材第四、五章没有相应 PPT，不能宣称本次已重绘这些章节。

这里的“重绘”是按独有知识内容重排公式、图示、原例及解答，不是逐页复制老师的版式。重复推导与铺垫可合并，课程安排、旧招聘数字、历史硬件照片等放到选读说明；逐页索引保留真实原物理页号。页码映射只是来源索引，不能替代内容与数学审阅。

原 PPT 文件和教材扫描只用于私有核对，不随新增资料公开。原站已有的 2.1/2.2 原图继续作为可选对照；其余小节只显示真实来源页，不伪造原图链接。

## 两遍安排与控量

- 第一遍：每节仅必学板、一题代表例题、易错自检；时间估计包含读图、阅读和该题练习，不叠加旧长文或教材对照。
- 第二遍：按自己的薄弱点展开证明、原课件更多例题和条件边界，不要求重新通读三套材料。
- 第二章第一遍合计约 145 分钟；第一章约 72 分钟。均为学习安排估计，不是实测学习效果或保证。
- 图和长公式可在自身区域滚动；默认不把矢量大图压成小缩略图。全屏提供清晰尺寸、适合窗口和缩放。

## 来源版本与纠错

PPT 采用第二版教材，核对扫描本为第三版。章节号和书页不机械替换；第一章原文件编号与首页节号亦不完全一致，导航保留文件编号并说明差异。

除第二章既有勘误外，后续章节重点核对采样频谱比例、Z 变换 ROC、滤波器反馈符号、并联部分分式、零点与极点、IIR 变换及 FIR 线性相位条件。发现教材与 PPT 同错时，采用原定义、符号恒等式或数值反算核验，而不是以教材出现过就视为正确。

## 进度兼容和验收

旧课程键、原 PPT 完成标记和手动计时脚本不变。新阅读器不调用 `localStorage`，不自动把看过重绘视为旧页完成；用户可继续从原入口导出、导入旧进度。

全课结构检查入口为 `python3 scripts/validate-dsp-course-redraw.py`，第二章专项和旧记录回归仍独立保留。内容检查包括物理页去重、卡片/页面双向关系、图片尺寸与路径、MathML 固定子节点数和首遍分量。它们不能替代原稿语义审阅和真实浏览器视觉检查。

桌面与窄屏检查使用真实 Chrome；窄屏为 iframe CSS 视口模拟，不冒称实体手机触摸或 Safari 已验。最终发布还须确认精确提交的 GitHub Pages CI 成功和线上文件，本文本身不是部署完成声明。
