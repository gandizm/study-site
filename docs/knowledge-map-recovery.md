# Persistent knowledge-map integration

The graph core and optional SVG neighborhood view sit outside paginated source articles. The original viewer, progress state and source images remain authoritative. Page jumps use the real source page numbers, and navigation does not mark learning progress.

Run `python3 scripts/integrate-knowledge-maps.py` after changing reviewed graph data or assets. Run `python3 scripts/validate-knowledge-maps.py` before publication; it checks coverage, prerequisites, asset hashes and load order. Content/source checks and real browser geometry are separate gates.

The reviewed recovery increments include communications Chapters 1 and 4 and computer-network Physical Layer. The first graph release preserved the original article bodies; later separately reviewed increments added the Physical Layer deep-study sections and the new 94-page Chapter 1 reader. Restored bytes and reconstructed code are distinguished by the independent QA evidence. Historical tests must not be substituted for checks of reconstructed files. No browser-layout pass is implied by this repository documentation.
