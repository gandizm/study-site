# 通原第5–7章：先把整条链路看清，再逐个补概念

## 三章只围绕一个问题：怎样把信息可靠地送到另一端

从一段声音出发，发送端先做两件事：把声音变成能表示和存储的数字，再把这些数字变成适合信道传输的电压脉冲或载波波形。接收端反过来做。

- **第5章，模拟信号数字化。** 声音本来每个时刻都有一个幅度。我们隔一段时间测一次，再把测到的幅度归到有限的小格，最后给小格编号。主线是“抽样 → 量化 → 编码”。你要会回答：多久测一次、每次保留多细、需要发送多少位。
- **第6章，数字基带传输。** 0和1还不能直接飞过去，要变成真实的电压脉冲。真实信道会把脉冲拖宽，相邻脉冲可能挤到一起，还会混进噪声。你要会回答：怎样表示0/1、最多能发多快、何时判决、怎样减少串扰和误判。
- **第7章，数字带通传输。** 当信道需要高频载波，就让0/1控制载波的幅度、频率或相位。你要会回答：ASK/FSK/PSK究竟改了什么、接收机凭什么判断、不同方式怎样交换带宽与抗噪声能力。

每章都沿同一条路学习：先知道要解决的问题，再读图的轴与点，认识符号和单位，跟着一个最小例子动手算，最后才读课内公式与完整推导。

**如果从未学过，先从[第五章：读懂一条电压曲线](communications-course-redraw.html#ch5-00)开始。** 第一遍不是一张公式清单。每节新增的“零基础起步”、数值演示与小检查都在页面直接展开；小检查先自己答，再揭开解释。只有高级推导和边界讨论放第二遍。

## 先避开三个最容易串起来的概念

### 第一遍

**1. 抽样不是量化。** 抽样解决“什么时候看一次”，把时间变成一个个时刻；量化解决“每次幅度记多精细”，把幅度归到有限档。抽样后的幅度仍可连续取值，做完量化才只有有限档。

**2. 比特不是电脉冲。** 比特是信息符号0或1，脉冲是承载它的物理波形。逻辑上的数字序列离散，不表示真实电压在所有时刻都只能取两个值。经过信道后波形可以弯曲、拖尾，接收端只要能正确判决符号就能继续恢复信息。

**3. 数字/模拟与基带/带通是两个分类角度。** 数字/模拟看信息怎样表示；基带/带通看信号频谱处于怎样的频率范围。数字信号既可以做基带传输，也可以调到载波上做带通传输。

### 第二遍

可用四种对象区分通信链路里的“数字”：

- 原声音 $m(t)$：时间连续，幅度连续。
- 抽样序列 $m[n]=m(nT_s)$：时间离散，幅度仍连续。$T_s=1/f_s$ 是抽样周期，单位秒，$n$ 是整数样值编号。
- 量化序列 $q[n]$：时间离散，幅度只有有限档。
- 传输波形 $s(t)$：随连续时间变化的真实电压或电磁波，它承载有限种符号。

“数字通信”说的是信息按有限符号处理，并不要求传输中的物理波形不连续。

## 做题前只分清这四个量

### 第一遍

- $f_s$：每秒抽多少个样，单位是样值/秒，通常写Hz。
- $N$：每个样值编码多少位，单位是bit/样值。
- $R_b$：每秒发多少bit，单位bit/s。单路固定长度PCM满足 $R_b=Nf_s$。
- $R_s$：每秒发多少个码元，单位baud。一个码元若承载 $k$ bit，则 $R_b=kR_s$。

例如：每秒取8000个样，每样8位，就得到64000 bit/s。若每个码元只承载1位，则是64000 baud；若每个码元承载2位，则是32000 baud。抽样率没变，改变的是如何把比特装进码元。

这时还不能只看数值就确定带宽。带宽还要看脉冲形状、调制方式和题目问的是理论最小值还是某个频谱零点。

### 第二遍

多路PCM复用若有 $L$ 路，每路抽样率为 $f_s$、每样 $N$ 位，且暂不计同步等附加位，则总比特率为 $R_b=LNf_s$。PAM复用传的是样值幅度，不能没有依据地再乘一个编码位数。

对固定长映射的 $M=2^k$ 进制调制，每个码元可装 $k=\log_2M$ bit；有编码、导频、同步开销时，净信息速率与实际发送比特率还须分别计算。

## 八道作业就是第一轮学习路线

### 第一遍

1. **5.9.1、5.9.3：先学抽样。** 看懂频谱为什么复制、什么叫混叠、恢复滤波器怎样补偿先前的变化。
2. **5.9.9：学量化和编码。** 找幅度范围、把范围等分、算需要几位，再找每格中点。
3. **5.9.13、14、15：把A律编码正着做、倒着做。** 正着先找极性、段、小格；倒着先拆码、查表、还原中点。第14题单独使用折叠段内码。
4. **5.9.20：学增量调制。** 每次只走一格，思考为什么台阶太小和太大都不行。
5. **5.9.25：学复用与速率。** 一帧里给每路一个时隙，算总脉冲速率，并区分两个带宽。它自然接到第6章的无码间串扰条件。

每题先读“原题要做什么”，再跟着“可抄解答”走一遍。抄完至少回答一句“这一步为什么成立”。不必先读完三章再开始作业，也不必为了第一遍把每个扩展都打开。

### 第二遍

如果某一步卡住，就回到对应的小概念：混叠不清楚只回抽样，码字拆不开只回A律表，带宽不同只回码元速率与脉冲形状。不要因此重新通读全部课件。原PPT页码是回查入口，不是要求再学一遍的额外任务。
