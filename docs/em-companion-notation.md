# Static textbook notation in the electromagnetics PPT companion

The original seven lecture slide image sets (330 slides) are unmodified. Only the accompanying, authored formula SVGs and four obsolete “boldface” explanations are changed. The course source is Zhong Shunshi, *Electromagnetic Fields and Waves*, 2nd ed., printed pp. 3–4 (base/units), 57 and 59 (directed area and line elements) and 130 (vector phasor versus scalar component); compare lecture 1, slide 2.

The two shared definitions live in `scripts/em-textbook-notation.cjs`. A single-letter vector rule is optically inset over its italic nucleus; the subscript and prime stay outside it. A unit direction carries only a hat; the directed line/area differential is a multi-letter exception. Scalar components, magnitudes, means, existing phasor dots and conjugates are independent of the vector macros. The two existing problems, 2.5-1 and 3.6-3, are also rebuilt with the same definitions. Their authored solutions, numerical results and original artwork are unchanged.

`scripts/compose-em-companion-notation.cjs` rebuilds static SVG only for the seven named chapter readers and their matching excerpts. Scalar-only SVGs use the original formula sprite. There is no runtime renderer, network call, or change to progress state. For a reviewed rebuild, install `@mathjax/src@4.1.0` and `@mathjax/mathjax-newcm-font@4.1.0` in a temporary prefix and use its node_modules via NODE_PATH. Run `node scripts/compose-em-companion-notation.cjs --render` on the untouched tracked pages, then `node scripts/compose-em-companion-notation.cjs` and `python3 tests/em-companion-notation.test.py`. Commit the checked, compressed parts, not the reconstructed HTML. Pages uses the frozen parts and Node/Python standard libraries; a new unreviewed source expression fails the build rather than silently rendering in the old notation.

Visual comparisons: original/companion at `ppt1.html#p02` (unit axes and components), `ppt1.html#p27` (primed source vector), `ppt2.html#p49` (Poynting vector) and `ppt5.html#p21` (phasor algebra). No chapter 4 slides were supplied.
