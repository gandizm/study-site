第2题 · 表达式双栈

表达式：A-B*C/D+E**F。画NS、OS的变化并给出后缀式。

NS为操作数及运算结果栈，OS为运算符栈。按课件算法在表达式末尾补#：A-B*C/D+E**F#。初始NS为空，OS中只有#。 以下所有横排栈内容均按“栈底→栈顶”书写。

T1=B*C；T2=T1/D；T3=A-T2；T4=E**F；T5=T3+T4。

步 当前符号 操作 NS（底→顶） OS（底→顶）
0 — 初始化：NS 置空，OS 压入栈底标记 # ∅ [ # ]
1 A 操作数 A 入 NS [ A ] [ # ]
2 - - 的优先级高于 #，- 入 OS [ A ] [ #, - ]
3 B 操作数 B 入 NS [ A, B ] [ #, - ]
4 * * 的优先级高于 -，* 入 OS [ A, B ] [ #, -, * ]
5 C 操作数 C 入 NS [ A, B, C ] [ #, -, * ]
6 / / 与栈顶 * 同级，先弹出 *，计算 B*C → T1；/ 暂不入栈 [ A, T1 ] [ #, - ]
7 /（仍为当前符号） / 的优先级高于 -，/ 入 OS [ A, T1 ] [ #, -, / ]
8 D 操作数 D 入 NS [ A, T1, D ] [ #, -, / ]
9 + + 的优先级低于 /，先计算 T1/D → T2；+ 暂不入栈 [ A, T2 ] [ #, - ]
10 +（仍为当前符号） + 与栈顶 - 同级，再计算 A-T2 → T3；+ 仍不入栈 [ T3 ] [ # ]
11 +（仍为当前符号） + 的优先级高于 #，+ 入 OS [ T3 ] [ #, + ]
12 E 操作数 E 入 NS [ T3, E ] [ #, + ]
13 ** ** 的优先级高于 +，** 整体入 OS [ T3, E ] [ #, +, ** ]
14 F 操作数 F 入 NS [ T3, E, F ] [ #, +, ** ]
15 # # 的优先级低于 **，先计算 E**F → T4 [ T3, T4 ] [ #, + ]
16 #（仍为当前符号） # 的优先级低于 +，再计算 T3+T4 → T5 [ T5 ] [ # ]
17 #（仍为当前符号） 输入 # 与栈底 # 相遇，停止；NS 栈顶 T5 为结果 [ T5 ] [ # ]

最终NS=[T5]、OS=[#]，输入#与栈底#相遇，求值结束。

第3题 · 二维数组地址

有一个二维数组A[1:m,1:n]，假设A[3,2]地址为1110，A[2,3]地址为1115，若每个单元占一个空间，问A[1,4]的地址是多少？

设B=LOC(A[1,1])。若按行优先存储，则

1115−1110=(B+n+2)−(B+2n+1)=1−n，

得n=−4，不符合数组列数为正整数的条件，所以本题应按列优先存储。

按列优先且每个元素占1个存储单元，有

LOC(A[i,j])=B+(j−1)m+(i−1)。

由已知条件：

B+m+2=1110，B+2m+1=1115。

两式相减得m−1=5，即m=6，进而B=1102。因此

LOC(A[1,4])=1102+(4−1)×6+(1−1)=1120。

答：A[1,4]的地址为 1120。（所求元素存在需n≥4；n的具体值不影响结果。）
