DTFT综合题与原表回读

先学：对称性怎样减少计算

学完能做什么

  • 完整回读原性质总表并保留条件
  • 独立完成原例2.1.7/11/12而非只列题号
  • 解决PPT实因果余弦和原题并回读求和哑变量

目标｜不把“求整个频谱”当成每道题的第一步

有些题只要零频率的一个值，有些只要能量，还有些给出频谱的一部分让你恢复序列。若每次都先算出完整 DTFT，会做很多不必要的运算。

本节对应课件 2.1 P32–P35：先读懂总表的分组，再完成课件引用的三个教材原例，以及 P35 直接给出的实因果系统题。不是只有例号的摘要，也不拿新题冒充原题。

来源页码先说清楚。当前核对的是方勇《数字信号处理——原理与实践》第3版，2021年版。课件中的旧页码与这一版不一致，应按例号定位：

  • 例2.1.7：课件 P34 标书P38；本版在印刷P43–P44。
  • 例2.1.11：课件 P35 标书P43；本版在印刷P48–P49。
  • 例2.1.12：课件 P35 标书P45；本版在印刷P50–P51。

本节题目条件已对照这些真实书页，解释和计算过程重新编写；整本书或扫描页不是本网页的公开附件。

记号｜有时同一个字母，只是不同位置的临时名字

本节仍用课件的 x(n)、X(ejω)。有三处必须当场区分：

  1. 总表里的 x(n−m)：这里 m 是一个固定的时间平移量，不是正在求和的变量。它相当于上一节的 n0。
  2. 卷积证明里的 ∑mx(m)h(n−m)：这里 m 才是跑遍时间的求和哑变量。相同字母不保证相同角色。
  3. P35 的 HR(ejω)=∑n=05(0.5)ncos(ωn)：这里求和内部的 n 是哑变量。恢复外面的 h(n) 时，为免两个作用域混在一起，我们会先把内部 n 一致换成 r。

上节的 xe 与 Xe、xr 与 XR 也仍按各自定义使用，不因为本节做题就省略这些区别。

回读｜把 P32 的总表分成三组，而不是背一长列

第一组：做线性组合、移动或相乘。

  • ax(n)+bh(n) 对应 aX(ejω)+bH(ejω)。
  • x(n−m) 对应 e−jωmX(ejω)，这里 m 固定。
  • ejω0nx(n) 对应 X(ej(ω−ω0))，固定的是 ω0。
  • 时域卷积 x(n)*h(n) 对应频域普通乘积 X(ejω)H(ejω)。
  • 时域逐点乘积 x(n)h(n) 对应 1/(2π) 乘两频谱的一周期卷积积分。

这一组分别由线性、换元和卷积定理得到。不要把时移因子里的 m 与频移指数里的 n 对调。

第二组：共轭与翻转。

  • x*(n) 对应 X*(e−jω)。
  • x(−n) 对应 X(e−jω)。
  • x*(−n) 对应 X*(ejω)。

检查星号有没有出现、频率有没有反向，两件事分开做。

第三组：拆分序列。

  • Rex(n) 对应频谱的共轭对称部分 Xe(ejω)。
  • jImx(n) 对应频谱的共轭反对称部分 Xo(ejω)。

这里不是把时域实部直接变成频域实部。例2.1.12 正是检验你有没有真正分清这一点。

回读｜P33 的实序列条件不能漏掉

一般复序列分解还有

xe(n)⟷ReX(ejω),xo(n)⟷jImX(ejω).

当原序列 x(n) 是实数值时，进一步有

X*(ejω)=X(e−jω).

所以频谱实部为偶、虚部为奇、幅度为偶；非零频谱的相位在模 2π 意义下正负相反。原表把相位写成严格奇函数时，应补上相位分支和零点的限制，不能给零频谱硬定相位。

表的最后又写实序列的 xe,xo。这时因为样值本来是实数，共轭对称分解就是普通奇偶分解，才可直接按“实偶部分对应实部，实奇部分对应带 j 的虚部”理解。

遇题不必整张表从头念一遍。先判断它给的是时间还是频率、实虚还是共轭对称，再选对应行。

原例2.1.7｜不求完整频谱，也能算五个量

题目条件来自第三版印刷P43–P44、对应课件P34。原图的全部非零样值如下；未列出的整数时刻均为零：

n −3 −1 0 1 3 4 5 7
x(n) −1 1 2 1 1 2 1 −1

设 DTFT 为 X(ejω)，要求以下五个量，且不要先展开整个频谱：

X(ej0),∫−ππX(ejω)dω,X(ejπ),
∫−ππ|X(ejω)|2dω,∫−ππ|dX(ejω)dω|2dω.

第一问：零频率把所有样值直接相加。

在定义中令 ω=0，每个指数都是1，所以

X(ej0)=∑nx(n)=−1+1+2+1+1+2+1−1=6.

这里得到的是样值总和，不是样值平均数，也不是说整条有限长序列在所有时刻都等于某个直流值。

第二问：没有指数的频率积分，抓住原点样值。

IDTFT 在 n=0 时为

x(0)=12π∫−ππX(ejω)dω.

表中 x(0)=2，因此积分是 2π·2=4π。此处不是能量积分，不能误套长度平方。

第三问：π 频率让奇偶时间位置交替变号。

因为 e−jπn=(−1)n，

X(ejπ)=∑n(−1)nx(n).

非零偶数位置 0,4 的样值之和是 2+2=4；非零奇数位置的样值之和是 −1+1+1+1+1−1=2。所以结果为 4−2=2。负奇数位置的 (−1)n 仍为 −1，不能因为 n 为负就改规则。

第四问：频谱长度平方积分，用时域能量。

先算

∑n|x(n)|2=1+1+4+1+1+4+1+1=14.

由帕斯维尔定理，题目里的积分未乘 1/(2π)，所以

∫−ππ|X(ejω)|2dω=2π·14=28π.

第五问：导数的能量，先找它对应的时间序列。

由频域微分性质，

dX(ejω)dω=DTFT[−jnx(n)].

虚数因子 −j 的长度为1，因此其时域能量是 ∑nn2|x(n)|2。逐个非零位置计算：

∑nn2|x(n)|2=9+1+0+1+9+64+25+49=158.

再次应用帕斯维尔：

∫−ππ|dX(ejω)dω|2dω=2π·158=316π.

五个答案依次为 6,4π,2,28π,316π。关键不是五套新公式，而是判断题目分别在问总和、原点、交替和、能量、时间加权后的能量。

原例2.1.11｜给频谱虚部与原点，恢复实因果序列

题目来自第三版印刷P48–P49、对应课件P35。它先要求说明实因果序列如何由奇偶分量表示，再给出

h(0)=1,Hi(ejω)=−sinω,

求 h(n) 和 H(ejω)。原书此处使用下标小写 i 表示虚部，作用相当于前面辅助记号的 HI；它不包含前面的 j。

第一步：把因果性转换成三段恢复规则。

对实因果序列，上一节已经逐段证明

h(n)=he(n)u+(n)=ho(n)u+(n)+h(0)δ(n),

其中 u+(n) 在正时间为2、原点为1、负时间为0。这正是题目第一问；不能把 u+ 换成普通阶跃而不改变系数。

第二步：虚部要连同 j 变换回奇部分。

DTFT[ho(n)]=jHi(ejω)=−jsinω=12e−jω−12ejω.

因此

ho(n)=12δ(n−1)−12δ(n+1).

这表示 n=1 处为 1/2，n=−1 处为 −1/2，原点为零。

第三步：因果性保留正时间并加倍，另补原点。

h(n)=δ(n−1)+δ(n).

于是

H(ejω)=1+e−jω.

最后按条件核对：h(0)=1；负时间为零；H 的虚部是 −sinω。如果漏掉题给的 h(0)=1，只能恢复出 cδ(n)+δ(n−1) 这一族，不能唯一选定常数 c。

原例2.1.12｜知道时间实部，不等于知道频谱实部

题目来自第三版印刷P50–P51、对应课件P35。给出

x(n)=xr(n)+jxi(n),

其中 xr,xi 都是实序列，且 X(z) 在单位圆下半部分的值为零。已知时间实部为

xr(n)={1/2,n=0,−1/4,n=±2,0,其他整数 n.

要求 DTFT X(ejω) 的实部和虚部。我们只使用题目给定的单位圆上的值，不额外假设其他复数 z 位置的值。

第一步：先求时间实部的变换，它叫 Xe，不是直接叫 ReX。

Xe(ejω)=DTFT[xr(n)]=12−14e−j2ω−14ej2ω=12(1−cos2ω).

按共轭对称分解，它也满足

Xe(ejω)=12[X(ejω)+X*(e−jω)].

这一步是题目真正要检验的性质。只有 xr 为实，并不意味着整个未知序列 x 为实。

第二步：把“单位圆下半部分”翻译成角度区间。

z=ejω 沿单位圆转动。在一个 0 到 2π 的周期里，下半圆对应 π<ω<2π，所以这一段的 X(ejω)=0。

当 0<ω<π 时，−ω 与 2π−ω 等价，而后者落在下半圆。因此

X*(e−jω)=0,

此时分解公式只剩

X(ejω)=2Xe(ejω)=1−cos2ω.

第三步：把两半拼起来，而不是把上半圆答案复制到整圈。

沿用本节普通连续 DTFT 的口径，端点由连续性取0，得到与原书相同的结果：

X(ejω)={1−cos2ω,0≤ω≤π,0,π<ω≤2π,

并按 2π 周期延拓。这里 0,π,2π 处两侧极限都为0，没有跳跃端点取值冲突。

答案在整个周期内都是实数，因此

ReX(ejω)=X(ejω),ImX(ejω)=0.

最后的“频谱恰好为实数”是利用额外半圆条件解题后得到的，不能倒回第一步说“时间实部的变换总等于频谱实部”。而且这个频谱通常不关于频率偶对称，所以也不能反推原时间序列必为实序列。

PPT原题｜从一串余弦系数恢复实因果脉冲响应

这道题的完整条件直接出现在课件P35，不依赖教材例号。系统是因果线性时不变系统，单位脉冲响应是实序列，给定频率响应实部

HR(ejω)=∑n=05(0.5)ncos(ωn),

求 h(n)。

先处理记号冲突。原式内的 n 在求和。为了把它与要恢复的输出位置 h(n) 分开，把这一个求和内部统一改名为 r：

HR(ejω)=∑r=05(0.5)rcos(ωr).

这是无损换哑变量，不是把原书的时间索引换成频率索引。

先恢复偶部分。r=0 的项为1；对 r≥1，

cos(ωr)=12e−jωr+12ejωr.

所以

he(n)=δ(n)+12∑r=15(0.5)r[δ(n−r)+δ(n+r)].

每一对正负位置的值都只有原余弦系数的一半。再用实因果条件，负时间去掉、正时间加倍、原点保持不变：

h(n)={(0.5)n,0≤n≤5,0,其他整数 n.

即六个样值为 1,1/2,1/4,1/8,1/16,1/32，从 n=0 开始。

最后直接变换核对。

H(ejω)=∑r=05(0.5)re−jωr,

其实际部正是题给的余弦和。题目只求 h(n)，到这里已经完成；若还要写闭式，可用有限等比和得到

H(ejω)=1−(0.5e−jω)61−0.5e−jω.

由于 |0.5e−jω|=0.5，分母对实数 ω 不会为零。也不要把这个有限6项序列误写成无限右边指数序列。

方法｜题目在问什么，就只取需要的信息

  • 问 X(ej0)：想样值总和。
  • 问不带平方的频谱一周期积分：想 IDTFT 的原点样值。
  • 问频谱长度平方积分：想帕斯维尔与 2π 归一化。
  • 问频谱导数的能量：先找时间加权序列，再用帕斯维尔。
  • 给实因果序列的频谱实部或虚部：先恢复奇偶部分，再处理因果条件和原点。
  • 给时间实部：想频谱共轭对称部分，不要直接写成频谱实部。

这些不是让你跳过推导，而是在已经理解推导后，为每个目标选最短的可靠路线。

自测｜用一点改变检验是否真的懂了

  1. 对例2.1.7的序列，令 y(n)=x(n−1)。Y(ej0) 是否变化？∫−ππY(ejω)dω 是多少？
  2. 例2.1.11若仍给 Hi=−sinω，但把 h(0) 改成0，答案怎样变？
  3. 例2.1.12里，为什么不能在求出 Xe=(1−cos2ω)/2 后立即宣布它就是 ReX？
  4. PPT的六项余弦和中，把内部求和索引 n 换成 r，需要同时修改哪几处？这是把时间变量变成了别的物理量吗？
答案｜把改变代回同一条规则
  1. 总和不随有限序列整体时移改变，所以 Y(ej0)=6。积分取决于新原点 y(0)=x(−1)=1，因此等于 2π，不是原来的 4π。
  2. 奇部分不变，但不再补原点脉冲，因此 h(n)=δ(n−1)，H(ejω)=e−jω。它的虚部仍是 −sinω。
  3. Xe 是时间实部的变换，按定义等于 [X(ejω)+X*(e−jω)]/2；ReX 则等于 [X(ejω)+X*(ejω)]/2。一个涉及负频率、一个不涉及，只有额外条件才能使它们相同。原题利用半圆为零才进一步确定完整 X。
  4. 求和标记、幂次 (0.5)n、余弦中的 ωn 必须一起改成 r。它仍然是同一个时间求和角色，只是换了不会与外部目标时刻冲突的名字。
