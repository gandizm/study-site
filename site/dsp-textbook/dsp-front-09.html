周期序列的DFS：两套系数与八点原例

先学：DTFT性质的综合题

学完能做什么

  • 区分周期延拓和有限主值序列
  • 保留原a_k与X̃(k)=Na_k两套归一化并逐式解释
  • 用正交两支推导DFS，完整计算原例2.2.1
  • 回读三角基与正负复指数及有限方波合成边界

学习目标｜这一节究竟要学会什么

你已经会对一个有限片段求频率成分。这次信号不是“片段以外为零”，而是把这一段永远重复。学完后，你应能：

  • 看见 x~(n)，知道波浪号提示周期序列；指出一周期的长度和样值。
  • 区分原课件先引入的 ak 与后来称作 DFS 的 X~(k)，不会丢掉 N 倍关系。
  • 用有限等比和解释正交，而不是硬背“乘一下就消失”。
  • 完整求出原例中八点周期矩形序列的 DFS，并从系数合成回去。

来源主线为原 2.2 P1–8；原例 2.2.1 已按第 3 版印刷 52–53 页核对。另有一段回读原 2.5 P30 的正弦、余弦与复指数基，只补必要联系，不要求先学 FFT。

定义｜“一个周期”不是“只有这几个点”

原课件把周期序列写为 x~(n)。周期条件是

x~(n+rN)=x~(n),n,r∈Z.

这里 n 是时间样点编号，N 是选用的正整数周期，r 表示向前或向后移了几个周期。它们不是三个频率变量。N 不一定是最小正周期，但选定后，本节全部计算都用这个 N。

例如每八点重复 [1,1,1,1,0,0,0,0]。写出这八个数，是列出一周期；不是声称第八点以后都为零。x~(8)=1，x~(−1)=0。

非零周期序列一般不绝对可和：每个周期都贡献相同的正数，绝对值的总和不断增加。因此不能不加说明地把普通 DTFT 的无穷级数当成收敛函数。我们先用有限项的 DFS 分解它；下一节再借冲激描述它的 DTFT。

记号｜原书在这里确实换了一套系数

先读原课件 P5 的系数形式。取 ω0=2π/N，用任意连续的 N 个不同谐波代表；本节选择 k=0,…,N−1：

x~(n)=∑k=0N−1akej2πNkn.
  • 固定 n：这是要合成的那个时间样点。
  • 求和中的 k：逐个挑出谐波，合成完成后它消失。
  • ak：第 k 个复指数前真正的复系数，包含幅度和相位。
  • 2πk/N：该谐波的数字角频率，单位 rad/sample。

原课件 P7 另外定义

X~(k)=Nak.

然后把下面这一对称为 DFS 与逆 DFS：

X~(k)=∑n=0N−1x~(n)e−j2πNkn,x~(n)=1N∑k=0N−1X~(k)ej2πNkn.

这不是原书先定义错了再改正，也不是两种不同的信号。它是在换归一化约定：ak 把 1/N 放在求系数的一侧；X~(k) 把 1/N 放在合成的一侧。必须连同整对公式读。

你以前熟悉的 x[n] 与这里的 x(n) 都可表示离散序列，括号形状不改变时间是离散的。熟悉的 X[k] 数值在取相同一周期、相同归一化时等于本书 X~(k) 的一周期，但本节波浪号还提醒：这里的时域、频域序列都按周期延拓。

推导｜为什么只要 N 个复指数

先比较编号相差 N 的两个基函数：

ej2πN(k+N)n=ej2πNknej2πn=ej2πNkn.

最后一步依赖 n 是整数。于是 k 和 k+N 没有提供新的离散时间波形。k 可以取任意整数，但独立的代表只有 N 种。比如 N=8，k=−1 和 k=7 在所有整数样点上完全相同。

这也解释一个原资料边界：原 PPT P5–6 把离散合成和写成了 k=−∞ 到 ∞。若同时采用它后面给出的周期系数 ak+N=ak，就会无限重复同一组分量，不能按普通求和使用。第 3 版印刷 51 页的合成式上限写到 N，也多计了与 k=0 相同的一项。这里明确采用 0≤k≤N−1；不是偷偷改变符号，而是避免重复计数。连续时间傅里叶级数的无限谐波和则没有这个离散样点上的重复问题。

推导｜用两支等比和把某一个系数挑出来

我们要找第 m 个系数，先把 m 固定为 0,…,N−1 中的一个数。它此时不是时间，也不是新的求和变量。将合成式乘 e−j2πmn/N，再把时间 n 从 0 加到 N−1：

∑n=0N−1x~(n)e−j2πNmn=∑k=0N−1ak∑n=0N−1ej2πN(k−m)n.

只需研究内层。令 q=ej2π(k−m)/N。

  1. 若 k≡m(modN)，则 q=1，内层是 N 个 1，总和为 N。
  2. 否则 q≠1，但 qN=ej2π(k−m)=1，因此 1+q+⋯+qN−1=(1−qN)/(1−q)=0。

在目前 k,m 都取 0,…,N−1 的范围里，同余才简化成相等。若放开到所有整数，原页“k=m 才为 N”应读作“k−m 是 N 的倍数才为 N”。例如 N=8,k=9,m=1 时也是 8，不是 0。

只剩 k=m 那项，所以

am=1N∑n=0N−1x~(n)e−j2πNmn.

现在把“待求谐波的名字”从 m 改回原书用的 k，就得到原式 ak。这里只重命名了自由的频率编号，没有把时间 n 变成频率，也没有宣称 m,n,k 永远等价。

例题｜原例 2.2.1：八点周期矩形序列

题目给定一个周期中 n=0,1,2,3 为 1，n=4,5,6,7 为 0，以 N=8 永久重复，求原书约定的 X~(k)。原 PPT P8 用 R4(n) 表示那段四点矩形，再按八点延拓。R4 的 4 是非零矩形长度，不是周期 8。

第一步，按定义把零项拿掉：

X~(k)=∑n=07x~(n)e−j2π8kn=∑n=03e−jπ4kn.

此刻 k 是你选择的输出频率编号，n 是走过四个非零时间样点的求和哑变量。

第二步，令 q=e−jπk/4。若 k 不是 8 的倍数，q≠1，故

X~(k)=1−e−jπk1−e−jπk/4=e−j3πk/8sin(πk/2)sin(πk/8).

后一种写法来自 1−e−jθ=2je−jθ/2sin(θ/2)：分子取 θ=πk，分母取 θ=πk/4，指数相除得到 e−j3πk/8。这解释了原书突然出现的相位因子。

第三步，别在 k=0 直接算 0/0。回到四项原和式，每项都是 1，所以 X~(0)=4；所有 k=8r 都同样为 4。

第四步，真正算一周期，不只停在公式：

k X~(k) 从哪里来
0 4 四个 1 相加
1 1−j(1+2) 四个相量相加
2 0 1−j−1+j
3 1−j(2−1) 四个相量相加
4 0 1−1+1−1
5 1+j(2−1) 与 k=3 共轭
6 0 与 k=2 共轭
7 1+j(1+2) 与 k=1 共轭

以 k=1 为例，四项是 1,(1−j)/2,−j,(−1−j)/2。实部相加为 1，虚部为 −(1+2)。其他项也可直接用同一种方法，不需要猜图高。

原图画的是模长。k=1,7 的模为 4+22≈2.6131；k=3,5 为 4−22≈1.0824。这些不是 ak 的模，后者还要除以 8。

检查｜用平均值和合成式检查是否少了八倍

平均值是四个 1 除以八点，故 a0=1/2，而 X~(0)=4。如果你把 4 当作直流的实际幅度，就忘了合成式外的 1/8。

在 n=0 合成时，每个复指数均为 1。八个 X~(k) 的和为 8，除以 8，得到 x~(0)=1。在 n=4，指数为 (−1)k；直流项贡献 4，四个奇数编号项的和为 4 但符号为负，其余为零，故合成得到 0。

这两个点不是整个逆变换的替代证明，却是很有效的归一化与相位检查。

回读｜原书说“一周期做 Z 变换再采样”到底在做什么

先取一周期成为有限主值序列：x(n)=x~(n) 对 0≤n<N，其他时间为 0。注意这里去掉了波浪号，表示此刻没有继续重复。

X(z)=∑n=0N−1x(n)z−n.

代入单位圆上 N 个位置 zk=ej2πk/N，就得到

X(zk)=∑n=0N−1x(n)e−j2πkn/N=X~(k).

所以原书这句话依次做了三件事：取一周期；求这段有限序列的 Z 变换；在单位圆均匀取 N 个值，再把所得频率序列按 N 周期重复。这里并没有声称“非零周期序列的双边 Z 变换有一个正常收敛环域”。下一节的冲激线谱又是另一个对象，不能把这些均匀样值直接当成它的冲激权重。

回读｜原 2.5 P30 的三角基与复指数基其实是一对一搭配

这一段是为回读后面的正交基图补的桥，不改变本节 DFS 定义。原页连续时间表达式里的 n 是谐波编号，t 才是时间。为了不和上面离散时间的 n 混淆，先在解释中临时把这个谐波编号改叫 r：

cos(rω0t)=ejrω0t+e−jrω0t2,sin(rω0t)=ejrω0t−e−jrω0t2j.

因此一对正、负复指数与同频率的一对余弦、正弦可以相互改写；不是多出了两种新频率。连续时间这里的 ω0 单位是 rad/s，不是本节离散时间 2π/N 的 rad/sample。

零频率只保留一个常数：cos0=1，sin0=0，不能把零函数当成一个独立基。对实信号，正负频率系数共轭，配对后得到实数的正弦、余弦展开；对复信号也可代数改写，但系数未必是实数。

原图右下用有限个谐波逐步拼接方波，展示的是逐步近似，不是“几项就能在每一个点精确等于方波”。在常见分段光滑周期函数的傅里叶级数中，跳变点的收敛值是左右极限的平均值；有限谐波在跳变附近还会有波纹。这里的教学目标是认出两套基的联系，不把示意图当成逐点精确的有限恒等式。回到原页时，再把解释中的 r 换回该页的谐波编号 n，就不会把它误认成离散时间样点。

自测｜四个能检查你是否真的读懂的短题

  1. 当 N=8 时，ej2π9n/8 与第几个 0 到 7 的基函数相同？原因是什么？
  2. 某周期序列的平均值为 3，选择周期 N=6。原课件的 a0 和 X~(0) 各是多少？
  3. 在求 X~(3)=∑n=07x~(n)e−j2π3n/8 时，3 是时间样点吗？把求和的 n 改成 r 会改变答案吗？
  4. 原例在 k=8 的正弦比式出现 0/0。能否说频谱不存在？应怎样求值？
答案｜先自己解释，再核对
  1. 与 k=1 相同。两者相差因子 ej2πn=1，这一步要求 n 为整数。
  2. a0=3，X~(0)=6×3=18。记住原书的 X~=Na。
  3. 3 是被固定的频率编号；n 是求和用的时间编号。若把 n 的全部出现一致地改为 r，求和范围不变，答案不变。但不能只改指数或只改 x~ 里的一个位置。
  4. 不能。是变形后的分式在该点不适用，原始有限和始终有定义；四个 1 相加得 4。
