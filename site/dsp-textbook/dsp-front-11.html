模拟与数字频率：100Hz采样原例慢解

先学：周期序列为何得到冲激线谱

学完能做什么

  • 区分模拟波形/冲激采样/数值序列三对象
  • 逐式换元推导频谱复制与1/T
  • 辨认Hz、rad/s、rad/sample与归一化撇号
  • 完整完成原例2.2.7三问并解释冲激尺度/混叠边界

学习目标｜先分清三个对象，再换频率单位

原 2.2 P14–24 同时出现 xa(t)、x^a(t) 和 x(n)，又同时出现 f、Ω、ω。困难不在公式长，而在它们并非同一个对象的随意改名。

本节先把三个对象分开，再推导频谱之间的关系，最后完整做原例 2.2.7 的三问。题目与图已按第 3 版印刷 58–60 页核对。目标是能回课堂读懂原式，包括 1/T、2π、冲激尺度和归一化撇号，而不是只背“采样使频谱周期延拓”。

定义｜三种时间对象，不能把帽子和下标省着看

令采样间隔为 T>0 秒，采样率为 fs=1/T Hz，采样角频率为 Ωs=2πfs=2π/T rad/s。

原书符号 自变量是什么 具体表示
xa(t) 连续时间 t，单位秒 尚未采样的模拟波形
x^a(t) 仍是连续时间 t 理想采样后、位于 nT 的加权冲激串
x(n) 整数样点编号 n 从波形取出的数值，满足 x(n)=xa(nT)

理想冲激采样模型写成

x^a(t)=∑n=−∞∞xa(nT)δ(t−nT)=∑n=−∞∞x(n)δ(t−nT).

原页有时将权重写成 xa(t)δ(t−nT)，筛选性质会把它变为 xa(nT)δ(t−nT)。这里的 n 是冲激位置的求和编号，t 仍然是连续自变量，不能用“把 t 改名为 n”解释整个式子。

数组 x(n) 只列数值，不是在两个采样点之间补一条台阶；冲激串也不是实际采样保持电路的输出。真实 ADC 还涉及保持、量化等效应，本节暂未建模。这样做是明确理想模型，而不是把硬件细节说成不存在。

记号｜大 Ω 和小 ω 的单位不同

模拟正弦 ejΩt 的 Ω 单位为 rad/s，采样后变成 ejΩnT。因此对应的数字角频率为

ω=ΩT=2πffs,Ω=2πf.

ω 的单位是 rad/sample。它说的是“每前进一个样点，相位增加多少”，不是“每秒增加多少”。两式都叫角频率，但乘了采样间隔后物理含义已经改变。

原 P19 中归一化频率带撇号，定义为

f′=ffs,Ω′=ΩΩs,ω′=ω2π.

三者数值相同，都是无量纲的周期/样点表示。这里撇号不是求导；原 P17 积分换元里出现的 Ω′ 却是临时积分变量。它们只是同一个记号在不同局部被重新使用，本节换元会用 θ 避开混淆，再告诉你怎样回读原页。

模拟频率 f 模拟角频率 Ω 数字角频率 ω 归一化数值
0 0 0 0
fs/2 Ωs/2 π 1/2
−fs/2 −Ωs/2 −π −1/2
fs Ωs 2π 1

“数字频率 π”若没有给 fs，就不能唯一翻译成多少 Hz。反过来，同一个 100 Hz 信号用不同采样率采样，会有不同的 ω。

回读｜原 P5 的连续周期级数为何是无限项

原页还写了连续周期条件 x~a(t+kT0)=x~a(t)。在这一句里 k 表示平移了几个周期，T0 是连续时间周期，单位秒。定义基角频率 Ω0=2π/T0 后，同一页又用 k 表示谐波编号：

x~a(t)=∑k=−∞∞A(k)ejkΩ0t.

请注意角色变化：这一式求和中的 k 已是频率编号，t 才是时间；A(k) 是对应复指数的系数，不是前面 DFS 的 X~(k)。为帮助理解，补充其常用求系数形式：A(k)=1T0∫t0t0+T0x~a(t)e−jkΩ0tdt，其中 t0 是任意所选一周期的起点。

连续时间 t 可取任意实数，所以编号相差一个任意整数 N 的两个连续谐波并不恒等；它们相差的因子 ejNΩ0t 不会对所有 t 都等于 1。因此连续级数一般要无限谐波，而离散周期序列只需 N 个不同基。不是把连续式的 t 换成 n 就能保留完全相同的求和范围。

这里的无限级数也有收敛含义：对常见分段光滑周期波形，在连续点收敛到原值，在跳变处收敛到左右极限平均值；有限能量一周期的情形还可用均方意义理解。不是任何周期函数都能不加条件地逐点相等，更不是有限几项就精确拼成带跳变的波形。它与上一节有限 N 项 DFS 的精确合成要分开。

定义｜三套傅里叶表示各自积分或求和

原书以角频率定义连续时间傅里叶变换：

Xa(jΩ)=∫−∞∞xa(t)e−jΩtdt,xa(t)=12π∫−∞∞Xa(jΩ)ejΩtdΩ.

序列的 DTFT 则是

X(ejω)=∑n=−∞∞x(n)e−jωn,x(n)=12π∫−ππX(ejω)ejωndω.

前面是对连续时间积分，后面是对整数时间求和。连续变换逆式沿整个 Ω 轴积分；DTFT 逆式只用一个 2π 周期。这正是原 P16 不能直接把两个被积函数相等的原因。

下面先在普通傅里叶逆变换、求和与积分交换均成立的条件下推导，例如足够平滑且快速衰减的信号。无穷正弦不满足这一普通函数条件，原余弦题另按上一节的广义冲激变换对计算；不要用那道题掩盖这里的交换条件。

推导｜采样冲激串与序列的频谱只差频率坐标

对 x^a(t) 作连续时间变换，用每个冲激筛出 t=nT：

X^a(jΩ)=∑n=−∞∞x(n)e−jΩnT=X(ejΩT).

也就是说，在 ω=ΩT 的对应频率处，两种表达匹配。注意这不是说 x^a(t) 等于 x(n)：前者是冲激串，后者是一串数；而且将冲激频谱改成另一坐标时，冲激权重需要按尺度变换，稍后原例会专门计算。

原 P10 的连续复指数也可在这里回读：ejΩ0t 的连续变换为一条 2πδ(Ω−Ω0)。它的频率轴不会由于时间离散而自动周期重复；采样后的序列 ejΩ0Tn 的 DTFT 才出现每隔 2π 的冲激梳。

推导｜为何原模拟频谱要复制，并乘 1/T

从 x(n)=xa(nT) 和连续逆变换出发。把整个 Ω 轴切成宽 2π/T 的区间，以整数 r 编号：

xa(nT)=12π∑r=−∞∞∫(2r−1)π/T(2r+1)π/TXa(jΩ)ejΩnTdΩ.

在第 r 个积分内，令 Ω=θ+2πr/T，便把所有积分区间都移到 [−π/T,π/T]。原页把这里的 θ 叫 Ω′；这是换元变量，不是刚才频率轴上的归一化值。

指数中的额外因子是 ej2πrn=1，因为 r,n 都是整数。因此

x(n)=12π∫−π/Tπ/T[∑r=−∞∞Xa(j(θ+2πrT))]ejθnTdθ.

再令 ω=θT。这里不仅把指数换成 ejωn，还必须把微分换成 dθ=dω/T：

x(n)=12π∫−ππ[1T∑r=−∞∞Xa(jω+2πrT)]ejωndω.

与逆 DTFT 比较，再把遍历全部整数的 r 换成 −r，得到原书常用的减号形式：

X(ejω)=1T∑r=−∞∞Xa(jω−2πrT).

所以加号改减号不是物理过程倒转，是求和哑变量反向编号。将 ω=ΩT 代回，就得到原 P14 的冲激采样频谱：

X^a(jΩ)=1T∑r=−∞∞Xa(j(Ω−rΩs)).

原式有时写 Xa(jΩ−jrΩs)，与这里的括号形式等价。此处 r 或原页的 k 是频谱副本编号，不是 DFT 输出格号，也不是时间索引。

回读最后一句务必加上坐标：在模拟角频率 Ω 轴上副本间隔是 Ωs=2π/T；在数字角频率 ω 轴上周期是 2π。原页一句“以 2π/T 为周期延拓”不能直接套到横轴标作 ω 的图上。

边界｜出现复制，不等于必定可以无失真恢复

频谱复制关系不要求事先无混叠。若原谱限制在 |f|≤B，取 fs>2B 可让各副本分开；这是一项易记、避免边缘争议的充分条件。理想带限与理想重构是模型条件，工程上还需要抗混叠滤波和过渡带。

不能把等号 fs=2B 对任意端点正弦都当成无条件保证。例如 sin(πn)=0：位于半采样率的某个相位分量会采成全零。若要用临界等号，必须额外说明端点谱和信号类别。

此外，相差整数倍 fs 的复指数会给出同样样点。混叠发生后，单凭这些样点不能辨别原来来自哪个副本；后面增大 DFT 点数也不能创造已丢失的区别。

例题｜原例 2.2.7：先完整写出条件和三问

已知

xa(t)=2cos(2πf0t),f0=100 Hz,fs=400 Hz.

用此采样率得到理想冲激采样信号 x^a(t) 和序列 x(n)。求：原模拟频谱 Xa(jΩ)；两个采样后时域表达式；两个采样后频谱 X^a(jΩ) 与 X(ejω)。

先列出不容混淆的参数：

T=1400 s=2.5 ms,Ω0=2πf0=200π rad/s,Ωs=800π rad/s,ω0=Ω0T=π2 rad/sample.

原信号周期为 1/100=0.01 秒，每周期包含四个采样间隔。这个例中离散序列恰有整数周期 4，并不是每个模拟周期信号经任意采样都必有整数样点周期。

例题｜第一问：连续频谱只含两条线

先用欧拉公式写为 xa(t)=ejΩ0t+e−jΩ0t。每项的连续变换是一条权重为 2π 的冲激，故

Xa(jΩ)=2π[δ(Ω−200π)+δ(Ω+200π)].

两条线在 ±200π rad/s，也就是 ±100 Hz；不要把 200π 当成 Hz。它们没有继续沿 Ω 轴周期复制，因为目前还没有采样。

例题｜第二问：帽子下仍是连续时间，无帽子才是样值序列

把 t=nT 代入，先得到样值：

x(n)=2cos(π2n),n∈Z.
n t=nT（ms） x(n)
0 0 2
1 2.5 0
2 5 −2
3 7.5 0
4 10 2

冲激串则必须把采样时刻保留下来：

x^a(t)=∑n=−∞∞2cos(π2n)δ(t−n400).

它不是 2cos(πt/2)，也不是把 [2,0,−2,0] 四个数连接成的曲线。原 PPT P15 的“冲激采样 → 取样值序列”正是在区分这两个对象。

例题｜第三问之一：采样冲激串的连续频谱

把第一问的两条线按 Ωs=800π 复制，每条权重乘 1/T=400：

X^a(jΩ)=800π∑r=−∞∞[δ(Ω−200π−800πr)+δ(Ω+200π−800πr)].

例如 r=0 给 ±200π，r=1 给 600π 与 1000π。每条线标注的 800π≈2513.27 是冲激权重。它相对原模拟频谱的 2π 发生了尺度变化，并不表示硬件把信号电压放大了 400 倍；我们讨论的是理想冲激模型及其连续时间单位。

因为 100<400/2=200 Hz，这两条信号线在本例不与相邻副本重合。这个判断只适用于已经给定的原余弦及理想模型。

例题｜第三问之二：样值序列的 DTFT

由 x(n)=ejπn/2+e−jπn/2，使用上一节变换对：

X(ejω)=2π∑r=−∞∞[δ(ω−π2−2πr)+δ(ω+π2−2πr)].

在 [−π,π) 内，只有 ±π/2 两条非零谱线，权重各为 2π；这与上一节四点余弦算例完全相同。

还要读懂原 P23 的另一条解法，否则你会疑惑“刚才不是乘 400 吗，怎么又没了？”将原模拟谱代入频谱关系，会遇到

2πTδ(ω−ω0−2πrT).

对 T>0，冲激尺度规律为 δ(u/T)=Tδ(u)。因此外面的 1/T 与冲激内部带来的 T 抵消，结果正是 2πδ(ω−ω0−2πr)。这个变化与横轴从 rad/s 改成 rad/sample 一起发生，不能只挪横轴而保留原来的箭头权重。

也可以从 X^a(jΩ)=X(ejΩT) 反查：将 DTFT 中的 δ(ω−ω0) 换成 δ(ΩT−ω0)=δ(Ω−Ω0)/T，就恢复权重 2π/T。

回读｜原 P24 的四幅图要怎么对照

  • 模拟时域：连续余弦，周期 10 ms、幅度 2。
  • 模拟频谱：Ω=±200π 的两条线，权重 2π，无周期复制。
  • 冲激采样频谱：Ω=±200π+800πr，权重 800π。
  • 数字序列频谱：ω=±π/2+2πr，权重 2π。

所以“都是两根线复制”只是形状直觉。读图时还必须检查横轴单位、复制间隔和箭头标注，三者同时一致才算对应。原图中的箭头不是普通函数的有限高度，个别连续时域图的横轴若未清楚标单位，应优先用已知 f0,T 校准，而不是按图片宽度猜周期。

自测｜不用重新推导，也要能检查单位与条件

  1. 若保持 100 Hz，却把采样率改成 500 Hz，T、ω0、归一化频率 f′ 各为多少？
  2. fs=400 Hz 时，模拟频率 500 Hz 与 100 Hz 的复指数给出的离散序列是否相同？说明原因。
  3. 原书积分换元中的 Ω′ 与原 P19 频率图中的 Ω′ 必然是同一变量吗？
  4. 本例 DTFT 冲激权重 2π 换到 Ω 轴，为什么变为 800π 而不是不变？
  5. 只给 x(n)=[2,0,−2,0] 的周期延拓，且不知道采样率，能确定原模拟频率一定是 100 Hz 吗？
答案｜先核对象，再核数字
  1. T=2 ms，ω0=2π(100/500)=0.4π rad/sample，f′=0.2。
  2. 相同。两频率相差一个 fs，样点指数之比为 ej2πn=1。在未限制原信号频带时，仅凭样点无法区分。
  3. 不是。前者是局部替换用的模拟角频率积分变量；后者明确定义为 Ω/Ωs 的无量纲归一化量。看到同一字母与撇号要就地读定义，不能跨页默认沿用。
  4. 因 ω=ΩT，且 δ(ΩT−ω0)=δ(Ω−ω0/T)/T。取 1/T=400 后权重为 800π。
  5. 不能。首先还缺采样率来换算 Hz；即使给定采样率，也需原频带等条件排除相差采样率整数倍的混叠来源。
