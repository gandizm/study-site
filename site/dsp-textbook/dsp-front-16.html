DFT的对称性与两条实序列的分离

先学：DFT性质逐条推导与验算

学完能做什么

  • 区分时间/频率两套实虚与共轭对称分解
  • 说明共轭对称和反对称的实虚、模、相位及自配对边界
  • 完整求解原例2.3.13并以四点数值核验分离

目标｜学会拆开复数谱，而不是只记“实偶虚奇”

这一节对应原2.3 P40–P53。最容易混淆的不是计算，而是把两种操作混在一起：

  • 在每个原位置，拆成实部与虚部。
  • 将一个位置与它的圆周反向位置配对，拆成共轭对称与共轭反对称部分。

它们在DFT两侧互相对应，却不是同一个分解。我们先把反向位置找对，再用同一组四点复数算例验证两套对应，最后完整解原教材例2.3.13：怎样从一次复数DFT里分离两条实序列的变换。

记号｜ep、op、r、i 各指什么

沿用原书的符号：

  • x(n) 与 X(k) 是一对 N 点DFT，正变换无 1/N，逆变换带 1/N。
  • xr(n)=Rex(n)、xi(n)=Imx(n) 都是实值数组，且 x=xr+jxi。虚部是 xi，原序列中的纯虚贡献是 jxi。
  • xep(n)、xop(n) 是时间数组的圆周共轭对称、圆周共轭反对称分量。
  • Xep(k)、Xop(k) 是频谱数组做同样分解得到的分量，并不默认是 X 的实部与虚部。
  • XR=ReX、XI=ImX，所以 X=XR+jXI。

n 始终标时间位置，k 标频点位置。在推导求和中，哪个符号被求和号绑定，哪个才是当时可换名的哑变量。小写与大写的对应尤其重要：xep 是时间分量，Xep 是频率分量，不要只看到相同下标就猜它们互为DFT。

定义｜圆周反向位置是负下标取模，不是把数组整条倒排

对于主值数组，n 的配对位置是

(−n)modN.

原书常把它写成 N−n，但 n=0 时应按周期读取 x(N)=x(0)。辅助取模写法只是把这个边界交代清楚，不是更换原书的变换。

例如 N=6，位置 0,1,2,3,4,5 的反向位置分别是 0,5,4,3,2,1。原P41的六点递增数组 [1,2,3,4,5,6]，圆周反转后是 [1,6,5,4,3,2]，不是 [6,5,4,3,2,1]。

为什么课件从普通反转讲起，又画周期延拓？普通序列的共轭反转读 x*(−n)；对周期延拓 x~，负位置可绕到代表周期的 N−n，最后乘 RN(n) 只保留一段主值。于是 P40–P43 的路线是：普通定义、周期序列上的配对、取一段得到圆周定义。

定义与推导｜一半加、一半减，得到唯一的两部分

在 0≤n<N 内定义

xep(n)=12[x(n)+x*((−n))N],xop(n)=12[x(n)−x*((−n))N].

相加立即恢复 x(n)。原P43写作 [x(n)±x*(N−n)]/2，就是同一个式子；若要写成全整数序列，则在主值式外明确窗口 RN(n)。

检查第一个分量：把 n 换成 −n 再取共轭，得到

xep*((−n))N=12[x*((−n))N+x(n)]=xep(n).

第二个分量同理满足

xop*((−n))N=−xop(n).

所以“共轭对称”是先反向再共轭后不变，“共轭反对称”是这两个操作后变号。不是说两个分量各自一定为实数或纯虚数。唯一性也容易检查：若 x=u+v 且 u 共轭对称、v 共轭反对称，将共轭反转后的等式与原式相加或相减，就只能得到上面的两个半和、半差。

对原P41的实数组 [1,2,3,4,5,6]，共轭不会改变数值，因而

xep=[1,4,4,4,4,4],xop=[0,−2,−1,0,1,2].

逐位置相加可恢复原数组。位置0与3各自和自己配对，所以这组实数组的圆周奇部分在这两个位置为0。

条件｜自配对位置不只在零点

满足 n≡−n(modN) 的位置与自己配对。

  • 任意 N 都有 n=0。
  • N 为偶数时还有 n=N/2。
  • N 为奇数时，主值区间里没有第二个自配对位置。

在这些位置，共轭对称条件是 z=z*，所以值为实数；共轭反对称条件是 z=−z*，所以值为纯虚数，不必为零。只有再限定数组是实值时，纯虚且实数才迫使它等于零。

例如 [j,0,0,0] 是4点圆周共轭反对称数组，位置0为 j，不是0。不要把实值奇序列的结论直接搬到一般复数共轭反对称序列。

结论与解释｜原P44的实部、虚部、模和相位

若 u(n)=u*((−n))N，设配对位置的值为 a+jb，另一边便为 a−jb。因此：

  1. 实部圆周偶对称：Reu(n)=Reu((−n))N。
  2. 虚部圆周奇对称：Imu(n)=−Imu((−n))N。
  3. 模圆周偶对称：|u(n)|=|u((−n))N|。
  4. 对非零配对点，相位满足 argu(n)≡−argu((−n))N(mod2π)。

最后一句要连同条件记：零值没有确定相位；采用主值角显示时可能在 π 与 −π 处跳变，不能把模 2π 的关系误当作任何软件显示出的两个角度都严格相反。

结论与解释｜原P45的反对称不是“什么规律都没有”

若 v(n)=−v*((−n))N，对应的配对数值是 a+jb 与 −a+jb。所以：

  1. 实部圆周奇对称。
  2. 虚部圆周偶对称。
  3. 模仍然圆周偶对称。
  4. 对非零配对点，相位满足
argv(n)≡π−argv((−n))N(mod2π).

原P45写“幅角没有对称性”。回读时不要把它理解成相位之间完全没有关系；这里不能直接套用上一页的普通奇对称形式，但仍有上式的互补关系。比如一对 1+j 与 −1+j，相位分别为 π/4、3π/4，相加为 π，而不是互为相反数。零点相位仍不定义。

定义｜频谱也能这样分，但配对的是 k，不是 n

P46在频率数组上定义

Xep(k)=12[X(k)+X*((−k))N],Xop(k)=12[X(k)−X*((−k))N].

它们相加为 X(k)，并满足各自的圆周共轭对称、反对称条件。这里配对的是频点 k 与 (−k)modN，不是在原时间数组里找第 k 个样值。

这些定义没有使用 X 必须是某条实序列的DFT这一前提。任意复数频谱数组都能拆成这两部分；实序列只是其中一个特别有用的情形。

推导A｜时间拆实部与虚部，频率得到共轭对称与反对称分量

由普通复数代数，

xr(n)=12[x(n)+x*(n)],jxi(n)=12[x(n)−x*(n)].

上一节已证明 DFT{x*(n)}=X*((−k))N。用线性性可得

DFT{xr(n)}=12[X(k)+X*((−k))N]=Xep(k),
DFT{jxi(n)}=12[X(k)−X*((−k))N]=Xop(k).

这对应 P48–P49。注意第二行输入是 jxi，不是 xi；若单独求实值虚部数组 xi 的DFT，结果应为 Xop/j=−jXop。

也不要把第一行误记成“时间实部的变换等于频谱实部”。正确结果是 Xep，它可以是复数。

推导B｜时间拆圆周共轭对称，频率才得到逐点实部与纯虚贡献

上一节的另一个性质是

DFT{x*((−n))N}=X*(k).

把它用于时间半和、半差：

DFT{xep(n)}=12[X(k)+X*(k)]=ReX(k)=XR(k),
DFT{xop(n)}=12[X(k)−X*(k)]=jImX(k)=jXI(k).

这对应 P50–P51。与推导A相比，关键差别就在是否对时间数组做了圆周反转。没有这个反转时，频域的共轭会带反向位置；有这个反转时，频域变成同一位置的共轭。

算例｜用同一组四点复数，把两套映射全部算出来

这是新增的小算例，不伪称原PPT的题目。取

x=[1,j,0,0],X=[1+j,2,1−j,0].

先按每个位置拆实部和纯虚贡献：

xr=[1,0,0,0],jxi=[0,j,0,0].

它们的DFT分别为

Xep=[1,1,1,1],Xop=[j,1,−j,−1].

例如第二条只在 n=1 有值 j，故第 k 点为 jW4k，依次是 j,1,−j,−1。这条频谱既不全实，也不全虚，但它确实满足圆周共轭反对称。两条频谱相加就是原来的 X。

现在做另一套分解。原数组的圆周共轭反转为 [1,0,0,−j]，因此

xep=[1,j/2,0,−j/2],xop=[0,j/2,0,j/2].

分别变换：

DFT{xep}=[1,2,1,0]=ReX,
DFT{xop}=[j,0,−j,0]=jImX.

可以逐点核验第一条：它的频谱为 1+(j/2)W4k−(j/2)W43k。k=0,1,2,3 依次得到 1,2,1,0。第二条为 (j/2)(W4k+W43k)，依次得到 j,0,−j,0。

看到区别了吗？Xep=[1,1,1,1]，但 ReX=[1,2,1,0]。它们在这个简单例子里已经不同，不能靠“都带偶或实的味道”混在一起。

回读｜P52实序列的频谱为什么成对共轭

若 x(n) 为实数，则 x*=x。由共轭定理，

X(k)=X*((−k))N.

因此整个频谱就是自己的共轭对称分量，即 X=Xep、Xop=0。这对应原P52前两行。后两行仍保留另外一套分解：实数组的圆周偶部分对应 ReX，圆周奇部分对应 jImX。

例如 x=[1,2,0,0]，

X=[3,1−2j,−1,1+2j].

频点1与3互为共轭；频点0与2自配对，值都是实数。实序列的频谱不必全实，实频谱还要求时间数组同时圆周偶对称。

对实序列，频谱实部圆周偶、虚部圆周奇、模圆周偶，相位在非零点按模 2π 为圆周奇关系。N 偶数时 X(N/2) 必为实数，但不必为零；本例就是 −1。

回读｜P53纯虚序列不是同一个表照抄

若 x(n)=jr(n) 且 r(n) 为实数，则 x*=−x，因此

X(k)=−X*((−k))N.

此时整个频谱是共轭反对称分量，即 Xep=0、X=Xop。频谱的实部圆周奇、虚部圆周偶；模仍圆周偶，相位使用前面的 π−ϕ 模 2π 关系，而不是普通的 −ϕ。

将上一例的时间数组乘 j：x=[j,2j,0,0]。线性性给出

X=[3j,2+j,−j,−2+j].

频点1与3满足 2+j=−(−2+j)*；自配对频点0与2为纯虚数 3j,−j。它们同样不必为零。原P53后两行仍然是 xep↔ReX、xop↔jImX，不会因为输入变成纯虚而交换位置。

方法｜一次复数DFT怎样分离两条实序列

这是原例2.3.13要用的结构。设 x(n),y(n) 都是实序列，组成

f(n)=x(n)+jy(n),F(k)=X(k)+jY(k).

请停一下：X(k),Y(k) 是两条实序列的DFT，各自仍可以是复数。因此一般不能写 X=ReF、Y=ImF。

因为 x,y 实值，X*((−k))N=X(k)、Y*((−k))N=Y(k)，所以

F*((−k))N=X(k)−jY(k).

与 F=X+jY 联立，分别相加、相减：

X(k)=F(k)+F*((−k))N2=Fep(k),
Y(k)=F(k)−F*((−k))N2j=−jFop(k).

原书写 F*(N−k) 时，k=0 仍读第0点。1/j=−j，所以后一个 −j 不是凭记忆添上的相位。

原例2.3.13｜先分离两条频谱，再回到有限长幂序列

原P53指向旧书P73；实际第三版题干和演示在印刷P81–P82。给定 x,y 为 N 点实序列，f=x+jy，且

F(k)=1−aN1−aWNk+j1−bN1−bWNk.

按原解的实参数 a,b 情形解释；原书数值演示为 a=0.8,b=0.6,N=32。下面的有限和还会说明分母为零时怎样取值，不把有限序列误当作无限几何级数，也不凭无限级数要求额外强加 |a|<1。

先用辅助记号

A(k)=∑m=0N−1amWNkm,B(k)=∑m=0N−1bmWNkm.

m 是这里的时间求和哑变量；k 是要算的频点。由有限等比和及 WNkN=1，分母非零时

A(k)=1−aN1−aWNk,B(k)=1−bN1−bWNk.

由于 a,b 为实数，A*((−k))N=A(k)、B*((−k))N=B(k)。所以

F*((−k))N=A(k)−jB(k).

按刚推导的半和、半差分离：

X(k)=A(k)=1−aN1−aWNk,Y(k)=B(k)=1−bN1−bWNk.

不能仅仅说“前一项是实部，后一项是虚部”。这两项含 WNk，在一般频点本来就是复数；能这样分离，是因为已经证明了它们的共轭配对关系。

接下来恢复 x(n)。把 A(k) 的有限和代入逆DFT，并用 m 与 n 分开表示“被求和的时间”和“待恢复的时间”：

x(n)=1N∑k=0N−1∑m=0N−1amWNkmWN−kn=∑m=0N−1am[1N∑k=0N−1WNk(m−n)].

方括号中的正交和，在 m≡n(modN) 时为1，否则为0。这里 m,n 都在同一个主值区间 0,…,N−1，所以只剩 m=n：

x(n)=an,y(n)=bn,0≤n<N.

作为有限长序列，区间外为零；若随后作周期延拓，则按 N 点重复，不能在区间外继续直接套 an 冒充周期序列。

若 aWNk=1，有理式出现 0/0，应回到有限和：每项都为1，所以 A(k)=N。B 同理。这是可去的表达式问题，不是该有限数组的DFT不存在。若参数不是实数，不能跳过共轭对参数的作用，原题“两个实序列”的分离条件也必须重新核查。

数值核对｜原书演示参数与一个可手算的小版本

原书 a=0.8,b=0.6,N=32 给出的时间序列前四项应为

x=[1,0.8,0.64,0.512,…],y=[1,0.6,0.36,0.216,…].

最后一项分别是 0.831 和 0.631。两条曲线都从1开始衰减，0.6n 衰减更快，与原演示图的意义一致；这里只解释和检查演示，不照录其程序。

再取新增的手算版本 N=4,a=1/2,b=1/4。先直接列数组：

x=[1,1/2,1/4,1/8],y=[1,1/4,1/16,1/64].

两条DFT全部为

X=[15/8, 3/4−3j/8, 5/8, 3/4+3j/8],
Y=[85/64, 15/16−15j/64, 51/64, 15/16+15j/64].

例如 k=1 时，把 W4=−j 逐项代入，X(1)=1−j/2−1/4+j/8=3/4−3j/8，其余点同样按四个旋转因子计算。

组合后

F(1)=X(1)+jY(1)=63/64+9j/16,F(3)=33/64+21j/16.

若误取 ReF(1)=63/64 当作 X(1)，会同时丢掉正确实部 3/4 与非零虚部 −3/8。正确操作是

F(1)+F*(3)2=(63/64+9j/16)+(33/64−21j/16)2=3/4−3j/8=X(1),
F(1)−F*(3)2j=15/16−15j/64=Y(1).

这两步是“配对再共轭再半和/半差”，不是在同一个复数上直接取实虚部。

回读｜四行关系，用一句操作描述分别记住

时间侧 DFT频率侧 在时间上做了什么
xr=Rex Xep 原位置与原位置共轭取半和
jxi=jImx Xop 原位置与原位置共轭取半差
xep ReX 原位置与反向位置共轭取半和
xop jImX 原位置与反向位置共轭取半差

这是原P47、P48、P50几组公式的共同结构。第一次读可以从操作解释回到符号；熟悉以后，仍要检查星号、反向下标以及 j 是否都在，不能只背“偶对应实”。

自测｜用边界和复数例检查你真的会区分

  1. N=5 时位置2与谁配对？N=6 时哪些位置自配对？
  2. 圆周共轭反对称数组在 n=0 必须为0吗？给一个反例并说明再加什么条件才必须为0。
  3. 对本节 x=[1,j,0,0]，DFT{Rex} 与 ReDFT{x} 是否相同？分别列出。
  4. 一对共轭反对称的非零值相位是 π/6 与多少（模 2π）？模是否相同？
  5. 设 N≥3，f=x+jy 且 x,y 实值，已知 F(1)=2+3j、F(N−1)=4+j。求 X(1),Y(1)。
  6. 原例逆变换中 ∑k∑mamWNk(m−n)，谁是待求时间、谁是求和时间、谁是频点？若把 m 改成 r，正交条件怎样写？
答案｜把操作、数值和角色一起说出
  1. (−2)mod5=3，所以与3配对。N=6 时0与3各自配对。
  2. 不必须。[j,0,0,0] 就是反例。若再要求数组实值，原点既纯虚又实，只能为0；偶数长度的 N/2 位置同理。
  3. 前者为 [1,1,1,1]，后者为 [1,2,1,0]。前者是频谱的圆周共轭对称分量，后者是频谱逐点实部，不能互换。
  4. 另一相位为 π−π/6=5π/6（模 2π）；两者的模相同。若其中为零，就不再谈它的确定相位。
  5. F*(N−1)=4−j。所以 X(1)=[(2+3j)+(4−j)]/2=3+j；Y(1)=[(2+3j)−(4−j)]/(2j)=2+j。检查 X+jY=(3+j)+j(2+j)=2+3j。
  6. n 是自由的待求时间，m 是时间求和哑变量，k 是频点求和哑变量。改名后正交条件为 r≡n(modN)；在同一主值区间可化为 r=n。不能把 k 在这个式子里也解释成时间。
