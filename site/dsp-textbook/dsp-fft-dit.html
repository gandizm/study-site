FFT 为什么快：奇偶拆分与四点手算

先学：四个采样值看频率

学完能做什么

  • 推导DIT分解与蝶形
  • 完成四点FFT
  • 区分位反转/普通倒序及运算计数

目标｜亲手做一次蝶形，而不是背流程图

FFT 计算的仍是 DFT。我们先把四点 DFT 拆成两次两点 DFT，算出与直接公式相同的答案，再看如何继续拆成八点、十六点以及更长的算法。原 PPT 2.5 P1–7、P10–19 是本节来源。

读完应能解释三个问题：拆开的数据来自哪里，蝶形中为什么一加一减，以及“倒序”到底倒什么。

记号｜原式中的 N、n、k 与层数

原书的正变换为

X(k)=∑n=0N−1x(n)WNkn,WN=e−j2π/N.

N 是本次 DFT 点数，n 是输入时域位置，k 是输出频率格点。旋转因子 WN 已含负指数；式子中写 WNkn 就是正变换。别再人为添一个负号。

本节专讲基2 FFT，要求 N=2M，M 是能连续对半拆分的次数。P10 使用 N=2m，P17/P19 改写成 N=2M，这里明确两页的 m,M 都表示层数，我们在同一段采用后者 M。它们不是下面对子序列求和的时间下标。

FFT 并不都要求2的整数次幂。其他长度有其他分解方法；若只是为本节基2算法补零，补零后的 DFT 点数已经改变，不能说仍在计算原来那个长度的完全相同频率网格。

定义｜直接 DFT 为什么会重复做很多工作

固定一个 k，原式有 N 次复乘、N−1 次复加；所有 N 个输出合计 N2 次复乘和 N(N−1) 次复加。这是把乘以1等特殊项也算进去的朴素口径，不是每种软件的实际指令数。

例如 N=1024，复乘有 10242=1048576 次。FFT 的节省来自复用中间结果及旋转因子的规律，不能仅靠“计算机变快”来解释。

P6 的24道记录例需要特别读条件：若24道互相独立，每道 5×500=2500 点，逐道直接 DFT 的复乘总量应为 24×25002=150000000。把所有道拼成60000点再平方，计算的是另一项60000点变换，不能把二者当成同一任务；“运算次数”也不等于“运行多少秒”。

P4 是算法发展背景，不是后面蝶形公式的证明。本节要掌握的是 P7 的可复用结构，而非靠记住历史故事来判断计算正确。

推导｜先把时间下标分成偶数和奇数

原 PPT P10 定义两条短序列：

x1(r)=x(2r),x2(r)=x(2r+1),0≤r<N/2.

换元必须在这里说清楚： 原序列位置是 n。取偶数位置时令 n=2r，取奇数位置时令 n=2r+1。r 是短序列内部的新时间位置，不是频率，也不是直接把 n 换个字母而不改变尺度。

例如 x={1,2,3,4} 时，x1={1,3}、x2={2,4}。名字“时域抽取”就是指此处按输入时间位置的奇偶分组；没有扔掉一半信息，两组都保留。

把 DFT 分开：

X(k)=∑r=0N/2−1x(2r)WN2kr+∑r=0N/2−1x(2r+1)WNk(2r+1).

因为

WN2kr=e−j2πkr/(N/2)=WN/2kr,

前一项恰好是 x1 的 N/2 点 DFT。后一项可以先提出 WNk，剩下 x2 的 N/2 点 DFT。沿用书中的 X1(k),X2(k)：

X(k)=X1(k)+WNkX2(k).

这里 X1,X2 是两条短序列各自的变换结果，不是把原结果 X 随便一分为二。

推导｜一对输出为何只要一次乘法

短 DFT 按 N/2 周期重复，所以 Xi(k+N/2)=Xi(k)。而旋转因子满足

WNk+N/2=WNke−jπ=−WNk.

因此，对 k=0,…,N/2−1，

X(k)=X1(k)+WNkX2(k),
X(k+N/2)=X1(k)−WNkX2(k).

先算一次 t=WNkX2(k)，再给出 X1(k)+t 和 X1(k)−t。这就是原 P12 蝶形图上的 A+BC 与 A−BC：A=X1(k)、B=X2(k)、C=WNk。一次复乘复用给两个输出，另做两次复加/减。

例题｜四点 FFT 完整手算

补充练习，不是原 PPT 的编号例。 输入 x(n)={1,2,3,4}，首项对应 n=0。

第一步，按原式取 x1={1,3}、x2={2,4}。两点 DFT 只有和与差，因为 W2=−1：

X1(0)=1+3=4,X1(1)=1−3=−2,
X2(0)=2+4=6,X2(1)=2−4=−2.

第二步，用 W4=−j 合并。不要混淆这里的“短频率 k=1”与最后输出位置 k+2=3：同一个短结果会参加两个完整输出。

蝶形编号 k 旋转后的 t=W4kX2(k) 上输出 X(k) 下输出 X(k+2)
0 1×6=6 4+6=10 4−6=−2
1 (−j)(−2)=2j −2+2j −2−2j

按自然频率次序，答案是

X(k)={10,−2+2j,−2,−2−2j}.

直接代入原 DFT 核对 k=1：1−2j−3+4j=−2+2j。因此 FFT 没有把 DFT 换成近似，只有执行顺序改变；实际浮点计算时，不同顺序仍可能带来很小的舍入差异。

推导｜继续拆分，才得到 N log N

P14 只拆一次，还要计算两个长 N/2 的 DFT，复乘约为 N2/2+N/2，只是约减半。若 N/2 还是2的幂，就继续拆。

P15 写 x1(2l)=x3(l)、x1(2l+1)=x4(l)。这里新增的 l 是更短序列内部的位置：

x3(l)=x(4l),x4(l)=x(4l+2).

只有把这次换元追到原序列，才不会误以为下标1、3、4是在说时间值。它们是不同子序列的名字。

一直拆到两点和差，总共 M=log2N 级，每级 N/2 个蝶形。按每蝶形一次复乘、两次复加计：

Cmul=N2log2N,Cadd=Nlog2N.

对 N=1024，是5120次复乘、10240次复加。与直接法的复乘相比，倍数为 1048576/5120=204.8；若将复乘和复加都当作一次等权操作，总数比约136.5。原 P17 列的是复乘与复加的总量比，却写“约200倍”；按它列出的总量口径应约为136.5，而“约200”只接近单独复乘的204.8倍。这个原页口径不一致要明确修正，更不能据此说软件运行时间必定快200倍。乘以 1,−1,±j 的优化还会减少一般复乘，但那是另一层实现计数。

P18 的两条曲线是在比较 N2 与 (N/2)log2N 的增长。对长序列，避免重复计算比微调一个常数更重要。

方法｜读八点流图，先追输入编号

P13/P16 给八点分解与流图。看箭头之前先检查四件事：每个输入原来是哪一项，当前块长是多少，哪个支路乘 WNp，输出标签是 X(k) 还是某级临时量 A。图上的上下位置本身不等于序列下标。

对于常见的“原位迭代 DIT，输出自然顺序”排列，输入按二进制位反转排列：

原下标 3位二进制 位反转 反转后的下标
0 000 000 0
1 001 100 4
2 010 010 2
3 011 110 6
4 100 001 1
5 101 101 5
6 110 011 3
7 111 111 7

输入存放为 x(0),x(4),x(2),x(6),x(1),x(5),x(3),x(7)。书中“倒序”不是 x(7),x(6),…,x(0) 的普通反向排序。其他递归实现或重排流图可采用不同内部布局，不能把该排列口径当成所有 FFT API 的强制输入格式。

在这种标准迭代布局中，第 L 级（L=1,…,M）的块长为 2L，蝶形两输入距离为 B=2L−1，块内第 J 个蝶形使用 WNP，其中

P=J2M−L,J=0,…,2L−1−1.

此处的 L 是原书的级号，不是卷积节的 DFT 长度。 对八点变换，三级的蝶距分别为1、2、4，旋转因子指数分别为 {0}、{0,2}、{0,1,2,3}。先用这个具体例子定位，再回读原 P17 的一般公式。

回读｜原公式的三次拆解

  1. n=2r 或 2r+1：把时间位置分成偶、奇，形成两条短序列。
  2. X(k) 与 X(k+N/2)：同一对短频谱值，复用一次旋转乘法，生成一加一减。
  3. 重复拆到两点：总共 log2N 级，不是只拆一次就能宣称复杂度变成 NlogN。

自测｜把计算与排列分开

  1. 四点例中，x1(1) 是原输入哪一项？它的值是多少？
  2. 为何计算 X(1) 与 X(3) 时不必把 (−j)(−2) 算两次？
  3. 八点位反转中下标3去哪里？这是普通倒放吗？
  4. 256点基2FFT有几级、每级几个蝶形、一般复乘计数多少？
  5. 2500点输入为了做4096点基2FFT而补零，频率网格是否仍是 2πk/2500？
答案｜核对角色与条件
  1. x1(1)=x(2)=3，短序列位置1对应原偶数位置2。
  2. 两个输出共用同一个 t=2j，仅在后面分别加、减。
  3. 011→110，去6；不是把数组整体反过来。
  4. 8级，每级128个蝶形，一般复乘计数 128×8=1024。
  5. 已改为4096点变换，网格是 2πk/4096。输入有效数据仍只有2500点，没有因为补零获得更长的真实观测。
