先认角色，再看字母：n和k到底能不能互换？

先学：全章导览

学完能做什么

  • 区分时间索引、频率格点与求和哑变量
  • 在变量换名时保持作用域和全部关联位置一致
  • 读回原PPT的DTFT与时域卷积记号

学习目的｜本节要会什么

读完这一节，你应该能说清三个问题：一个字母现在表示哪个量；它有没有被求和号绑定；改写这个字母时，哪些位置必须一起改。

这一节是为阅读原 PPT 增加的铺垫，不是新增的变换理论。我们会回到原书使用的 x(n)、X(ejω) 等写法。

定义｜字母只是名字，角色来自当前公式

用 x(n) 表示序列在第 n 个位置的数值。例如，给出四个采样值 [1,0,−1,0]，并规定从 n=0 开始编号，就是：

x(0)=1,x(1)=0,x(2)=−1,x(3)=0.

这里的 n 是时间采样点的编号，不是以秒为单位的时间。若相邻采样点相隔 Ts 秒，并以第0个样值的时刻为0，第 n 个点对应的物理时刻才是 nTs 秒。

有些信号与系统资料写 x[n]。在此处，x[n] 与 x(n) 都表示序列的第 n 个样值，方括号本身没有产生新的运算。本站回读原书时沿用原书的圆括号。

例题｜求和用的 n 可以换名，但要成套换

先只计算四个数的总和：

S=∑n=03x(n)=x(0)+x(1)+x(2)+x(3).

本式的符号角色：S 是求出的总数；n 依次取 0,1,2,3，只是求和过程的编号。求和完成后，S 不再依赖 n。

把求和编号改叫 m，不改变任何计算：

S=∑m=03x(m).

换字母提醒：求和号下面的 n 和括号里的 n 必须一起改。不能写成 ∑m=03x(n) 后还声称是原式，因为这时求和的 m 没有进入被加的量，而 n 留在了外面。

这种只在求和内部起作用的编号，叫作求和哑变量。名字虽然陌生，意思就是“它负责依次点名，最后不会留在答案中”。

定义｜频率索引不是时间索引

现在看一个 N 点 DFT。先认识符号，不要求此刻完成一般推导：

X(k)=∑n=0N−1x(n)e−j2πkn/N,k=0,1,…,N−1.
  • N：这次变换使用的采样值个数，事先固定。
  • n：当前被加进计算的时间样值编号，在求和里依次取 0 到 N−1。
  • k：这次正在计算的频率格点编号。先固定一个 k，完成对全部 n 的求和，才得到一个 X(k)。
  • j：满足 j2=−1 的虚数单位，不是新的编号。
  • 2πk/N：第 k 个格点的离散时间角频率，单位是弧度每采样。

为什么两个编号缺一不可？ 取 N=4、固定 k=1 时，要把四个不同的时间样值分别乘上对应权重，再相加。这里“第 1 个频率格点”与“第几个时间样值”是两件事。

因此，这个式子里的 k 不能被解释成“以前的 n”。它在这里明确是频率索引。

推导｜合法换名：只改求和编号

在上面的 DFT 定义中，把时间求和编号 n 改成 m：

X(k)=∑m=0N−1x(m)e−j2πkm/N.

这与原式完全相同。频率格点 k 没动，求和遍历的仍是全部时间样值，只是临时编号换了名字。

如果要把频率索引也换名，例如改叫 r，必须同时改左边的 X(k)、指数里的 k 和公式后面的取值范围：

X(r)=∑m=0N−1x(m)e−j2πrm/N,r=0,1,…,N−1.

作用域提醒：这两种改名都合法，但不是“把看到的所有字母随便替换”。每次都要知道自己改的是外面的频率参数，还是求和内部的时间编号。

回读｜DTFT 里如果出现 k，先看它在哪儿

原 2.1 第 5 页使用的 DTFT 定义可以读为：

X(ejω)=∑n=−∞∞x(n)e−jωn.

本节先识别符号；这个无穷和作为普通求和成立的条件，留到 DTFT 正文说明，不能先假定任何序列都收敛。

本式的 ω 是连续变化的离散时间角频率，n 是遍历全部整数时间位置的求和编号。这里没有 DFT 那种“第 k 个频率格点”。

如果另一本书把同一个式子写成：

X(ejω)=∑k=−∞∞x(k)e−jωk,

那么此处 k 确实承担上一式中 n 的角色：它是时间求和编号，不是频率索引。判断依据是整个定义，而不是字母 k 本身。

读回原式的方法：先指着 X(ejω) 说“我在求频率 ω 处的变换值”；再指着求和号说“我要把所有时间样值的贡献加起来”。最后才把这些角色与式中的字母配上。

这段改写是辅助阅读的示例，不是在声称原 PPT 第 5 页真的把 n 改写成了 k。

解释｜每次遇到陌生符号，问三句话

  1. 它表示什么量：时间位置、频率格点、长度，还是一个常数？
  2. 它被哪个求和或积分绑定，还是留在结果外面自由变化？
  3. 如果换名字，哪些位置和取值范围必须一起换？

以后每次推导遇到换元，我们都会在发生的地方回答这些问题，而不是让你记住“某字母永远代表某东西”。

自测｜先说角色，不急着算

  1. 在 A(r)=∑q=03x(q)e−j2πrq/4、r=0,1,2,3 中，哪个字母是时间求和编号，哪个是频率格点？
  2. 把式一的 q 改成 m，结果会变吗？需要改哪些位置？
  3. 在 B(ω)=∑k=−∞∞x(k)e−jωk 中，能不能因为出现了 k 就断定这是 DFT？
  4. 在卷积式 y(n)=∑k=−∞∞x(k)h(n−k) 中，n 和 k 谁是要计算的输出时间位置？谁在求和里遍历？这里的 k 是频率吗？
答案｜先做再看
  1. q 遍历四个时间样值，r 指定要计算的频率格点。
  2. 不变。求和下标、x(q) 和指数中的 q 都要改成 m；r 不改。
  3. 不能。这里的 k 是时间求和编号，ω 才是频率变量。按这个式子的形式，它是在写 DTFT，而不是有限点 DFT。
  4. n 是当前要计算的输出时间位置，k 是时间求和哑变量，不是频率。h(n−k) 表示在固定输出位置 n 时，各输入位置 k 对应的系统响应位置。卷积的详细含义和逐项计算会在应用小节展开。
