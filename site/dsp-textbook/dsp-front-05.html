时移、频移与频谱运算

先学：DTFT正逆变换的完整算例

学完能做什么

  • 从定义推导线性、时移、频移、翻转与微分
  • 区分n/n0和ω/ω0并检验每个正负号
  • 用同一短序列逐条核验，学会组合性质

目标｜把“修改样值”翻译成“修改频谱”

上一节从头算了一串 1 的频谱。如果只把这串数据向右挪两个位置，难道又要重新做一次等比求和？不必。DTFT 的性质就是这种翻译规则：时域做什么，频域跟着怎样变。

但本节不会只给你一张表。每条规则先从定义推出，再用同一条短序列验算，最后回读课件原式。这样既能节省计算，也不容易把时移的负号、频移的方向或微分前面的 j 背反。

本节对应课件 2.1 P11、P13–P16。P11 是性质目录；卷积、能量和对称性将在后续单元分别展开，P32–P33 总表也等这些内容讲完后再整体回读。

记号｜固定偏移量和正在变化的变量不是一回事

符号 作用
n 时域输出位置或求和中的时间索引，具体角色在式旁注明
n0 固定的整数时间平移量
ω 正在询问的数字角频率
ω0 固定的频率移动量，单位弧度/样点
m 换元之后的时间求和哑变量
X(ejω)、Y(ejω) 输入序列 x(n) 与变换后序列 y(n) 各自的 DTFT

这里 n0 的下标 0 表示一个固定参数，不是乘以零；ω0 同理。不要把 ejω0n 和 ejωn0 看成同一式：前者的样值随时间 n 变化，后者把正在分析的频率 ω 放进了一个固定时间平移因子。

写

x(n) ⟷ X(ejω)

表示一对 DTFT，不是说左右两个函数的值直接相等。继续沿用原课件的圆括号，熟悉的 x[n] 与此同义。

本节普通求和的论证采用绝对可和条件；所有具体算例都有限长。微分性质还会单独说明更强的充分条件。

定义｜本节反复使用的三个样值

为减少新的记忆负担，后面的例题都从同一条新编序列出发：

x(n)=δ(n)+2δ(n−1)+3δ(n−2).

即 x(0)=1、x(1)=2、x(2)=3，其他整数时刻为零。直接代入定义得到

X(ejω)=1+2e−jω+3e−j2ω.

这些数字例题是补充教学例，不假称原 PPT 已有对应题干。它们的好处是每条规则都能与逐项求和独立对照。

推导｜线性：先相加再变换，等于分别变换再相加

课件 P13 的原式为

DTFT[ax1(n)+bx2(n)]=aX1(ejω)+bX2(ejω),

其中 a,b 是不随 n 变化的常数，可以是实数或复数。

证明只是把求和拆开：

∑n[ax1(n)+bx2(n)]e−jωn=a∑nx1(n)e−jωn+b∑nx2(n)e−jωn.

本节未写上下限的 ∑n 均表示遍历全部整数，并不是只在某个周期内求和。

**小检查。**若只把我们的三个样值都乘以 2，得到 [2,4,6]，频谱当然变成 2+4e−jω+6e−j2ω=2X(ejω)。若系数本身随时间变化，就不能当常数提出求和，必须另用合适的规则。

推导｜时移：在时间上延迟，频谱多一个相位因子

课件 P14 的时移式是

x(n−n0) ⟷ e−jωn0X(ejω).

先判断方向：n0>0 时，旧样值 x(0) 要等到新时刻 n=n0 才出现，因此是向右延迟，不是提前。

令 y(n)=x(n−n0)，从定义写起：

Y(ejω)=∑nx(n−n0)e−jωn.

换元 m=n−n0，也就是 n=m+n0。m 仍然是时间求和索引，全部整数只是换了编号：

Y(ejω)=∑mx(m)e−jω(m+n0)=e−jωn0∑mx(m)e−jωm=e−jωn0X(ejω).

因为 |e−jωn0|=1，纯时移不改变幅度谱；在频谱非零处，它给相位增加 −ωn0，相位值仍按模 2π 理解。

**完整算例。**取 n0=2，则 y(2)=1、y(3)=2、y(4)=3，其余为零。直接求和：

Y(ejω)=e−j2ω+2e−j3ω+3e−j4ω=e−j2ω(1+2e−jω+3e−j2ω).

这就独立核对了负号与平移方向。这里没有圆周移位，也没有把跑出原区间的样值绕回去；那是后面的 DFT 有限周期结构才要讨论的事。

推导｜频移：给样值乘复正弦，频谱沿频率轴平移

正确的频移关系为

ejω0nx(n) ⟷ X(ej(ω−ω0)).

请特别看下标：固定频率是 ω0，乘在它后面的 n 才是时间索引。课件 P32 汇总表也使用这一关系；回读 P14 时，要按这个角色辨认指数，不能把 n0 的时移参数移植到这里。

证明时先不要猜方向，把两个指数合并：

Y(ejω)=∑n[ejω0nx(n)]e−jωn=∑nx(n)e−j(ω−ω0)n=X(ej(ω−ω0)).

如果原频谱在 ω=0 有一个特征，新频谱要在 ω=ω0 才读到它，因为此时括号里的 ω−ω0=0。所以 ω0>0 对应向正频率方向移动。整个频谱本来以 2π 为周期，因此移动超出一个所选画图周期的部分，会从等价频率位置重新出现。

**完整算例。**取 ω0=π/2，时间序列变成

y(0)=1,y(1)=2j,y(2)=−3.

直接求和给出

Y(ejω)=1+2je−jω−3e−j2ω.

用性质核对：

X(ej(ω−π/2))=1+2e−j(ω−π/2)+3e−j2(ω−π/2)=1+2je−jω−3e−j2ω.

如果把正变换的负号记反，这个非对称复数例子会立刻暴露问题，不会像偶对称余弦那样掩盖错误。

补充推导｜乘余弦为什么产生左右两份频谱

复指数频移知道以后，只需要上一节学过的欧拉式：

cos(ω0n)=12ejω0n+12e−jω0n.

结合线性与两次频移，得到

x(n)cos(ω0n) ⟷\ 12X(ej(ω−ω0))+12X(ej(ω+ω0)).

每一份前面有 1/2，不能因为有“两份”就把系数省掉。如果两份频谱重叠，要按复数相加，不能只把幅度图简单相加。这是已证明规则的组合，不要求再背一条独立结论。

用原三个样值、ω0=π/2 检查：余弦在 n=0,1,2 分别为 1,0,−1，新样值是 [1,0,−3]，所以频谱应为 1−3e−j2ω。上式两份相加时，一次项 2je−jω 与 −2je−jω 抵消，确实得到相同结果。

推导｜时间翻转：读样值的顺序反过来，频率也反向

课件 P15 写

x(−n) ⟷ X(e−jω).

右边可以读成“把原频谱中的频率参数 ω 换成 −ω”。它不是把整个复数频谱取负。

证明中令 m=−n：

Y(ejω)=∑nx(−n)e−jωn=∑mx(m)ejωm=X(e−jω).

全部整数换成相反数后，仍然遍历全部整数；在绝对收敛条件下可以这样重排。

**完整算例。**原来位于 n=0,1,2 的 1,2,3，翻转后位于 n=0,−1,−2，因此

Y(ejω)=1+2ejω+3ej2ω.

注意，时间翻转与复共轭是不同操作。对这条实序列，翻转频谱恰好也等于原频谱的共轭；但不能据此推广到所有复序列。例如 x(n)=jδ(n) 的频谱恒为 j，时间翻转不改变它，仍为 j；取共轭则会得到 −j。一般共轭关系留到对称性单元证明。

推导｜时间乘 n 为什么对应频率微分

课件 P16 的式子是

y(n)=nx(n)⟹Y(ejω)=jdX(ejω)dω.

这里 d/dω 是对“沿 ω 变化的整个频谱”求导，不是对独立复变量 z 求导；j 是虚数单位，不是求和索引。

若允许逐项求导，

dX(ejω)dω=∑nx(n)de−jωndω=∑n(−jn)x(n)e−jωn.

两边乘 j，因为 j(−j)=1，得到

jdX(ejω)dω=∑nnx(n)e−jωn=Y(ejω).

这就是前面系数为 j 而不是 −j 的来源。

**条件不能省。**有限长序列可以直接逐项求导；对于无限长序列，一组足够安全的条件是原序列绝对可和，并且

∑n|nx(n)|<∞.

只有原序列绝对可和，并不足以自动保证任意阶求导都可以交换到求和里面。

**完整算例。**原样值 [1,2,3] 分别乘时间编号 0,1,2，得到 [0,2,6]，所以应有

Y(ejω)=2e−jω+6e−j2ω.

另一边计算导数：

dXdω=−2je−jω−6je−j2ω,jdXdω=2e−jω+6e−j2ω.

两种做法吻合。n=0 处的样值被乘成零，并不是因为原样值是零，而是它的时间编号是零。

综合算例｜两倍原序列，减去延迟一格的序列

求

y(n)=2x(n)−x(n−1)

的 DTFT，其中 x(n) 仍是本节的三个样值。

先用性质，只需一行：

Y(ejω)=(2−e−jω)X(ejω).

再在时域把四个可能非零的位置逐项列完：

  • n=0：2x(0)−x(−1)=2−0=2。
  • n=1：2x(1)−x(0)=4−1=3。
  • n=2：2x(2)−x(1)=6−2=4。
  • n=3：2x(3)−x(2)=0−3=−3。
  • 其他整数时刻两项都为零。

所以直接求和应为

Y(ejω)=2+3e−jω+4e−j2ω−3e−j3ω.

把 (2−e−jω)(1+2e−jω+3e−j2ω) 展开，常数、一次、二次、三次系数分别是 2,3,4,−3，独立检查完成。

回读｜看原式时先圈出“谁固定、谁在跑”

对课件的四种写法，推荐按下面顺序读：

  1. x(n−n0)：n 是新时刻，n0 是固定延迟量；频域乘 e−jωn0。
  2. ejω0nx(n)：ω0 固定、n 随样值变化；频谱中的参数换成 ω−ω0。
  3. x(−n)：先把时间位置翻转；频谱中的参数换成 −ω。
  4. nx(n)：样值乘自己的时间编号；频域是 j 乘对 ω 的导数。

某个证明把内部 n 换成 m，通常只是为了让换元后的式子清楚。换字母时样值参数、指数和求和标记必须一起换；固定参数 n0、ω0 不跟着乱改。

自测｜先猜方向，再用一两个样值核对

  1. y(n)=x(n+3) 是提前还是延迟？频谱前面的因子是什么？
  2. y(n)=e−jπn/2x(n) 的频谱是把 ω 换成 ω−π/2 还是 ω+π/2？
  3. 对本节的 x(n)，求 x(1−n) 的所有非零样值及 DTFT。不要只说“翻转加平移”。
  4. 有人把 nx(n) 的变换写成 −jdX/dω。用只有 x(1)=1 的序列检查这个符号。
  5. “时间翻转等于取共轭”为什么不是一般规则？给出本节中的最小反例。
答案｜每一处负号都能追到定义
  1. x(n+3)=x(n−(−3))，所以是提前 3 个样值，因子为 ej3ω。原来的 x(0) 在新时刻 n=−3 出现，可核对方向。
  2. 调制频率是固定的 ω0=−π/2，所以换成 ω−ω0=ω+π/2。不能仅凭指数里看见负号就把结论也写成负向参数替换。
  3. 令 1−n=0,1,2，分别得到新时刻 n=1,0,−1，样值依次为 1,2,3。因此 Y(ejω)=e−jω+2+3ejω。也可先翻转得到 X(e−jω)，再延迟1格，得到 e−jωX(e−jω)，展开一致。
  4. 该序列的 X(ejω)=e−jω，乘时间编号后仍只有 n=1 处为1，所以变换也应是 e−jω。jdX/dω=j(−j)e−jω=e−jω；若写 −j 则得到负号，错误。
  5. x(n)=jδ(n) 时间翻转后不变，频谱仍为 j；取频谱共轭会得到 −j。实序列的特殊关系不能不加条件地推广到复序列。
