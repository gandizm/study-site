学习目的｜本节要会什么

这章研究的是：拿到一串采样值后，怎样换一种坐标来看它，判断其中的频率成分，并把这种表示用于计算。

你最后要能做六件事：

  1. 看到一个序列，分清它是一般序列、周期序列，还是只取出的一段有限数据。
  2. 说明为什么有的频谱是一条连续曲线，有的却是一组离散系数。
  3. 手算一个很小的 DFT，并用逆变换把原数据找回来。
  4. 看懂 FFT 的拆分过程，知道它为什么算得快，而不是把 FFT 当作另一种变换。
  5. 用 DFT 算线性卷积，知道什么时候必须补零、为什么补。
  6. 对一幅计算机画出的频谱，正确解释频率刻度、泄漏和分辨率，不把“图更密”误当作“分辨能力更高”。

现在不需要先背下本章所有公式。先知道每一节回答哪个问题，再按顺序把公式读懂。

本章内容怎样连起来

原 PPT 的六部分仍然全部保留。我们增加一段基础铺垫，再重排部分解释和算例；学习目标仍然是回去看懂原教材和课堂公式。

起点：序列、频率与符号角色

先分清“第几个采样值”和“第几个频率成分”。同一个字母在不同公式里可能换工作，后面每次换角色都会就地说明，不要求你靠猜。

2.1 DTFT：一串离散数据的连续频谱

问题是：对于离散时间序列，能不能像信号与系统里那样讨论它在各个频率上的成分？

这里的时间编号是整数，但待考察的频率可以连续变化。你会学习 DTFT 的正变换、逆变换及性质，也会理解频谱为什么以 2π 为周期。

2.2 周期序列：只用一组系数描述反复重复的数据

如果序列每隔 N 个采样值重复一次，只需要给出一周期数据。我们先看它怎样由有限种复正弦模式组成，再理解周期序列的 DTFT 为什么要用冲激表示。

这一节里的傅里叶级数系数，与后面 DFT 的数值可能差一个 N。这不是随意换公式；每次都会把采用的归一化写清楚。

2.3 DFT：把有限个采样值换成有限个频率坐标

计算机手里通常只有 N 个数。DFT 把这 N 个数变为 N 个复数，并且可以逆变换回来。

这里最容易混淆的是三件不同的事：原信号可能并不周期；我们只取了有限数据；DFT 的数学表示却与周期延拓有联系。我们会把这三层分开讲，而不是一句“默认周期”带过。

2.4 频域采样：DFT 与 DTFT 是怎样接上的

对一段有限长序列，它的 DTFT 是连续频率函数。DFT 则在等间隔频率点上取值。

这一节回答：取多少点才够？这些频率样值能够恢复什么？点数不足时，时域为什么会发生周期叠加？它与“对连续时间信号采样”的采样定理有联系，但不是同一个操作，不能混着背。

2.5 FFT：不改答案，只改算法

FFT 是计算 DFT 的高效方法。我们先用很小的例子看“偶数位置与奇数位置分开算，再合起来”，最后再学习蝶形图和排序。

只有先明白 DFT 要算什么，FFT 的下标变化才有意义。

2.6 应用：用频率坐标完成实际任务

第一条线是计算卷积：从线性卷积到循环卷积，再说明补零为什么能避免首尾混在一起。

第二条线是观察频谱：采样频率、数据长度、窗和补零分别改变什么。你会练习从“我想观察什么”出发选择计算方式，而不是只会调用 FFT。

两条阅读路线

第一次学习，按“符号与频率铺垫 → 四个采样值的算例 → DTFT → 周期序列 → DFT → 频域采样 → FFT → 应用”读。前面的四点算例只负责建立直觉，不要求先接受所有一般公式。

跟课堂复习时，可以直接按原 PPT 的 2.1 至 2.6 进入。每节都会列出对应原页，并把新增的解释标为“补充铺垫”。

这份教材怎样标注内容

  • 定义：规定一个量或运算是什么意思。先看它接收什么、输出什么。
  • 结论：在明确条件下可使用的性质。条件与归一化不能省。
  • 推导：说明结论怎样从前面得到。换元、求和范围和关键等号会解释。
  • 例题：把定义或结论用于具体数据。例题不是又增加了一套公式。
  • 自测：用一个小问题确认你能否自己说清。答案可以展开，但建议先做。
  • 原书回读：回到原 PPT 的记号，辨认每个符号的角色，确认离开这份辅助说明后仍能认出来。

遇到符号冲突，我们怎样处理

不会把全书的 k 都改成 n，也不会说它们永远一样。

如果某一式中的 k 只是遍历时间采样点的求和编号，它可能承担前一式中 n 的工作；如果 k 表示第几个频率格点，它与时间编号 n 就是不同角色。每次要先看量的定义和求和范围，再看字母。

下一节用三个很短的式子专门练习这件事。以后不是靠查一大张符号表，而是在推导发生换角色的地方提醒你。

先做一个不需要计算的自测

自测

  1. FFT 是一种新的频率变换，还是计算 DFT 的一种算法？
  2. “时间是离散的”是否意味着“频率变量也只能离散取值”？
  3. 两个公式里都出现 k，是否足以证明它们表示同一个量？
展开 答案｜先做再看
  1. FFT 是计算 DFT 的高效算法，结果仍是相同定义下的 DFT。
  2. 不是。DTFT 的输入是离散时间序列，频率变量仍可连续变化。
  3. 不足以。必须查看当前公式的定义、作用域和求和范围。
