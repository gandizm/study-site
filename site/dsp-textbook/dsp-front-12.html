有限序列的DFT与逆变换为什么成立

先学：从模拟信号到样值和频谱副本

学完能做什么

  • 按原W_N约定完整证明DFT/IDFT和1/N
  • 区分有限数组、DTFT采样、Z单位圆采样与DFS归一化
  • 完成原R4不同点数例及脉冲例，说明补零和隐含周期性边界

目标｜从整条频谱，走到可逆的 N 个数

DTFT 可以回答任意数字频率处的值；DFT 则选定 N 个等间隔频率，把 N 个时间样值变成 N 个复数系数。这里重要的不只是“计算机喜欢有限个数”，还包括：为什么恰好这些频点足以把原来的 N 个样值恢复出来？

本节对应原2.3 P1–P13。第一节已经完整算过四点例子；现在给一般定义、逆变换证明，以及原 PPT 的矩形序列多种点数算例。我们会保留原来的 WN、X(k)、X~(k)，解释它们之间的关系，不把书里的记号换掉后让你回去又看不懂。

P1–P2 是本节封面和路线。P3 用无限长求和、连续频率与积分说明数字处理的动机，但这应理解为一般情形的难点，而不是“计算机不能算 DTFT”。有限长序列的 DTFT 在任何一个给定频率处，本来就能通过有限次加法得到；DFT 进一步指定一组有限、可逆的频率坐标。

记号｜长度、时间位置与频点编号分别是谁

符号 角色
N 本次 DFT 点数，也是这次数组的长度
n 时间样值位置，代表范围 0,1,…,N−1
k 频点编号，代表范围 0,1,…,N−1
ωk=2πk/N 第 k 个频点的数字角频率
WN=e−j2π/N 固定的单位复数，原课件的旋转因子
m 逆变换证明中内部的时间求和哑变量
x~(n),X~(k) 按长度 N 周期延拓后的序列与系数

本节 k 是频点编号，与上一节卷积证明里作为时间哑变量的 k 不同。不是我们把同一物理量忽然改名，而是每条公式的定义与作用域不同。

原书的 x(n),X(k) 与熟悉的 x[n],X[k] 仅是括号风格差别。课件用 X(ejω) 表示连续频率的 DTFT，用 X(k) 表示指定频点的 DFT；不能只把 ω 的字母直接换成 k，还须代入 ω=2πk/N。

定义｜保留原书的正逆公式与 W_N

课件 P4 的正变换为

X(k)=DFT[x(n)]=∑n=0N−1x(n)e−j2πkn/N=∑n=0N−1x(n)WNkn,0≤k≤N−1.

固定一个 k，让 n 跑遍全部时间样值，得到这一个频点的系数。然后再换下一个 k。

原书的逆变换为

x(n)=IDFT[X(k)]=1N∑k=0N−1X(k)WN−kn=1N∑k=0N−1X(k)ej2πkn/N,0≤n≤N−1.

这里固定目标时间位置 n，让 k 跑遍全部频点。正变换没有 1/N、逆变换有 1/N；WN 自身已经带负号，所以逆变换中的 WN−kn 恰好产生正指数。

DFT 作为一个有限数组变换，本身不要求真实物理信号在观察窗口之外周期重复。若把数组解释为区间外为零的有限序列，就可与它的 DTFT 对照；若另做周期延拓，则可与 DFS 对照。这两种延拓不是同一条无限序列。

铺垫｜先用两个数看清为什么需要 1/N

取任意两个复数样值 x(0)=a,x(1)=b，令 N=2。因为 W2=e−jπ=−1，

X(0)=a+b,X(1)=a−b.

把两式相加、相减：

a=X(0)+X(1)2,b=X(0)−X(1)2.

因此逆变换的 1/2 并非额外“平均掉信号”，而是抵消正变换叠加时产生的因子。一般的 1/N 同样来自不同频率基的相互正交。

推导｜有限的整圈求和如何筛选一个样值

考虑原书旋转因子的和

Sm,n=∑k=0N−1WNk(m−n).

这里 m,n 都是时间位置，k 才是频点求和编号。若 m−n 是 N 的整数倍，则每项都为1，和为 N。

否则令 q=WNm−n，有 q≠1，但

qN=e−j2π(m−n)=1.

用有限等比和：

Sm,n=1−qN1−q=0.

因此完整条件是

∑k=0N−1WNk(m−n)={N,m≡n(modN),0,其他情况.

m≡n(modN) 表示两整数之差是 N 的整数倍，例如 N=4 时0与4属于同一余数类。

在本次逆变换证明中，m,n 都限制在 0 到 N−1，所以同余就等于 m=n。只有加上这个范围，才能把结论简写成“相同则为 N，不同则为0”。若允许任意整数编号，不能忘掉模 N 的条件。

推导｜逐式回读原 P5 的 m 与 n

我们要证明逆变换真的恢复给定的 x(n)。先固定一个输出时间位置 n，代入正变换：

1N∑k=0N−1X(k)WN−kn=1N∑k=0N−1[∑m=0N−1x(m)WNkm]WN−kn.

为什么内层写 m，不再写 n？外层的 n 已经是固定目标位置，内层还要把全部时间样值遍历一遍。课件把正变换内部的时间哑变量换成 m，就是为了把这两个角色分开；m 不是又添了一种频率。

有限求和可交换顺序，合并指数后得到

=1N∑m=0N−1x(m)[∑k=0N−1WNk(m−n)].

方括号只在 m=n 时等于 N，于是

=1NNx(n)=x(n).

这同时说明逆变换为何要有 1/N，以及为什么这一组等间隔频点能恢复原来的全部 N 个样值。证明针对完整复数系数；如果只留下幅度而丢掉相位，一般就不再可逆。

关系｜DFT 是有限序列 DTFT 的等间隔采样

对长度不超过 N、并放在 0 到 N−1 内的序列，区间外设为零，则

X(ejω)=∑n=0N−1x(n)e−jωn.

代入 ωk=2πk/N，就得到

X(k)=X(ejω)|ω=2πk/N.

因此 DFT 的 k 是频点编号，不是以弧度计的角度。若样值来自采样率 fs 的均匀采样，频率间隔为 fs/N；在指定的一周期表示里，第 k 个点对应 kfs/N，超过半个采样率的点也可以改写成等价负频率。

从 Z 变换看，课件 P6 写

X(z)=∑n=0N−1x(n)z−n,X(k)=X(z)|z=ej2πk/N.

注意取样点 z=e+j2πk/N 是正指数；因为 Z 变换内部用 z−n，代入后才得到正变换的负指数。若使用 WN，这些单位圆取样点应写成 z=WN−k，不是无条件写成 WNk。

关系｜与 DFS 相同的是一周期数据，不是所有命名都相同

把这 N 个时间样值每隔 N 重复，得到 x~(n)。原课件采用

X~(k)=∑n=0N−1x~(n)e−j2πkn/N,k∈Z,

作为 DFS 的一种归一化约定。因为取的是同一周期数据，在 k=0,…,N−1 内有

X~(k)=X(k).

若改用前面普通级数综合式中的系数 ak，则

ak=X~(k)N=X(k)N.

两者只是把因子 1/N 放在不同位置。回读课件时，要看它当前写的是 ak 还是 X~(k)，不能把两者的数值混用。

P6 的四格关系图表达的就是：左侧有限数组与其 DFT，右侧周期延拓后的时间序列与 DFS；从右边取一个代表周期回到左边。频谱数组延拓成 X~(k) 的“周期”在整数 k 上是 N，而 DTFT 在角度 ω 上的周期是 2π，两句话并不矛盾。

推导｜P11 的隐含周期性究竟是哪一层

正变换的表达式若允许 k 超出代表范围，则

X(k+N)=∑n=0N−1x(n)e−j2π(k+N)n/N=∑n=0N−1x(n)e−j2πkn/Ne−j2πn=X(k).

同样，把逆变换表达式延伸到所有整数 n，结果会每隔 N 重复。它恢复的是周期延拓后的 x~(n)；在 0 到 N−1 内与原数组相同，区间外不必与“补零的有限序列”相同。

所以做 DFT 并不证明实际采集信号必然周期重复；它说明所用有限复指数基带有这样的数学延拓结构。下一节的主值、圆周移位，正是用这层结构来定义。

原例｜四个 1，做不同点数的 DFT

原 P7–P10 都围绕 x(n)=R4(n)，也就是 n=0,1,2,3 处为1，其余为零。

P7 题目要求8点和16点 DFT，P8–P9分别展开，P10作并列图示。下面把两组完整复数系数都算出来，不只列幅度图。

在 N≥4 时，把原四个样值后面补零到 N 点，并没有改变区间外为零的那条序列。它的 DTFT 仍是

X(ejω)=∑n=03e−jωn=e−j3ω/2sin(2ω)sin(ω/2).

在 ω=2πℓ 处用原有限和取值4。不同点数的 DFT 只是选取不同的频率网格。

原例展开｜8点 DFT 的每个系数

频率为 ωk=πk/4。课件 P8 的式子整理为

X8(k)=e−j3πk/8sin(πk/2)sin(πk/8),k=1,…,7,

并单独有 X8(0)=4。这里额外下标8只为比较不同 DFT 点数，不是改变课件原定义。

先示范一个非零点的逐项加法。k=1 时，四项为

1,22−j22,−j,−22−j22,

所以 X8(1)=1−j(1+2)。k=3 的四项已在矩形DTFT单元算过，结果是 1−j(2−1)。其余位置代入同一有限和，得到完整数组：

k X8(k)
0 4
1 1−j(1+2)
2 0
3 1−j(2−1)
4 0
5 1+j(2−1)
6 0
7 1+j(1+2)

后半与前半按共轭配对，因为原数据为实数。这是对计算结果的检查，不意味着只需保留幅度就能完成一般逆变换。

原例展开｜16点 DFT 的完整结果与更密的网格

现在 ωk=πk/8。原 P9 给出

X16(k)=e−j3πk/16sin(πk/4)sin(πk/16),k=1,…,15,

另有 X16(0)=4。例如 k=1 时不跳步，仍从四项相加：

X16(1)=1+e−jπ/8+e−jπ/4+e−j3π/8.

实部是 1+cos(π/8)+cos(π/4)+cos(3π/8)，虚部是这三个正弦之和的负数，约为 3.013670−j2.013670。

可以立即做两项检查：实序列频谱应满足 X16(16−k)=X16*(k)；偶数位置应满足 X16(2k)=X8(k)，因为它们取的是同一个DTFT上的相同频率。

这就是 P10 中16点图比8点图更密的含义。补零让频谱曲线采得更密，没有新增原信号观测，也不凭空使两个原先因观测时长不足而难分开的频率变得可分辨。频率网格间隔与真实分辨能力要分开。

原例｜单位脉冲为什么在每个 DFT 频点都是1

课件 P12–P13 给出 x(n)=δ(n)。对任意正整数 N，

X(k)=∑n=0N−1δ(n)WNkn=WN0=1,k=0,…,N−1.

因为只有 n=0 那一项留下，结果不随 k 变。因此有限 DFT 数组是 N 个1；如果再将系数按 N 延拓，它才成为所有整数频率编号上的常数序列。

反向检查也很重要：把 N 个1做 IDFT，

x(n)=1N∑k=0N−1WN−kn.

在代表范围 0≤n<N 内，整圈筛选使它只在 n=0 处为1，其余为0。若把 n 延到全部整数，得到的是每隔 N 重复的脉冲列，不是区间外补零的单个脉冲。这正是有限数组与周期延拓必须分开说的原因。

自测｜别把索引、延拓与点数混为一谈

  1. 对两点数组 [2,5]，求 DFT 并反变换回原数组。
  2. 在原 P5 的逆变换证明中，n,m,k 各扮演什么角色？为什么内层不能也直接用固定的 n 当求和索引？
  3. 用 WN 表示 Z 变换的单位圆采样位置时，应取 WNk 还是 WN−k？
  4. 对 R4 的16点DFT，k=6 对应8点DFT的哪个位置？写出精确系数。
  5. 把只有一个1的单位脉冲做N点DFT，再把逆变换公式用于 n=N，得到1是否说明原有限序列在 n=N 本来就为1？
答案｜每个判断都回到明确的作用域
  1. X(0)=2+5=7，X(1)=2−5=−3。逆变换为 x(0)=(7−3)/2=2、x(1)=(7+3)/2=5。
  2. n 是固定目标时间位置，m 是内层遍历样值的时间哑变量，k 是外层频点求和编号。两个时间角色若都写成同一个未区分的 n，就会把目标位置与正在扫描的变量混同；这不是允许的无损改名。
  3. 应取 WN−k=ej2πk/N。代入 z−n 后才得到 WNkn=e−j2πkn/N，与原正变换一致。
  4. 相同频率要求 6/16=3/8，所以对应8点的 k=3，系数是 1−j(2−1)。
  5. 不是。逆公式超出代表区间后按所用基周期延拓，n=N 与 n=0 等价，得到1。区间外为零的有限序列与这条周期延拓序列在区间外不是同一对象。
