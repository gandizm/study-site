对称性怎样减少计算：先分清偶与共轭偶

先学：能量守恒与两种卷积定理

学完能做什么

  • 分清一般复序列共轭对称与实序列奇偶
  • 完整推导两组实虚/共轭对称交叉对应并保留原记号
  • 由实因果条件恢复序列，知道仅虚部还缺原点

目标｜不把四种分解背成一团

课件 2.1 P23–P31 连续使用 xe,xo,xr,xi,XR,XI,Xe,Xo，初看容易觉得只是大小写在来回变化。其实它分成两个方向：

  • 时间上分成“共轭对称、共轭反对称”，频率上就分成“实部、带 j 的虚部”。
  • 时间上分成“实部、带 j 的虚部”，频率上就分成“共轭对称、共轭反对称”。

本节先解释每一种拆法，再证明这两条对应。最后用实因果序列说明：为什么有时知道频谱实部，就能恢复整条序列；而只知道虚部，还少一个原点值。

记号｜同一个下标 e，不保证指同一个对象

沿用原课件，但把角色逐个写清：

记号 本节的实际含义
xr(n),xi(n) 时间序列的实部与虚部，二者本身都是实数值序列
xe(n),xo(n) 时间序列的共轭对称部分、共轭反对称部分，通常可以是复数
XR(ejω),XI(ejω) 频谱的实部与虚部，二者都是实数值函数
Xe(ejω),Xo(ejω) 频谱关于 ω 的共轭对称部分、共轭反对称部分

因此原课件的两种写法分别是

x(n)=xe(n)+xo(n),X(ejω)=XR(ejω)+jXI(ejω),

以及

x(n)=xr(n)+jxi(n),X(ejω)=Xe(ejω)+Xo(ejω).

注意第一行频谱虚部前有 j；第二行 Xo 已经包含对应的整块贡献，不要再凭外形额外乘一次 j。

本节的 n 始终是整数时间位置，ω 是频率变量；右上角星号表示复共轭。所有普通 DTFT 推导先在有限长或绝对可和条件下进行。判断一个序列是否对称则纯属代数，不要求它先有普通函数意义下的 DTFT。

定义｜先翻转，再取共轭

普通偶序列满足 x(n)=x(−n)，普通奇序列满足 x(n)=−x(−n)。如果样值可能是复数，课件还要考虑另一种比较：把对面位置取来的样值再取共轭。

共轭对称：

x(n)=x*(−n).

共轭反对称：

x(n)=−x*(−n).

例如对面位置的样值是 2−3j，取共轭后是 2+3j。所以两边不一定是同一个复数，不能把“共轭对称”简化为“左右样值完全一样”。

只有当序列本来就是实数值时，取共轭才不改变样值，这两种定义才分别退化为普通偶对称与奇对称。

推导｜为什么实部、虚部有不同奇偶性

写成 x(n)=a(n)+jb(n)，其中 a,b 都是实数值序列。

若共轭对称，则

a(n)+jb(n)=a(−n)−jb(−n).

比较实部与虚部，得到

a(n)=a(−n),b(n)=−b(−n).

因此实部是偶的，虚部是奇的。在 n=0 处，虚部必须为零，所以共轭对称序列的原点样值一定是实数。

若共轭反对称，则

a(n)+jb(n)=−a(−n)+jb(−n),

所以实部是奇的，虚部是偶的。此时原点的实部为零，但虚部可以非零：例如 x(0)=j 并不违反共轭反对称。不要把普通实奇序列“原点必为零”的结论直接套到复序列上。

原例｜复指数为什么是共轭对称，而不是普通偶序列

课件 P24 给出 x(n)=ejωn。这一个例子中，ω 表示构造序列时选定的固定频率，不是同时正在扫描的另一条 DTFT 横轴。为把两种角色暂时分开，我们先辅助写成 ω0：

x(n)=ejω0n.

先翻转，再取共轭：

x*(−n)=(e−jω0n)*=ejω0n=x(n),

其中 ω0 为实数。所以它是共轭对称序列。展开为

x(n)=cos(ω0n)+jsin(ω0n),

也能看见实部余弦是偶的、虚部正弦是奇的。

回到原课件，把固定参数 ω0 的名字还原为它使用的 ω，这就是原例的全部证明。一般情况下 ejωn 不等于 e−jωn，所以不能直接叫普通偶序列。

这个无限复指数通常不绝对可和。此处只是在验证代数对称性，没有把它的普通 DTFT 无条件当成收敛函数；周期线谱将在后续内容专门讨论。

推导｜任意复序列怎样拆成两块

课件 P25 的分解为

xe(n)=12[x(n)+x*(−n)],xo(n)=12[x(n)−x*(−n)].

两式相加，中间的共轭翻转项抵消，正好得到 x(n)。还要检查它们真的具有所要求的性质，而不是仅仅加起来正确。

对第一式翻转并取共轭：

xe*(−n)=12[x*(−n)+x(n)]=xe(n).

对第二式同样操作：

xo*(−n)=12[x*(−n)−x(n)]=−xo(n).

所以第一块确为共轭对称，第二块确为共轭反对称。这是“与对面共轭取平均”和“取一半差值”，并不是把负时间一律删掉。

例题｜三个复样值，完整拆成两块

以下是新编数例。只有 n=−1,0,1 处非零，原样值依次是

x(−1)=1+j,x(0)=2+j,x(1)=3+2j.

先列对面取共轭后的结果，再平均与相减：

n x(n) x*(−n) xe(n) xo(n)
−1 1+j 3−2j 2−j/2 −1+3j/2
0 2+j 2−j 2 j
1 3+2j 1−j 2+j/2 1+3j/2

例如 n=−1 时，平均为 [(1+j)+(3−2j)]/2=2−j/2；一半差为 [(1+j)−(3−2j)]/2=−1+3j/2。其他位置的样值全为零，因此两块在这些位置也为零。

检查三件事：每列 xe+xo 都回到原值；xe(−1)=xe*(1)；xo(−1)=−xo*(1)。原点的 xo(0)=j 也说明，共轭反对称并不要求原点样值一定为零。

推导｜先建立两个共轭变换关系

由定义取共轭可得

x*(n) ⟷ X*(e−jω).

为什么频率还要反向？因为

X*(e−jω)=[∑nx(n)ejωn]*=∑nx*(n)e−jωn.

再加上时间翻转，就有

x*(−n) ⟷ X*(ejω).

第二式也能令 m=−n 直接验证。这里只改变求和时间编号，ω 没变成时间变量。

所以三种操作要分开：单纯取共轭、单纯翻转、取共轭后再翻转。只记一个星号而忘记负频率，常会把题做错。

推导｜时间上的共轭对称，为什么对应频谱实部

对 xe 的定义逐项变换，利用上一段第二条关系：

DTFT[xe(n)]=12[X(ejω)+X*(ejω)]=ReX(ejω).

同样，

DTFT[xo(n)]=12[X(ejω)−X*(ejω)]=jImX(ejω).

这就是课件 P26–P27 的对应：

xe(n) ⟷ XR(ejω),xo(n) ⟷ jXI(ejω).

第二式右边不能漏 j。XI 是一个实数值函数，jXI 才是原频谱的整块纯虚贡献。

**对前面的数例实际验算。**原频谱是

X(ejω)=(1+j)ejω+(2+j)+(3+2j)e−jω.

展开正负指数后，实部与虚部分别为

XR(ejω)=2+4cosω+sinω,
XI(ejω)=1+3cosω−2sinω.

对表中的 xe 直接求和，得到

(2−j/2)ejω+2+(2+j/2)e−jω=2+4cosω+sinω,

确为实数。对 xo 直接求和，则得到 j(1+3cosω−2sinω)，确为纯虚数。注意实频谱不一定是偶函数：这个例子的实频谱里还有 sinω，因为 xe 是共轭对称而不一定是实偶序列。

推导｜反过来，时间上的实虚分解对应什么

课件 P28–P29 改用

xr(n)=x(n)+x*(n)2,jxi(n)=x(n)−x*(n)2.

这里取共轭时没有翻转时间，因此对应的频率形式要有 −ω：

DTFT[xr(n)]=12[X(ejω)+X*(e−jω)]=Xe(ejω),
DTFT[jxi(n)]=12[X(ejω)−X*(e−jω)]=Xo(ejω).

第一块满足 Xe(ejω)=Xe*(e−jω)，第二块满足 Xo(ejω)=−Xo*(e−jω)，所以它们分别是频域共轭对称、共轭反对称部分。

与上一段对照。xe 的变换是实部 XR；xr 的变换是共轭对称部分 Xe。两式的下标看似交叉，正因为它们讨论的是不同方向的分解，不是作者随意给同一对象换了名字。

特别是“时域实部的变换”通常不等于“频域的实部”。例如实序列 δ(n−1) 的频谱是 e−jω，它本身就是时间上的实部，但频谱一般不是实数。

结论｜实序列的频谱为什么只需知道半边

若 x(n) 本身是实序列，则 x*(n)=x(n)，由共轭关系得到

X(ejω)=X*(e−jω).

所以实部关于频率为偶函数、虚部为奇函数，幅度也是偶函数。非零频谱处的相位满足正负频率相反的关系，但应按模 2π 理解；在相位主值边界处，不宜不加说明地强求两个数值严格互为负数。频谱为零时相位不确定。

“只需知道半边”保留的是复数频谱信息，不是说只知道幅度就能恢复原序列。一般情况下，半边的幅度和相位都要知道，另一半才由共轭关系确定。

如果实序列还具有普通偶对称，则频谱是实偶函数；如果它是实奇序列，则频谱是纯虚奇函数。这里“实”的条件不能从句子中删掉。

原例扩写｜实因果序列为什么能从偶部分恢复

课件 P30–P31 的例子不是一个指定数字序列，而是一般实因果序列 h(n)：样值为实数，并且 n<0 时为零。

因为它是实序列，共轭对称分解变成普通奇偶分解：

he(n)=12[h(n)+h(−n)],ho(n)=12[h(n)−h(−n)].

分三类看，不能把原点与正时间混在一起：

  • n>0 时，h(−n)=0，所以 he(n)=ho(n)=h(n)/2。
  • n=0 时，he(0)=h(0)，而 ho(0)=0。
  • n<0 时，h(n)=0，所以 he(n)=h(−n)/2，ho(n)=−h(−n)/2。

课件为此定义了一个专门的权重序列

u+(n)={2,n>0,1,n=0,0,n<0.

它不是默认的普通单位阶跃 u(n)。下标加号也不是“取正值部分”的通用运算，这里要按课件给出的分段定义读。

因此

h(n)=he(n)u+(n),

而用奇部分恢复时，还需补回原点：

h(n)=ho(n)u+(n)+h(0)δ(n).

这两式都是逐点相乘，不是卷积。第一式在正时间乘2、原点乘1、负时间乘0；第二式的奇部分在原点本来就是零，因此无论怎么乘，都必须另外补上 h(0)。

例题｜用完整数字看见缺失的原点

取新编实因果序列

h(0)=2,h(1)=3,h(2)=1,

其他时刻为零。其奇偶分解为

n −2 −1 0 1 2
he(n) 1/2 3/2 2 3/2 1/2
ho(n) −1/2 −3/2 0 3/2 1/2

偶部分乘 u+ 后得到 0,0,2,3,1，正好恢复 h；奇部分乘后只有 0,0,0,3,1，还差 2δ(n)。

它的频谱为

H(ejω)=2+3e−jω+e−j2ω=(2+3cosω+cos2ω)−j(3sinω+sin2ω).

若只知道实部，反变换得到的是 he(n)，再利用实因果条件与 u+ 可以恢复整个 h(n)。若只知道虚部，先把它与 j 一起反变换得到 ho(n)，还需要额外知道 h(0)。

为什么后者不能自行猜原点？把 h(0) 改成任意另一个实数，只会给频谱加一个实常数，不改变其虚部。没有额外条件时，原点确实无法从虚部唯一确定。

回读｜一张不省略 j 和星号的对应表

时域对象 DTFT 对应对象
x*(n) X*(e−jω)
x*(−n) X*(ejω)
xe(n) ReX(ejω)=XR(ejω)
xo(n) jImX(ejω)=jXI(ejω)
xr(n) [X(ejω)+X*(e−jω)]/2=Xe(ejω)
jxi(n) [X(ejω)−X*(e−jω)]/2=Xo(ejω)

回到原 PPT 时，先检查它在拆时间还是频率，再检查拆的是实虚还是共轭对称。这样即使字母很像，也能按定义识别。

自测｜专门检查最容易被省略的条件

  1. 共轭反对称序列在 n=0 处一定为零吗？给一个最小反例。
  2. 若 x(n)=δ(n−1)，写出 xe(n),xo(n)，再给它们的 DTFT。
  3. “时域实部的 DTFT 就是频域实部”是否正确？用第2题检验。
  4. 已知某实因果序列的频谱实部为 3+2cosω，恢复该序列。
  5. 若只知道某实因果序列的频谱虚部是 −2sinω，能否唯一确定原点样值？请写出全部可能序列中的一族。
答案｜回到分解公式，而不是猜下标
  1. 不一定。只有它的实部必须为零，虚部可以非零。x(n)=jδ(n) 满足 x(n)=−x*(−n)，原点为 j。
  2. xe(n)=[δ(n−1)+δ(n+1)]/2，xo(n)=[δ(n−1)−δ(n+1)]/2。它们分别变换为 cosω 与 −jsinω，相加得到原频谱 e−jω。
  3. 不正确。原序列本来就是实的，所以它的时域实部仍是自己，DTFT为整个 e−jω；而频谱的实部只是 cosω，两者一般不同。
  4. 先反变换得到偶部分 he(n)=3δ(n)+δ(n−1)+δ(n+1)。利用实因果条件，正时间样值乘2、原点不加倍、负时间置零，得到 h(n)=3δ(n)+2δ(n−1)。直接变换为 3+2e−jω，实部确为所给式。
  5. 不能。h(n)=cδ(n)+2δ(n−1)，其中 c 为任意实常数，都有频谱虚部 −2sinω。缺失的是原点样值 h(0)=c，需要另给信息。
