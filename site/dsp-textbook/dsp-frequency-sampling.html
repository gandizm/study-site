频率只取 N 个点，时域会发生什么

先学：四个采样值看频率

学完能做什么

  • 推导频率采样导致的时域周期叠加
  • 准确使用N≥M及支持区间条件
  • 用有限核重构DTFT并分清无限长近似

目标｜理解有限个频谱值何时够用

原 PPT 2.4 的问题是：DTFT 是一整条连续的频率曲线，只取其中 N 个等间距的点，还能恢复原序列吗？这一节先说明采样后真正得到什么，再解释 N≥M 的条件，最后补上如何由这些点恢复整条频谱。

学完后，你应能看着原书的 xN(n)、X(k) 和 RN(n)，说出各自是什么，而不只是背“采样点数要大于序列长度”。

记号｜这里的 X(k) 从连续曲线上取出来

保留原书写法：x(n) 是离散时间序列，X(ejω) 是其 DTFT。n 是整数时间位置，ω 是连续的数字角频率，单位为 rad/sample。

X(ejω)=∑n=−∞∞x(n)e−jωn.

在本节，N 是频域采样点数，M 是原有限序列的长度。取

ωk=2πkN,X(k)=X(ejωk),k=0,…,N−1.

符号角色变化在这里： X(ejω) 的自变量是连续频率，X(k) 的自变量是整数采样点编号。k 不能直接当成角频率，二者通过 ωk=2πk/N 相连。

P3 先从 Z 变换 X(z)=∑nx(n)z−n 出发，然后令 z=ej2πk/N。原因是：单位圆上的 z=ejω 代入后，z−n=e−jωn，得到同一个 DTFT。你暂时不会一般 Z 变换也能完成本节。

以下对有限序列当然成立。对无限序列，先假设绝对可和 ∑n|x(n)|<∞，这样 DTFT 及后续交换有限频率和、时间和都可靠。仅口头说“有傅里叶变换”不应自动替代这些收敛条件。

定义｜IDFT 恢复的是 x_N(n)，先别叫它原信号

原书把这 N 个频率值送进 N 点 IDFT，结果叫 xN(n)：

xN(n)=1N∑k=0N−1X(k)ej2πkn/N,0≤n<N.

下标 N 记录“用了多少个采样点”。这个名字是在提醒：还没证明它等于 x(n)。输出 n 固定，式中的 k 逐个走过频率格点；求完以后 k 消失。

推导｜为什么相隔 N 的时域样本会叠在一起

把 DTFT 采样表达式代入 IDFT。因为外面已用 n 表示当前输出位置，里面原来 DTFT 求和的时间变量改名为 m：

X(k)=∑m=−∞∞x(m)e−j2πkm/N.

这是合法的哑变量换名。它不表示“原信号变成 x(m) 后时间含义变了”，只是避免把当前输出位置和所有输入位置混用。

xN(n)=∑m=−∞∞x(m)[1N∑k=0N−1ej2πk(n−m)/N].

方括号是一道筛选：当 m−n 是 N 的整数倍时，指数每项都等于1，平均后为1；否则，令 ρ=ej2π(n−m)/N，有 ρ≠1 而 ρN=1，故

∑k=0N−1ρk=1−ρN1−ρ=0.

只有 m=n+rN 留下，其中 r 必须是整数。原 PPT P4 这里写“r 为实数”不合筛选条件；例如 m−n=1,N=4 时当然不能因为 r=1/4 而判成保留。

因此，原书的核心结果是

xN(n)=∑r=−∞∞x(n+rN),0≤n<N.

若把 xN 看成一段之外为零的有限序列，原书还会写

xN(n)=[∑r=−∞∞x(n+rN)]RN(n),

其中 RN(n) 在 0,…,N−1 为1，其他地方为0。r 是副本编号，n 是输出时刻，k 是已求和掉的频率编号。

解释｜频域离散对应时域周期叠加

想象把所有时域下标按“除以 N 的余数”放进 N 个盒子：0,N,2N,… 放在第0盒，1,N+1,2N+1,… 放在第1盒。盒里所有数相加，就是 IDFT 的结果。

频率采样没有命令算法“删掉第 N 点以后所有样本”，而是使它们与前面的样本无法区分。周期平移的所有副本都会参加叠加。P9 的“周期个数等于 N”应读作平移/重复间隔为 N 个样本，不是只有 N 份副本。

这与时域采样产生频域周期重复形成对照，但两个采样条件不同：时域采样要控制频谱混叠，频域采样要控制时域折叠。不能把“fs>2fmax”直接换成这里的 N≥M，而不解释采样的是哪一个域。

定理｜有限长序列为什么能精确恢复

设已知 x(n) 只在 0≤n<M 内可能非零。只要 N≥M，这 M 个位置进入不同的余数盒子，其他副本不会叠在它们上面，因此

xN(n)=x(n),0≤n<N,

右边包含必要的尾部零。此时采到的 X(k) 就是补零到 N 点后序列的 DFT。

N≥M 是对这一整类未知长度 M 数组都能保证恢复的条件。若 N<M，一般不能唯一恢复；比如把某个数从位置0搬到位置 N，这些频率样本察觉不到。对于已知特殊结构的信号，可能用额外先验恢复，但那不是本定理的普通 IDFT 结论。

还要知道非零区间的位置：若信号位于其他已知连续区间，可先移位或按正确索引解读。只看一段主值不能判断信号是否整体平移了 N 个样本，这同样来自周期性。

例题｜原 PPT 的五点矩形序列

P8–10 给出五个连续等高的样本。以下把高度取为1来算清楚，即 x(n)=1（n=0,1,2,3,4），其他位置为0。其 DTFT 为

X(ejω)=1+e−jω+e−j2ω+e−j3ω+e−j4ω.

先取 N=5。在 ωk=2πk/5 采样，k=0 时是5，其余四点为0，所以采样值是 {5,0,0,0,0}。IDFT 在每个 n 给出 5/5=1，恢复出五个1，正对应原图的无混叠情况。

再取 N=4。第4个下标与第0个下标进入同一个盒子，故

x4(n)={2,1,1,1}.

也可以从频域验证：采样点为 0,π/2,π,3π/2，得到 X(k)={5,1,1,1}。IDFT 恢复的是四点数组 {2,1,1,1}，不能凭这四个频率值知道第0盒的2究竟来自两个1，还是本来就有一个2。

看原图时的学习目的： 红色原信号与平移副本在哪些时刻叠到一起，蓝色主值为什么变高。不是对比曲线画得漂不漂亮。

推导｜已有 N 个频谱值，如何补回整条曲线

这是对原P2“内插公式是什么”的补充展开。假设 x(n) 支持在 0,…,N−1，先由 IDFT 恢复它，再代入 DTFT：

X(ejω)=1N∑k=0N−1X(k)∑n=0N−1e−j(ω−2πk/N)n.

新定义有限和核

DN(θ)=∑n=0N−1e−jθn=e−jθ(N−1)/2sin(Nθ/2)sin(θ/2).

分式分母为零时用原有限和或连续极限解释，θ=2πr 时为 N，不能直接做 0/0。

于是

X(ejω)=1N∑k=0N−1X(k)DN(ω−2πk/N).

把 ω 放回任一采样点，只有相应的核留下 N，正好还原该 X(k)。所以这不是随手连直线的近似插值，而是利用“时域只有 N 点”这一已知条件的精确重构。条件不满足时，公式重构的是折叠后那段 xN 的频谱，不会自动找回丢失的时域区别。

例题｜无限长序列为什么通常只能近似

对应 P7 的无限长情形，补充一个可算清的例子。设 x(n)=an（n≥0），n<0 时为0，且 0<a<1。对 0≤n<N，

xN(n)=an+an+N+an+2N+⋯=an1−aN.

原值是 an，多出来的是 an+N/(1−aN)。例如 a=1/2,N=4，x4(0)=16/15，仍不是原来的1。加大 N 会让尾部更小，但有限 N 不会把这条无穷尾巴变没。

“更多频率采样点可减小误差”在这里成立，是因为尾部确实快速衰减。对于一般不衰减或不满足上述收敛条件的序列，不能不加条件地沿用这个结论。

回读时按三个问题核对：X(k) 采自哪一条曲线？IDFT 的 xN(n) 叠加了哪些位置？已知支持区间是否足以排除叠加？

自测｜判断条件比背结论更重要

  1. 长5的未知数组只取4个频率样本，为什么一般不能唯一恢复？
  2. P4 的 m=n+rN 中，r 应是什么类型的数？为什么？
  3. 长5的序列补零后取8点DFT，是否产生新的时域信息？是否仍能恢复原五点？
  4. 若序列 {1,1,1,1,1} 取 N=3 个DTFT样本，IDFT结果是什么？
  5. 重构整条DTFT曲线时，为什么不能无条件用上述有限核公式恢复任意无限序列？
答案｜把符号变成人话
  1. 下标相差4的样本叠在一起，采样值只知道它们的和，不能一般地区分各项。
  2. 整数；根单位有限和筛选的是差值为 N 的整数倍，实数倍条件会错误地放行所有整数差值。
  3. 没有创造新样本信息，仍能精确恢复原五点和尾部三个零；它给同一DTFT更密的频率采样。
  4. 下标0与3相加，下标1与4相加，得到 {2,2,1}。
  5. 推导用了时域仅在一段N点内有值的条件；无限序列的不同周期副本通常已经混在样本中。
