线性卷积和圆周卷积如何区分

先学：主值、周期延拓与圆周移位

学完能做什么

  • 从支持区间与取模定义分清线性和圆周卷积
  • 证明折回相加并完成原课堂作业五问
  • 解原例2.3.10，明确哪些结果不能唯一确定

目标｜把课件课堂作业五问都算完

线性卷积允许输出变长；N 点圆周卷积则只保留 N 个位置，把越过边界的贡献绕回相加。它们并不是两个毫不相干的算法，也不是“只要用DFT就自动算出了线性卷积”。

本节对应原2.3 P20–P25。我们先解释定义与操作，再完整计算 P24 的 [1,2,2,1] 自卷积五问，最后做原P25引用的教材例2.3.10。该原例已按第三版印刷P75–P76核对；课件标注的旧书页P68不适用于这一版。

记号｜长度和本次圆周点数要分开

  • x1(n),x2(n)：区间外为零的有限序列，分别支持在 0≤n<L、0≤n<M。课件将这两个长度写作 N1,N2，这里辅助用 L,M 以免和本次DFT点数混淆。
  • N：本次圆周卷积的长度，先要求 N≥max(L,M)，把两输入补零到 N 点。
  • yl(n)：线性卷积结果，下标 l 提醒它是线性结果。
  • yN(n)：本次 N 点圆周卷积结果，只列 0≤n<N。
  • n：固定的输出位置；m：求和时遍历的时间位置。
  • x((r))N：按照 N 周期读取原数组下标 r，不是把样值的幅度取模。

原课件用 * 表示线性卷积，用 ⊗ 表示圆周卷积。不同资料可能换符号，但是否按模 N 取下标，才是决定性差别。

定义｜线性卷积最多占多少个输出位置

按课件 P21，

yl(n)=x1(n)*x2(n)=∑m=−∞∞x1(m)x2(n−m).

有非零贡献时，两个输入位置之和必须等于 n。最早可能的位置是 0+0=0，最晚是 (L−1)+(M−1)=L+M−2，所以最多占

L+M−1=N1+N2−1

个位置。这里说的是可能非零的范围，不保证中间每个样值都非零；端点取零或不同项抵消时，实际非零数可以更少。

线性卷积中，某个下标落在输入支持区间外就读到零，不把它绕回数组开头。

定义｜圆周卷积把下标折回所选周期

课件 P22 在把两输入补成同样的 N 点后，写成

yN(n)=x1(n)⊗x2(n)=∑m=0N−1x1(m)x2((n−m))N,0≤n<N.

辅助写法就是

yN[n]=∑m=0N−1x1[m]x2[(n−m)modN].

固定 n 后，让 m 依次跑0到 N−1，每次读取第二条数组的模 N 下标。交换两输入不会改变结果，这是卷积的交换性；并不意味着可以删去反转或移位。

在代表区间外，若继续使用同一周期定义，结果也会周期重复。但题目要求的 N 点数组通常只列0到 N−1，不是无限长输出表。

方法｜把 P23 的反转、移位、乘、加逐步说清

课件流程图可按下面做：

  1. 两输入先补零到指定 N 点。
  2. 将第二条数组按 N 周期延拓。
  3. 相对整数下标反转，形成 x2((−m))N。
  4. 为了求第 n 个输出，将这条反转后的序列移动，得到 x2((n−m))N。
  5. 它与 x1(m) 在每个 m 位置相乘，再把这一周期的 N 个乘积相加。
  6. 换下一个输出位置 n，重复上述读取与相加。

注意第4步的 n 是本次固定的输出位置，而第5步的 m 才是正在扫描的求和位置。不要把流程图里“移动几格”和“在哪一格相乘”混成一个没有区分的字母。

推导｜圆周结果等于线性结果每隔 N 折回相加

第二条输入的周期取值可以写成

x2((n−m))N=∑r=−∞∞x2(n−m+rN).

r 是周期副本编号，不是频率。代入圆周卷积定义：

yN(n)=∑m=0N−1x1(m)∑rx2(n−m+rN)=∑r∑m=0N−1x1(m)x2(n+rN−m).

由于 x1 在代表区间外为零，内部和就是线性卷积 yl(n+rN)。因此

yN(n)=∑r=−∞∞yl(n+rN),0≤n<N.

对于从0开始的有限序列，通常就是 yl(n)+yl(n+N)+yl(n+2N)+⋯，范围外的项为零。这叫绕回相加或时域混叠，不是单纯把尾部删掉。

若选

N≥L+M−1,

线性结果已经完全装得进一个周期，不同副本不会在代表区间重叠，所以圆周卷积与线性卷积在所需位置一致，多余位置为零。这是保证一般有限长输入不绕回的充分长度条件。某些特殊输入可以因零值或抵消更早一致，但不能把偶然情况当作通用保证。

原课堂作业｜先把七个线性结果逐项算出来

课件 P24 原图从 n=0 起的样值是

x(n)=[1,2,2,1],

其余位置为零。先求 yl=x*x。最多有 4+4−1=7 个输出位置，全部如下：

yl(0)=1·1=1,
yl(1)=1·2+2·1=4,
yl(2)=1·2+2·2+2·1=8,
yl(3)=1·1+2·2+2·2+1·1=10,
yl(4)=2·1+2·2+1·2=8,
yl(5)=2·1+1·2=4,yl(6)=1·1=1.

所以第一问完整结果为

yl=[1,4,8,10,8,4,1].

支持区间外全为零。这里卷积的是这条序列与自身，不是逐点平方；逐点平方会是 [1,4,4,1]，明显不是同一运算。

原课堂作业｜4点圆周卷积，尾部不是被丢掉

第二问不加长，取 N=4。用折回关系：

y4(0)=yl(0)+yl(4)=1+8=9,
y4(1)=yl(1)+yl(5)=4+4=8,
y4(2)=yl(2)+yl(6)=8+1=9,y4(3)=yl(3)=10.

所以

y4=[9,8,9,10].

再用原圆周定义独立核对所有四个位置：

  • n=0：1·1+2·1+2·2+1·2=9。
  • n=1：1·2+2·1+2·1+1·2=8。
  • n=2：1·2+2·2+2·1+1·1=9。
  • n=3：1·1+2·2+2·2+1·1=10。

两种算法一致，说明我们确实在“加回尾部”，而不是把七点线性结果截成前四点 [1,4,8,10]。

原课堂作业｜6、7、8点为什么分别不同

第三问：N=6。两输入先补成 [1,2,2,1,0,0]。七点线性结果中，只有第6个位置会绕回0：

y6=[1+1,4,8,10,8,4]=[2,4,8,10,8,4].

这仍然没有完整保存七个线性输出，因为周期长度6还不够。

第四问：N=7。线性结果刚好装得下，没有绕回重叠：

y7=[1,4,8,10,8,4,1].

第五问：N=8。线性结果完整保留，最后多一个零：

y8=[1,4,8,10,8,4,1,0].

到这里原课堂作业的五问已全部完成。不是“补零越多越接近”才慢慢变准：在一般保证条件 N≥7 达到之后，这道题的线性结果已经精确装入，继续补零只增加额外零位置与相应频域计算点数。

总和检查。输入样值之和为6，两输入卷积的结果总和应为 6·6=36。上面五组结果的样值总和都是36。这个检查不能代替逐项计算，但能发现很多漏项和错误截尾。

原例2.3.10｜由50点圆周结果，尽可能恢复59点线性结果

题目条件来自第三版印刷P75–P76，课件 P25 只引用例号。

已知 x(n) 在 0 到49以外为零，h(n) 在0到9以外为零。问线性卷积最多有多少个可能非零值；又已知它们的50点圆周卷积每个位置都等于12，而线性卷积的前五个值均等于5，要求尽可能多地确定线性输出。

第一问：先确定支持区间。

两个长度分别为50与10，线性卷积最多有

50+10−1=59

个可能非零位置，即 0≤n≤58。

第二问：把每个圆周位置对应哪些线性位置列清楚。

对 0≤n≤49，折回关系只有

y50(n)=yl(n)+yl(n+50)=12,

因为再往后的 n+100 已经超过58，负方向副本也在支持区间之外。

  • 当 9≤n≤49 时，n+50≥59，尾项为零。因此 yl(n)=12，一共41个值被直接确定。
  • 当 0≤n≤4 时，题目给 yl(n)=5，所以 yl(n+50)=12−5=7。这确定了位置50到54的五个值。
  • 当 5≤n≤8 时，只知道 yl(n)+yl(n+50)=12。题目没有再给其中一项，不能擅自把两项各填成6，也不能把前面的5或后面的7机械延伸过来。

整理得到

yl(n)={5,0≤n≤4,12,9≤n≤49,7,50≤n≤54,0,n<0 或 n>58.

尚未分别确定的是 n=5,6,7,8 与 n=55,56,57,58，只保留四条配对约束

yl(5)+yl(55)=12,yl(6)+yl(56)=12,
yl(7)+yl(57)=12,yl(8)+yl(58)=12.

在59个可能非零位置中，已单独确定51个，另外8个只能确定配对之和。这道题的学习目标不是再做一次大卷积，而是看出圆周结果合并了哪些不同的时间位置。

条件回读｜原对照表中的系统输出，要补上时不变与零状态

P25 将线性卷积与“信号通过线性系统”的输出联系起来。这里应明确按线性时不变系统（LTI）的零状态响应理解：系统对一个平移后的单位冲激，产生同样平移的冲激响应，才能把输入的各个样值贡献相加成 y(n)=x(n)*h(n)。仅有线性、没有时不变性，不能保证用一条固定的 h(n) 这样计算全部输出。

“零状态”表示不另带初始储能或初始状态引起的响应。若还有额外的初始响应，卷积给出的是输入所产生的这一部分，不能不加区分地称为全部输出。这是在回读原表时补足适用条件，不改变上面的卷积数例。

关系｜以后用DFT算卷积，先决定你要哪一种结果

下一节将证明：两份 N 点DFT逐点相乘再做IDFT，得到的是 N 点圆周卷积。若目标是线性卷积，必须先把输入补零到足以容纳线性结果的长度，通常选 N≥L+M−1。

所以流程应是：先由问题确定线性还是圆周，再选长度，再决定计算方法。不能因为用了FFT，就认为边界问题已经自动解决；FFT只是计算DFT的一种算法，不会替你改变所选的数学运算。

后半关于DFT卷积应用的单元会继续用完整例子与分段方法说明工程实现，本节先把原课堂题与折回关系理解透。

自测｜判断混叠落在哪些位置

  1. 两输入长度分别为3和4，若要保证一般情况下用圆周卷积得到完整线性卷积，N 至少选多少？
  2. 若某线性卷积结果是 [1,2,3,4,5,6]，作4点折回后是什么？不能只取前四项。
  3. 为什么 N=max(L,M) 足以容纳两个输入，却不一定足以容纳线性输出？
  4. 在原50点例中，yl(8) 能否直接判为12？为什么位置9却可以？
  5. 圆周卷积中 x2((n−m))N 的取模作用于谁？若 n−m=−1，是否应把读到的样值幅度取负？
答案｜检查支持范围与实际取值规则
  1. 至少 3+4−1=6 点。此时一般线性输出的位置0到5都能装入一个周期。
  2. 位置4折到0，位置5折到1，所以为 [1+5,2+6,3,4]=[6,8,3,4]。
  3. 输入各只占自己的长度，而线性输出的位置由两个输入位置相加得到，通常延长到 L+M−2。容纳输入和容纳输出是两个不同要求。
  4. 不能，因为 8+50=58 仍在可能非零的尾部范围内，只知 yl(8)+yl(58)=12。位置9的尾部伙伴是59，已经在范围外为零，所以 yl(9)=12。
  5. 取模作用于整数下标，不作用于幅度。若下标为 −1，应读取原数组的 N−1 位置，不因负下标额外给样值加一个负号。
