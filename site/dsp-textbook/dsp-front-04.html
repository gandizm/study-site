DTFT正逆变换的完整算例：一串连续的1

先学：DTFT：从序列到连续的数字频谱

学完能做什么

  • 从等比数列推导矩形序列DTFT而非背公式
  • 正确处理0/0、真正零点及相位跳跃
  • 完整逆变换并区分有限序列与周期延拓

目标｜看懂课件的分式，也看懂幅度图上的零点

课件 2.1 P8–P9 用矩形序列作为第一个 DTFT 例题。它看起来只是“一串 1”，却能一次讲清有限求和、频谱零点、幅度与相位，以及为什么公式里的 0/0 不一定表示频谱不存在。

读完本节，你应能自己画出四个 1 的频谱骨架：零频率处是 4，哪些地方降为 0，为什么相位会跳，而不是把整张图硬记下来。

本节主例确实来自原 PPT；随后用反变换把它还原、以及自测中的数字变式是补充讲解。原 P10 只给正逆变换公式和“计算举例”的提示，没有一份额外的数字题干，我们不把新编题冒充原例。

记号｜R 的下标是长度，括号里才是时间

原课件写 x(n)=RN(n)。这里约定

RN(n)={1,0≤n≤N−1,0,其他整数 n,N≥1.
  • n：时间样值编号，是整数。
  • N：这串 1 的个数，是固定的正整数，不参与本次求和。
  • ω：连续取值的数字角频率，单位弧度/样点。
  • q：下面推导等比数列时临时采用的公比，不是时间索引，也不是频点编号。
  • ℓ：后面列零点时用的整数编号，不是序列长度。

辅助方括号写法是 RN[n]，与原 RN(n) 同义。不要把 RN 理解为“第 N 个样值”：它是一整条序列的名字。

R4(n) 的四个 1 位于 n=0,1,2,3，而不是 n=1,2,3,4。起点差一个样值，会改变相位。

推导｜先从有限求和得到课件分式

从定义开始，不直接背结果：

X(ejω)=∑n=−∞∞RN(n)e−jωn=∑n=0N−1e−jωn.

因为区间之外 RN(n)=0，无限和变成有限和。现在暂记 q=e−jω，则

S=1+q+q2+⋯+qN−1.

把两边乘以 q：

qS=q+q2+⋯+qN−1+qN.

两式相减，中间项逐个消掉：

(1−q)S=1−qN.

只有在 q≠1 时才能除以 1−q。因此

X(ejω)=1−e−jNω1−e−jω,ω≠2πℓ,ℓ∈Z.

这里 Z 表示所有整数。若 ω=2πℓ，应回到有限和：每项都是 1，所以

X(ej2πℓ)=N.

分式的 0/0 只是这次除法失效，不是原来的有限和发散。把这些点的值补为 N 后，频谱仍是连续函数。

推导｜为什么会出现半角正弦和一个相位因子

课件 P8 把分式整理为正弦比值。关键不是另用一个变换公式，而是把指数拆成两半：

1−e−jNω=e−jNω/2(ejNω/2−e−jNω/2)=2je−jNω/2sin(Nω/2).

分母同理：

1−e−jω=2je−jω/2sin(ω/2).

相除时，2j 抵消，两个指数因子的指数相减，得到原课件式：

X(ejω)=e−jω(N−1)/2sin(Nω/2)sin(ω/2).

仍要保留刚才的特殊点说明：ω=2πℓ 时由原有限和取值 N，不是把两个正弦都当成零后停止。

看懂两部分各做什么：

  • e−jω(N−1)/2 长度恒为 1，记录相位随频率的变化。
  • 正弦之比是实数，但可以为正、为负或为零，所以它不仅影响幅度，也可能给相位增加一个 π。

因子里的 (N−1)/2 是 0 到 N−1 这段位置的中心。N 为偶数时，中心可以落在两个样点之间；这不意味着序列突然有了半整数时间样值。

结论｜幅度、零点与相位必须分开处理

因为单位复指数长度为 1，幅度是

|X(ejω)|=|sin(Nω/2)sin(ω/2)|.

在一个周期 0≤ω<2π 内，真正的零点为

ω=2πℓN,ℓ=1,2,…,N−1.

原因是这些位置分子为零、分母不为零。ℓ=0 对应 ω=0，分母也为零，原有限和的值是 N，不能算作零点。N=1 时上述列表为空，频谱就是常数 1。

相位不能不加条件地写成 −ω(N−1)/2。令实数比值为 D(ω)：

  • D(ω)>0：相位是 −ω(N−1)/2，允许加减整数倍 2π。
  • D(ω)<0：还须加一个 π，然后按所选范围整理。
  • D(ω)=0：复数为零，没有确定相位。

课件 P9 的相位曲线出现跳跃，正是这些符号变化和相位表示范围共同造成的；不能把相位跳跃误读成时域样值突然跳动。

例题｜N=4 的关键位置全部算出来

原课件取 N=4，于是

X(ejω)=1+e−jω+e−j2ω+e−j3ω=e−j3ω/2sin(2ω)sin(ω/2).

先用有限和检查几个位置，避免被分式特殊点骗到。

零频率 ω=0。

X(ej0)=1+1+1+1=4.

幅度为 4，相位为 0。

ω=π/2。

X(ejπ/2)=1−j−1+j=0.

幅度为 0，相位不确定。

ω=π。

X(ejπ)=1−1+1−1=0.

ω=3π/2。

X(ej3π/2)=1+j−1−j=0.

ω=2π。

X(ej2π)=1+1+1+1=4.

这五个位置已经给出一个周期的基本骨架：从 4 开始，中途三次到零，最后又回到 4。中间不只是直线连接，因为每项的方向随 ω 连续旋转。

再算两个不在这四个等间隔频点上的位置。

**ω=π/3。**四项分别为

1,12−j32,−12−j32,−1.

实部 1+1/2−1/2−1=0；虚部 −3/2−3/2=−3。所以

X(ejπ/3)=−j3,|X|=3,argX=−π/2.

用正弦比值复核：e−jπ/2=−j，sin(2π/3)/sin(π/6)=3，结果一致。

**ω=3π/4。**四项分别为

1,−22−j22,j,22−j22.

所以

X(ej3π/4)=1+j(1−2).

幅度为

1+(1−2)2=4−22.

它的实部为正、虚部为负，所以相位在第四象限。用正弦因子看得更直接：sin(3π/2)<0，需要给基准相位 −9π/8 加 π，得到 −π/8。若只机械写 −3ω/2，这里就错了。

回读｜怎样把课件相位折线拆成可检查的小段

选取一个完整频率周期 −π<ω<π，并用主值范围 (−π,π] 表示相位。对 R4(n)，在非零频谱位置可写为

argX(ejω)={−3ω/2−π,−π<ω<−π/2,−3ω/2,−π/2<ω<π/2,−3ω/2+π,π/2<ω<π.

这不是新增一种变换，而是把上一段“正弦比值正负”落实成分段答案。

中间区间包含 ω=0，此时相位为 0。在 ω=±π/2 以及边界 ±π，频谱为零，不给它硬填一个相位。换成课件图中延伸到 2π 的坐标时，只是沿周期继续画，并按相位范围加减 2π。

如果暂时不想记三段式，至少会做两个检查：先找零点，再在每段取一个测试频率判断正弦比值正负。这样可以自己重建相位图，不必死背跳跃位置。

例题｜用反变换把矩形序列完整恢复

这里是围绕原例补写的完整逆变换。先保留频谱的有限和形式，并把里面的时间求和变量改名为 r：

X(ejω)=∑r=0N−1e−jωr.

为什么换名？因为接下来外面的 n 要表示我们想恢复的目标时刻，不能同时让它在内层从 0 跑到 N−1。r 是原先时间求和索引 n 的替身，不是新的频率变量。

代入 IDTFT：

x(n)=12π∫−ππ[∑r=0N−1e−jωr]ejωndω=∑r=0N−112π∫−ππejω(n−r)dω.

这是有限项求和，可以逐项积分。上一节的整圈筛选规则给出

x(n)=∑r=0N−1δ(n−r).

现在完整判断输出，不省略区间之外：

  • 若 n 是 0,1,…,N−1 中的一个整数，求和中恰有一项 r=n，得到 1。
  • 若 n<0 或 n≥N，没有任何 r 等于这个 n，所有项为零。

所以正好恢复 RN(n)。这是有限长、区间外为零的序列，不是每隔 N 重复一次的周期序列；仅仅做 DTFT 和 IDTFT，并不会自动把它周期延拓。

对比｜四点 DFT 只有一个非零值，为什么 DTFT 还有其他波瓣

对四个 1 做四点 DFT，第一节的规则选择

ωk=2πk4,k=0,1,2,3.

它们就是刚才算过的 0,π/2,π,3π/2，因此

X[k]=[4,0,0,0].

这不表示 DTFT 在其余频率处全为零。比如我们已实际算出 ω=π/3 时为 −j3。DFT 在此只报告四个规定位置，不能把“没有在这里列值”误读成“这里值为零”。

也不要把这四个数直接叫作周期序列的普通傅里叶级数系数 ak。若将四个 1 周期延拓，成为恒为 1 的周期序列，在常用综合式约定下它的直流系数为 a0=4/4=1。有限数据、选定的频点、周期延拓及系数归一化是四件需要明确连接的事。

自测｜不查结论，先写出有限和

  1. R3(n) 的 DTFT 在 ω=0 和 ω=π 分别是多少？在 0≤ω<2π 内有哪些零点？
  2. 把 R4(n) 的四个 1 改放在 n=1,2,3,4，频谱与原来相比怎样变化？幅度是否改变？
  3. 有人把 R4(n) 在 ω=2π 处判成零，理由是 sin(2ω)=0。他漏了哪一步？
  4. 在 ω=3π/4 处，只写相位 −9π/8 是否正确？写出正确主值相位。
  5. 写 x(n)=∑r=03δ(n−r) 时，n 和 r 各是什么角色？n=5 时得到多少？
答案｜每个结果都能从原来的样值检查
  1. X(ejω)=1+e−jω+e−j2ω。零频率处为 3；ω=π 时为 1−1+1=1。一个频率周期内零点是 2π/3 和 4π/3，不是 π。
  2. 新频谱为 e−jω+e−j2ω+e−j3ω+e−j4ω=e−jωX(ejω)。新增因子的长度为 1，所以幅度不变；非零频谱处的相位额外减去 ω，再按需要加减 2π。这为下一节时移性质作铺垫。
  3. 同时还要看分母。此时 sin(ω/2) 也为零，不能只看分子。回到有限和，每项 e−j2πn=1，总和为 4。
  4. 不正确，因为正弦比值是负数，必须计入负号的相位。−9π/8+π=−π/8，与复数 1+j(1−2) 位于第四象限相符。
  5. n 是固定要检查的输出时刻，r 是依次跑过 0、1、2、3 的时间求和哑变量。n=5 时没有 r=5 这一项，四个脉冲全为零，结果为 0；不能把 r 自动取模折回去。
