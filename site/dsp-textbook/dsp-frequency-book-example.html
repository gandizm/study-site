先学：频率取N点，时域发生什么

  • 按原题推导指数周期折叠
  • 核原参数N10/40误差

目标｜把频域采样定理读回原题

原 PPT 2.4 P11 只写了“例2.4.2（P79）”。实际核对方勇《数字信号处理——原理与实践》第3版后，这个例子在印刷页86–87，对应PDF物理页103–104。PPT写的79不是这份第3版的实际题页，不能直接按79跳转。

这一节按已核原题的信号与参数慢解，不拿另一道新编题冒充原例。学习目的很具体：分清主值与周期延拓，算出混叠误差，并解释书中为何比较 N=10 与 N=40。

记号｜无限长原序列与有限长主值各指谁

原例给定

x(n)=anu(n),0<a<1.

u(n) 是单位阶跃：n≥0 时为1，n<0 时为0。因此 x(n) 从0开始向右无限延伸，虽然越来越小，仍是无限长。原书题干已明确写“无限长序列”；后面要求的“有限长序列 xN(n)”指 IDFT 选取的主值，而不是在说原 x(n) 有限。两个函数名字相似，但长度角色不同，应在这里分清。

N 是单位圆上采样的频率点数，不是原序列的长度。不能给这条无穷尾巴硬指定一个 M，再机械套 N≥M。

推导｜先从原式读出采样值

由等比求和，

X(z)=∑n=0∞anz−n=11−az−1,|z|>a.

因为 a<1，单位圆在收敛域内。保留原书的 WN=e−j2π/N，采样位置写作

z=WN−k=ej2πk/N,k=0,…,N−1.

这里的负号很容易看反： WN 本身已经带负指数，WN−k 才对应单位圆上正角度的位置；把它代进 z−1，会得到 WNk。因此

X(k)=11−aWNk.

k 是采样点编号，n 是原序列时间位置，这两者没有互换。

推导｜用时域周期叠加求 IDFT

沿频域采样定理，原书写

xN(n)=[∑r=−∞∞x(n+rN)]RN(n).

RN(n) 只保留 0≤n<N。先把 n 固定在这个范围；r 是整数副本编号。由于 u(n+rN)：

  • r≥0 时，n+rN≥0，该项保留。
  • r<0 时，n+rN≤n−N<0，该项为0。

所以无穷双边求和缩成单边等比和：

xN(n)=an∑r=0∞(aN)rRN(n)=an1−aNRN(n).

等比比值是 aN，不是 a。因为相邻被折回的样本在原序列里相隔 N 个位置。

例题｜按原书参数 a=0.8 算出误差

在主值区间内，原值 x(n)=an，恢复值比它多

xN(n)−x(n)=anaN1−aN.

因为本例每个 an>0，相对误差为

xN(n)−x(n)x(n)=aN1−aN,0≤n<N.

它在这段内与 n 无关；绝对误差仍随 an 下降。

原书设置 aN 恢复的首点 xN(0) 主值内相对误差
a=0.8,N=10 0.1073741824 约 1.12029025 约 12.0290%
a=0.8,N=40 约 0.0001329228 约 1.00013294 约 0.0132940%

原首点是1，所以第一行的约0.12029不是计算机把1算错了，而是后面 x(10),x(20),… 全部折回来相加。N=40 把第一次折回的位置推得更远，那里尾巴已经很小，故误差小得多，但并非严格为零。

回读｜为什么书中的 N=10 图画到了 n=39

原书代码先令 N=40，用它生成 n=0,…,39 和 k=0,…,39，再另令 N1=10 代入单位圆指数。这里代码的 N=40 是数组/绘图长度，N1=10 才是这一组不同采样位置的数量。 40个频率数组元素只包含10个不同的单位圆位置，各重复4次；合成后除以40，恰把重复4次的倍数抵消，等效于10点IDFT。第二组改为 N2=40，才有40个不同的频率位置。

所以第一幅图中每10点重复一次，显示的是10点 IDFT 合成式的周期延拓。同一个字母 N 在数学推导和程序局部命名中的作用要重新辨认，不能只看它写着40就认定第一组是40个不同频率点。

若严格按本题定义再乘 R10(n)，有限主值 x10(n) 只保留 n=0,…,9，其他位置应为0。不要把图中后面反复出现的峰误认成原指数信号每十点重新长大，也不要把40个绘图位置说成这次使用了40个不同频率采样点。

这一点正是原符号最需要解释的地方：xN(n) 表示被选出的主值，去掉选段窗以后则是周期合成序列；二者在第一段相同，段外含义不同。

自测｜回到原公式判断

  1. 为什么此题不能用“取 N 大于原信号长度”保证完全恢复？
  2. 把 z=WN−k 代入 1/(1−az−1) 后，分母是 1−aWNk 还是 1−aWN−k？
  3. n=3,N=10 时，r=−1 为什么不参加叠加？
  4. N=10 的图在0到39重复四段，说明用了40个不同的频率采样位置吗？
答案｜先解释再核算
  1. 原公式为无限长衰减序列；有限 N 一般仍有非零尾部折回，只能使误差减小。
  2. 1−aWNk，因为 z−1=(WN−k)−1=WNk。
  3. n+rN=3−10=−7<0，阶跃函数为0。
  4. 没有40个不同位置。原代码确有40个频率数组元素，但只是10个不同位置各重复4次；它等效地把同一10点周期合成式评价在更多时间位置，主值仍只有10点。
