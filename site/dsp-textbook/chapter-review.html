  • 从输入对象与目标选择DTFT、DFS、DFT或FFT
  • 区分归一化、索引作用域、记录外延拓与真实信号

学习目的｜不用一次背完，也能独立开始做题

这一节是第二章的收束，不是替代前面推导的公式速记卡。你应当已经读过 DTFT、周期序列、DFT、频域采样、FFT 与应用。现在练习把它们放回同一张思考路线：题目给了什么对象，要得到什么结果，公式中的字母在做什么，计算怎样验错。

本节的数值题均为新编回忆练习，不冒充原书例题。原书真题另有对应讲解。第一次做时可以回看前面小节；第二次只看题目，先用一句话说出自己的选择理由。

方法｜每道题先回答四个问题

  1. 输入是什么？一般离散序列、明确周期的序列、一段有限记录，还是连续时间信号？“我只拿到一段记录”不等于“真实信号周期重复”。
  2. 输出是什么？连续频率函数、有限个频率系数、卷积结果，还是某个物理频率的估计？
  3. 哪些条件已给？求和是否收敛，序列周期是多少，有效数据多少点，采样频率有没有给，采用哪一种归一化？
  4. 怎样验算？逆变换、直流和、能量、对称性、直接卷积，至少选择一种独立检查。不要用同一条有可能写错的公式来“自证”。

这四问就是解题入口。先写清楚它们，之后的字母更换便不容易把你带走。

对照｜DTFT、DFS、DFT 与 FFT 各自做什么

名称 本章处理的对象 得到什么 最需要记住的边界
DTFT 离散时间序列 关于数字角频率的连续变量表达式 频率变量连续，频谱以 2π 为周期；普通函数形式要检查存在条件
DFS 已知周期为 N 的离散序列 一组独立的谐波系数 同余频率表示相同离散模式，只需 N 个独立系数
DFT N 个有限数据 N 个复系数 这组数据可以精确逆变换；周期延拓是表示方式，不是对真实记录外信号的测量
FFT 已经定义好的 DFT 计算任务 同一组 DFT 系数 它改变算法的计算量，不定义一种新变换

原书回读。 原 2.5 第31页把采样、频谱周期复制、频域取点、时域周期化画在同一幅图中。不要把图上的箭头误读成“所有符号都不需要尺度就能互换”。连续时间积分换成求和会带采样间隔；DFS 的系数归一化与 DFT 也必须区分。下面用一组数把三种表达真正对齐。

算例｜同一组数据，为什么可以有三个不同的正确表达

给定四个数，从编号0开始：

x(0)=1,x(1)=2,x(2)=0,x(3)=0.

暂时不规定记录外的数据。为了求 DTFT，我们先另行定义零延拓序列 x0(n)：在 n=0,1,2,3 等于这四个数，其余整数处为0。下标0在这里只是序列名字的一部分，不是“只取第0个样值”。

第一步：零延拓序列的 DTFT

按原书记号，令 X0(ejω) 表示这个零延拓序列的 DTFT：

X0(ejω)=∑n=−∞∞x0(n)e−jωn=1+2e−jω.

本式的 n 是时间求和编号，ω 是要考察的数字角频率，单位 rad/sample。这里只有两项非零，不存在无限求和的收敛困难。ω 可以连续取值，不只允许四个点。

第二步：在四个频率格点上取值，得到4点 DFT

沿用原书旋转因子 WN=e−j2π/N，本题 W4=−j。DFT 为

X(k)=∑n=03x(n)W4kn=1+2W4k,k=0,1,2,3.

这里 k 是输出频率格点编号，不是前一式的时间编号 n。逐项代入：

X(0)=3,X(1)=1−2j,X(2)=−1,X(3)=1+2j.

它们正好等于 X0(ejω) 在 ω=0,π/2,π,3π/2 的值。关系是“在同一个函数上取四个点”，不是把连续变量 ω 改名成 k 就算完成了换元。

第三步：另定义周期延拓，读回 DFS

现在才定义 x~(n)：把 [1,2,0,0] 每四点重复一次。因此 x~(4)=1，而零延拓的 x0(4)=0。两者在前四点相同，记录外不是同一个序列。

若把 DFS 写成

x~(n)=∑k=03akej2πkn/4,

则系数为 ak=X(k)/4。若原书改用 X~(k)，并把 1/N 放在合成式前，则本题 X~(k)=X(k)。这两种写法不同的是系数命名与归一化的位置，不是周期序列变了。

换字母提醒。 在 DFT 正变换中，k 是固定的输出编号，n 在求和。到上面的 DFS 合成式中，n 成为想恢复的时间位置，k 在求和；k 仍标记频率，只是从输出索引换成了求和索引。

如果还要求周期序列的 DTFT，就需要在广义意义下用周期冲激谱描述。不能因为这一周期只有四个数，就把无限重复序列当成绝对可和序列，直接宣布其普通 DTFT 处处是有限函数。

验算｜四个检查，分别抓住哪一种错误

沿用刚才的 X(k)，逆变换采用

x(n)=14∑k=03X(k)W4−kn,n=0,1,2,3.

检查一：直流系数等于样值总和

X(0)=1+2+0+0=3.

平均值则是 X(0)/4=3/4。这里最容易抓住“把未归一化 DFT 的直流值直接叫平均值”的错误。

检查二：所有频率系数相加，恢复第0点

x(0)=14[3+(1−2j)−1+(1+2j)]=1.

这可以检查逆变换的 1/N。漏掉这个因子，会得到4，而不是1。

检查三：复数模平方检查能量

时域能量是 12+22=5。频域中，|1−2j|2=12+(−2)2=5，不是把复数本身平方。按本章归一化：

∑n=03|x(n)|2=14∑k=03|X(k)|2=14(9+5+1+5)=5.

这可以检查整体尺度，以及有没有误用普通平方代替模平方。但它不一定能抓住正、逆指数符号互换，因为共轭不会改变模平方。

检查四：用非对称数据核符号

取更简单的新输入 z=[0,1,0,0]，正变换应为

Z(k)=W4k,Z=[1,−j,−1,j].

若得到 [1,j,−1,−j]，正变换的指数符号就反了。不要只用实偶序列验程序；它有时会掩盖这个错误。

自测｜你能分清数据、系数与相位吗

  1. 对上面的四个数，“频谱是 1+2e−jω”与“频谱是四个复数”是否矛盾？分别指哪种表达？
  2. x0(4) 与 x~(4) 各是多少？仅凭原来的四个观测值，能知道真实信号在第4号位置是多少吗？
  3. 周期延拓的平均值是多少？用 ak 作 DFS 系数时，a0 是多少？
  4. 只保存 |X(k)|，能否保证逆变换恢复原四个数？
答案｜先把对象说完整
  1. 不矛盾。前者是零延拓序列的 DTFT，是连续频率函数；后者是4点 DFT，是该函数四个格点上的值。两者不能只凭都写大写 X 就混为一谈。
  2. 分别是0与1。两者来自我们明确规定的两种延拓；原四个观测值本身不足以确定真实记录外的第4点。
  3. 平均值为 3/4，a0=X(0)/4=3/4。
  4. 不能。相位也参与合成。若把模 [3,5,1,5] 当成完整频率系数，逆变换第0点会是 (4+25)/4，并不等于1。实信号具有共轭对称频谱，也不意味着相位可以删除。

算例｜采样率、有效数据长与 FFT 点数分开写

设采样频率 fs=800 Hz，采样间隔 T=1/fs=1/800 s。现在实际取得 M=80 个样值，只对这80点使用矩形窗，再补零到 N=800 点计算 FFT。

本题角色。 n 数真实时间位置，k 数 FFT 频率格点；M 是真实记录长度，N 是含补零的计算点数。原课件在不补零的情形可把二者都写成 N，本题分成两个字母是为了区分角色，不是宣称原来的 N 永远只能表示某一种长度。

频率格距是

Δf=fsN=1 Hz.

矩形观察窗的标称长度是 MT=0.1 s，而第0个到第79个样值的时刻间隔是 79T=0.09875 s。前者用来描述80格观察窗，后者是两个端点相减，不能为了字面上都叫“时长”就互相替代。

矩形窗频谱从主瓣中心到第一零点的间隔是 fs/M=10 Hz。补零把取点变密了，却没有把这份窗频谱的第一零点变成1 Hz。因此“网格间隔1 Hz”不等于“所有相差1 Hz的两个频率都可以可靠分开”。具体可分辨程度还受窗、幅度比、噪声和判据影响。

若 k=750，直接用 kfs/N 得到750 Hz；在主值频率区间 [−400,400) Hz 中，它等价于 −50 Hz。这里的负号表示离散复指数的旋转方向，不是采样时间倒流。

自测｜补零能不能救回已经混叠的信息

  1. 以800 Hz采样，真实700 Hz余弦与100 Hz余弦能否产生完全相同的样值？请写一个等式，而不只说“会混叠”。
  2. 上述80点补零到800点，数据中真的多出了720个测量值吗？DFT系数个数变多，是否意味着测量信息也增加？
  3. 400 Hz正弦以800 Hz采样、且起点相位为0，会得到什么？这提醒我们怎样理解奈奎斯特边界？
答案｜用定义而不是口号
  1. 对整数 n，有
cos(2π700800n)=cos(2πn−2π100800n)=cos(2π100800n).

两者给出相同的离散样值。仅在这些样值后补零，不能判断原连续信号来自哪一个频率；必须有采样前限带等额外条件。

  1. 没有新增测量值。补入的0是我们给计算数组添加的数，不是仪器在额外时刻测到的事实。更多 DFT 格点描述同一个有限记录的 DTFT 曲线。
  2. 样值为 sin(πn)=0。边界频率的相位信息可能退化，因此不能把“采样率恰好为最高频率的两倍”无条件当作对任意相位信号都安全的保证。通常需要严格限带、正确的边界约定及实际滤波裕量。

算例｜用最短的卷积把循环边界看出来

新编例：x=[1,2]，h=[1,−1]，均从编号0开始，其余位置为0。我们要的是线性卷积

y(n)=∑mx(m)h(n−m).

n 是正在求的输出位置；m 在时间位置中求和，不是频率索引。直接计算：

y(0)=1,y(1)=2−1=1,y(2)=−2.

所以线性卷积是 [1,1,−2]，支持区间为0至2。若只做2点 DFT 相乘再逆变换，尾部第2点折回第0点，得到

y2=[1+(−2),1]=[−1,1].

这不是 FFT 算错了，而是2点乘法对应的本来就是2点循环卷积。要直接得到这两个长度均为2的零起点有限序列的全部线性卷积，应把变换点数取为 L≥2+2−1=3，并对两序列都补到相同的 L 点。L=3 或更大都可；“必须是2的幂”是某些 FFT 实现的方便条件，不是线性卷积定理本身的要求。

自测｜先解释为什么，再套长度式

  1. 为什么 L=2 时是第2点折回第0点，而不是折回第1点？
  2. L=4 时线性卷积的数值是否改变？第四个输出是什么？
  3. 原书有时用 N 表示滤波器长度，有时用它表示 DFT 点数。遇到 L≥N+M−1 时，怎样确认角色，而不是把所有 N 都当作同一个量？
答案｜圆周编号按模计算
  1. 因为 2mod2=0。循环卷积按输出编号对长度取模，把相差整数个周期的位置相加。
  2. 不改变前三个值。4点结果是 [1,1,−2,0]，新增末位为0。
  3. 看当前段落的长度定义：在这条常见写法里，N 与 M 是两个有限序列的长度，L 才是共同变换点数。如果作者换一种命名，要把整个式子的角色重新对应；不能只凭字母熟悉就沿用上一页的角色。

回读｜遇到原书长公式时，按这个顺序拆开

先圈出结果依赖的变量，再圈求和或积分变量。例如

x(n)=1N∑k=0N−1[∑m=0N−1x(m)WNkm]WN−kn

最外面的 n 是固定输出时间位置；k 是频率求和编号；内层 m 是时间求和编号。m 接替了正变换原来使用的时间字母，以免和外层固定的 n 冲突。

读懂角色后，再看 WNk(m−n) 的有限和。当 m−n 为 N 的整数倍时，内层频率和为 N；否则为0。在 m,n=0,…,N−1 的范围内，只有 m=n 留下来，外面的 1/N 抵消这个 N，于是恢复 x(n)。

注意：有限个复指数基的正交性可以用有限几何级数直接证明；连续函数空间中的完备性和均方极限还需要相应的函数空间条件。不能把这个有限和证明机械地搬成“任何函数都逐点、均匀地收敛”。本章涉及连续正交概览时，先理解它在合适条件下的均方含义，不要求用一个没有条件的口号吞掉分析细节。

收束｜怎样判断自己是真的学会了

不要求你立刻背出每条性质，但你应能做到：看到新题先说明对象；看到 k,n,m 就地辨认角色；写出所用正逆变换的归一化；解释周期延拓与真实信号的差别；区分混叠、截断、泄漏和补零；用一个独立小例子检查答案。

如果某一项做不到，回到相应小节的“定义”和第一道小算例，而不是从头重背整章。最后再回看原 PPT：能够指着原式说出它在解决什么问题，指出其中一次合法换名，并把一个结果验回原数据，就比只记住公式的外形更可靠。

本节不把原书所有例题改造成这几道短题。它是连接已讲各节的回忆练习；原始题干、页码对应、逐式推导和必要纠错仍保留在各专题中。
