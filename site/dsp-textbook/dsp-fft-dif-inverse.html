另一种蝶形、位反转与逆变换

先学：FFT为何快：奇偶拆分与四点手算 · 频率取N点，时域发生什么

  • 推导DIF与DIT的区别

目标｜看懂同一 DFT 的另一种拆法

上一节按时间下标奇偶拆输入，叫 DIT。原 PPT 2.5 P20–28 改成先把输入前后对半相加减，最后得到偶数和奇数频率的两组输出，叫 DIF。两者计算同一个 DFT，但蝶形的旋转乘法位置、内部排序不同。

P29–31 又退后一步回顾正交展开与变换全貌。本节把这部分接在计算之后，让你知道为什么结果是坐标变换，以及归一化系数为什么不能漏。

记号｜x_1 的名字又被重新定义了

仍有 N=2M、WN=e−j2π/N、n 为时间位置、k 为频率格点。原 PPT 在 DIT 中写过 x1(r)=x(2r)，但 DIF 的 P22 重新定义 x1,x2。不能把上一节的奇偶子序列直接带入本节同名符号。

这里的新定义是

x1(n)=x(n)+x(n+N/2),
x2(n)=[x(n)−x(n+N/2)]WNn,0≤n<N/2.

x1 是两半对应位置的和，x2 是差再乘旋转因子。下面从原 DFT 推出为什么要这么定义。

推导｜先拆前半和后半，再挑频率奇偶

将原 DFT 按时间范围分开，后一半的时间下标换成 n+N/2：

X(k)=∑n=0N/2−1x(n)WNkn+∑n=0N/2−1x(n+N/2)WNk(n+N/2).

因为 WNkN/2=e−jπk=(−1)k，可以合成

X(k)=∑n=0N/2−1[x(n)+(−1)kx(n+N/2)]WNkn.

现在分频率的奇偶：

  • 偶数频率，令 k=2r，r=0,…,N/2−1。
  • 奇数频率，令 k=2r+1，r 取同一范围。

这里 r 是频率组里的编号。 上一节 DIT 的 r 是时间子序列编号，同一个字母在新的定义中承担了不同任务。看见 k=2r 就知道此处拆的是频率。

偶数支路 (−1)2r=1，于是

X(2r)=∑n=0N/2−1[x(n)+x(n+N/2)]WN/2rn=DFTN/2{x1(n)}(r).

奇数支路 (−1)2r+1=−1，还要从 WN(2r+1)n 中提出 WNn，得到

X(2r+1)=∑n=0N/2−1[x(n)−x(n+N/2)]WNnWN/2rn=DFTN/2{x2(n)}(r).

这就解释了原书的新 x1,x2：这样定义以后，两组输出都能用较短 DFT 计算。

定义｜DIF 蝶形先减后乘

原 P23 的蝶形接收 a=x(n) 与 b=x(n+N/2)，给出

a+b,(a−b)WNn.

与 DIT 的 a+Wb、a−Wb 对照：DIT 先在一个输入上旋转，再加减；DIF 的差支路先相减，再旋转。乘法放在哪里不同，但都可按“一复乘、两复加/减”计数。

例题｜用 DIF 重算四点，核对同一答案

沿用补充输入 x(n)={1,2,3,4}，N=4。现在按前后两半配对，不按奇偶取数：

n x(n)、x(n+2) 新 x1(n) 新 x2(n)
0 1,3 4 (1−3)×1=−2
1 2,4 6 (2−4)(−j)=2j

分别做两点 DFT：

DFT2{4,6}={10,−2}={X(0),X(2)},
DFT2{−2,2j}={−2+2j,−2−2j}={X(1),X(3)}.

若先放偶数支路、再放奇数支路，存储次序是 X(0),X(2),X(1),X(3)，不是自然频率顺序。重新按频率编号排列后，仍是上一节的 {10,−2+2j,−2,−2−2j}。排序不同不意味着频谱变了；但把未排序数组直接画在自然频率轴上，会画错。

方法｜原书流图与倒位序的适用范围

P24/P25 的八点图要沿输出标签辨认哪条支路给偶频率、哪条给奇频率，不能单凭箭头上下位置推断 k。对于标准原位迭代布局：DIT 常用位反转输入、自然顺序输出；DIF 常用自然顺序输入、位反转输出。实际软件可在内部处理排列，调用者要按接口说明，而不是先替所有 FFT 函数倒位序。

原 P26 用 L 表示级号、M=log2N。在这里，L 仍不是卷积的变换长度。第 L 级 DIF 的蝶距与旋转因子指数为

B=2M−L,P=J2L−1,J=0,…,2M−L−1.

八点 DIF 的三级蝶距为4、2、1，块内旋转指数分别为 {0,1,2,3}、{0,2}、{0}，与 DIT 从小块合并的方向相反。两者都有 M 级、每级 N/2 个蝶形，因此一般计数同为 (N/2)log2N 次复乘与 Nlog2N 次复加。

P27 强调的是：FFT 对离散数据实现了 DFT 本身的快速计算。数学上这一步是精确恒等变形；后面把实际连续信号变成有限数组时，才另外面对采样、截断等近似问题。

推导｜用同一个正 FFT 算逆变换

原 P28 的反变换为

x(n)=1N∑k=0N−1X(k)WN−kn.

WN 本身含负指数，反变换写 WN−kn 因而是正的复指数。这和“正变换负指数、逆变换正指数”完全一致。

原书星号在本页表示复共轭，不是前面写在两序列之间的卷积号。为让操作顺序清楚，记 z* 为共轭：先对输入频谱逐项取 X*(k)，做正向 FFT，再对结果逐项取共轭，最后除以 N。

x(n)=1N[DFTN{X*(k)}(n)]*.

证明只用两步：WN*=WN−1；对整个和取共轭会同时把 X*(k) 变回 X(k)、把 WNkn 变成 WN−kn。

这里又要说明输入位置： FFT 程序接收的是数组 X*(0),…,X*(N−1)。虽原数据来自频域，算法仍只是对这份数组应用正变换公式，不必把 k 假装成原信号时间。

例如四点例的频谱为 {10,−2+2j,−2,−2−2j}。对它取共轭后做正 DFT，结果为 {4,8,12,16}；再共轭、除4，得到原输入 {1,2,3,4}。本例结果刚好为实数，不能因此省略一般复数数据所需的共轭步骤。

定义｜正交展开就是换一套坐标

P29–30 把傅里叶分析联系到正交函数。先用有限维版本理解：N 点数组相当于 N 维向量，用下面 N 条复指数序列作为基底：

ϕk(n)=ej2πkn/N,k,n=0,…,N−1.

k 标记“第几条基底”，n 是该基底序列里的位置。不同基底满足

∑n=0N−1ϕk(n)ϕℓ*(n)={N,k=ℓ,0,k≠ℓ.

这就是根单位等比求和。每条基底的平方范数是 N，因此展开系数为

ak=1N∑n=0N−1x(n)ϕk*(n)=X(k)N,x(n)=∑k=0N−1akϕk(n).

把这段数组周期延拓后，ak 正是这一归一化约定下的 DFS 系数；X(k) 是未除 N 的 DFT 值。二者不能只因都叫“傅里叶系数”就直接写成相等。

能量恒等式随之为

∑n=0N−1|x(n)|2=1N∑k=0N−1|X(k)|2=N∑k=0N−1|ak|2.

四点例左边 1+4+9+16=30；右边 (100+8+4+8)/4=30。这是检验漏掉归一化系数的一种方法。

回读｜P29–31 哪些符号不能直接照搬

P29 写了一般正交展开 f(t)≈∑rcrgr(t)。这里 t 是连续时间，r 是基函数编号；同页的求和上限 n 是保留的项数，不是本章离散序列的时间位置 n。P30 的 ejnω0t 又用 n 表示谐波编号，也必须就地读为“第几次谐波”。

该页均方误差公式的分母显示为 t1−t2。若区间 t1<t2，非负误差应除以 t2−t1；复信号还应使用误差的模平方。能量写成 ∑r|cr|2 需要正交归一基底；未归一时要带每条基底的平方范数。不要把概览页中的简写当成无条件公式，再覆盖刚推导的 DFT 1/N。

为把 P29 的“完备”和极限也读完整，暂用 K 表示保留的基函数项数，对应原页求和上限的 n。若 f 在区间 [t1,t2] 上平方可积，gr 是该空间的完备正交归一基，系数取相应投影，则

EK=1t2−t1∫t1t2|f(t)−∑r=1Kcrgr(t)|2dt⟶0.

“均方趋零”说的是积分意义的总误差越来越小，不自动保证每个点的误差都趋零，更不保证所有位置同时以一样的速度变小。有限 N 点 DFT 的基底已经有恰好 N 个，普通数组可以精确展开，不必等待这个无限项极限。

P29 右侧又写连续时间傅里叶变换对。沿该页原符号，

F(ω)=∫−∞∞f(t)e−jωtdt,f(t)=12π∫−∞∞F(ω)ejωtdω.

这一处 ω 是连续时间角频率，单位 rad/s；不是 DTFT 的 rad/sample。 公式在相应普通积分成立条件下使用，更一般的信号需要均方或广义意义解释。正变换负指数、逆变换正指数及 1/(2π) 必须配套。若改用 Hz 的 f，指数变为 2πft，尺度也跟随变量替换，不能把连续积分的系数抄到有限 DFT 中。连续采样到DFT的 T 尺度将在《DFT看实际频谱》对应原2.6 P17–19完整推导。

P31 的多格图在串联不同操作，读图时先标记“在哪一个域”：

  • 连续时间信号采样，得到离散时间序列；频谱会周期重复，单位和采样尺度需要单独保留。
  • 有限离散序列的 DTFT 频率仍连续；在一周期内取等间隔 N 点得到 DFT，支持区间条件见频域采样节。
  • 对这 N 个频率值作 IDFT，得到一段 N 点主值；对应的周期延拓可以用 DFS 描述，系数为 X(k)/N。
  • DFT 与 FFT 之间的箭头表示“同一个有限变换的快速算法”，不是又经历一次采样或另一种新的物理变换。

原图用相似的 X(·) 标记不同域对象时，必须同时看自变量、单位、是否周期以及归一化。回到课堂后先标这四项，比靠函数名字猜意思可靠。

自测｜认出同名符号的新角色

  1. DIF 的 x1(1) 与前节 DIT 的 x1(1)，在四点输入 {1,2,3,4} 中各等于多少？
  2. DIF 中 k=2r+1 的 r 是时间位置还是频率编号？
  3. 原 P28 的上标 * 与 h(n)*x(n) 中间的 * 含义一样吗？
  4. 四点 DFT 的 X(0)=10，对应 DFS 的 a0 是多少？
  5. 如果把四点例的能量写成 ∑k|X(k)|2，会大了几倍？
答案｜先答角色，再算数字
  1. DIF 是 x(1)+x(3)=2+4=6；DIT 是 x(2)=3。两段局部定义不同。
  2. 是奇数频率组内的编号，不是前一节奇偶时间抽取的 r。
  3. 上标星号表示复共轭，中间的运算号表示卷积，位置与定义不同。
  4. a0=X(0)/4=2.5，也正是四个时间样本的平均值。
  5. 大4倍，未归一DFT的能量和为120，时域能量为30。
