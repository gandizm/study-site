主值、周期延拓与圆周移位

先学：有限序列的DFT与逆变换为什么成立

学完能做什么

  • 分清有限主值、周期延拓与主值窗口
  • 按原加号移位约定逐位置计算左右移与负下标
  • 理解补零改变所选周期，避免把数组倒排当圆周反转

目标｜移出去的样值，到底去哪了

普通时间平移会把样值移到新的时间位置；圆周移位则在一个固定长度的环上移动，从一端出去的样值会从另一端回来。两者都叫“移位”，但边界规则不同。

本节对应课件2.3 P14–P19。先讲主值与周期延拓，再把原图中的五个样值实际移动。学完后，你应能看着 x((n+m))N 说清方向，而不是见到“加号”就凭印象决定向右。

P14 还列出卷积、对称与相关。卷积和对称分别在后面的单元展开；相关由专门的补充相关单元承接原目录，不把这一行提纲冒充完整的相关教学。

记号｜双括号带 N，不是普通函数括号的装饰

本节保留课件的写法：

  • x(n)：一个长度为 N 的数组，代表位置 0 到 N−1；作有限序列时区间外取0。
  • x~(n)：把该数组每隔 N 重复得到的周期序列。
  • x((n))N：课件对按 N 周期取值的另一种写法。
  • RN(n)：在 0≤n<N 为1、其他整数位置为0的矩形序列。
  • m：本节固定的移位量，不是卷积式里正在求和的 m。

为帮助计算，也写 nmodN，表示将整数 n 折回 0,1,…,N−1 中的唯一余数。它是下标运算，不是对样值的幅度取模。

例如 N=5 时，6mod5=1，−1mod5=4。后一式因为 −1=(−1)·5+4。数学上选的是0到4之间的余数，不是把负下标留在原数组之外。

定义｜周期延拓与取主值互为哪种操作

从区间外为零的有限序列出发，可以写

x~(n)=∑r=−∞∞x(n+rN)=x((n))N.

这里 n 是要检查的时间位置，r 是各个周期副本的编号。由于原数组只占一个代表区间，每个 n 只有其中一个副本能贡献原数组中的相应位置。

回读 P15 的可读展示式时要留意：它左侧写 x~(k)，右侧求和的输入却含 n+mN。要让一个等式表示同一条序列的同一时刻，左右自由的时间索引必须一致。本稿用 n 表示待求的时间位置，用 r 表示可换名的周期副本哑变量；那里左侧的 k 应按时间角色理解，不能仅因字母是 k 就当作频率索引。这里是在说明可读展示式的角色对应，不据此断言原生公式对象的编辑状态。

课件的“主值区间”选为 0≤n≤N−1，主值序列可写成

x(n)=x~(n)RN(n).

乘 RN 是逐点乘一个窗口：区间内保留，区间外置零。它不是再做一次傅里叶变换，也不是把所有周期相加。

这里的“主值”指选定的一段代表周期，和复数相位的“主值角”不是同一个概念。也并非世界上只能从0开始取周期；选别的连续 N 个整数也能代表同一个周期序列，但必须把下标与相位约定一起交代。课件本节统一从0开始。

原例｜五个数按5点或6点重复，得到的是不同周期序列

课件 P18 的原数组从 n=0 开始为

x(n)=[2,1,3,1,0.5].

若选 N=5。周期序列连续重复这五个数，所以

x~5(0)=2,x~5(4)=0.5,x~5(5)=2,x~5(−1)=0.5.

若选 N=6。先补一个零，代表数组是

[2,1,3,1,0.5,0].

再每隔6个位置重复，所以

x~6(0)=2,x~6(5)=0,x~6(6)=2,x~6(−1)=0.

原先的五个非零样值没变，但“多久重复一次”的规则变了，因而两条周期序列不同。不能先按5点移位，最后再补一个零，声称与按6点周期移位总是相同。

定义｜普通线性移位不把样值绕回

对一条区间外为零的有限序列，y(n)=x(n+m) 表示普通时间平移。m>0 时是向左提前，m<0 时是向右延迟。

怎么判断，不靠口诀？原来的 x(0) 出现在满足 n+m=0 的新位置，即 n=−m。因此 m=1 时，它移到 n=−1，是向左。

例如原五个数线性左移1格后，非零样值位于 n=−1,0,1,2,3，数值仍按顺序为 2,1,3,1,0.5。若只显示原窗口 0 到4，会看到 [1,3,1,0.5,0]；第一个2没有变成零，而是到了显示窗口之外的 n=−1。

“线性平移”和“平移后再截掉窗口外内容”是两个操作。圆周移位则从定义上就采用另一种边界。

定义｜按原课件的加号，圆周左移这样写

课件 P16 写

y(n)=x((n+m))NRN(n).

它表示：先让下标按 N 周期取值，再只保留主值区间。若只列数组的 0≤n<N 部分，也可写成辅助形式

y[n]=x[(n+m)modN].

这两个式子的意思相同：m>0 为圆周左移，m<0 为圆周右移。课件 P19 的 m=1 左移与 m=−2 右移，都是按这个加号约定。

你也会在别处看到 x((n−n0))N。那是用减号把 n0>0 定义成右移，二者只需令 n0=−m 就能对应；不能把两种参数符号混用。

方法｜把 P17 流程图变成可执行的四步

  1. 先选本次长度 N。原数组较短时，先补零到 N 点。
  2. 按 N 周期延拓，明确窗口外从哪里继续取值。
  3. 对周期序列做所需时间平移。
  4. 取 0 到 N−1 的主值，得到新的 N 点数组。

实际手算可以不画无限长的周期副本，而直接算每个新位置的 (n+m)modN。这是同一定义的简便实现，不是另一种移位。

课件说“一端每移出一个值，另一端就移入同一个值”，正是周期边界的含义。它与窗口外一律填零的线性移位不同。

原例展开｜N=5、m=1，每个位置都算一遍

按课件 P19，把 [2,1,3,1,0.5] 圆周左移1格：

新位置 n 读取的原下标 (n+1)mod5 新值 y(n)
0 1 1
1 2 3
2 3 1
3 4 0.5
4 0 2

所以结果为

y(n)=[1,3,1,0.5,2],0≤n<5.

最后一个2来自原来的第0个位置绕回，不是新增样值。与前面普通线性左移后显示在同一窗口的 [1,3,1,0.5,0] 相比，差别就在边界。

原例展开｜N=5、m=−2，负下标怎样折回

现在按原式 x((n−2))5，即圆周右移2格：

新位置 n 读取的原下标 (n−2)mod5 新值 y(n)
0 3 1
1 4 0.5
2 0 2
3 1 1
4 2 3

完整结果为

y(n)=[1,0.5,2,1,3],0≤n<5.

新位置0和1之所以不是零，是因为周期序列在负时间也有样值；它们来自上一周期的末两项。数组没有丢掉任何一个值，只是循环改变顺序。

补充算例｜先补零到6点再移位，不是最后随便补零

先按 P18 的6点规则得到 [2,1,3,1,0.5,0]。

  • 左移1格，读取原下标 1,2,3,4,5,0，结果是 [1,3,1,0.5,0,2]。
  • 右移2格，读取原下标 4,5,0,1,2,3，结果是 [0.5,0,2,1,3,1]。

与5点右移结果 [1,0.5,2,1,3] 相比，不仅长度多一个位置，绕回来的末端内容也变了。原因是取模的 N 已经改变。

这也提醒你，题目只说“圆周移位”却没交代周期长度时，不能直接唯一作答。需要从给定DFT点数、数组补零要求或明确的周期中确认 N。

铺垫｜圆周反转不是简单把数组左右倒排

后面的圆周卷积与对称性会用到 x((−n))N。在主值区间里，它读取的原下标依次为

0,N−1,N−2,…,1.

第0个位置保持在第0个位置，其余位置按模 N 反向。对原五个数，圆周反转得到

[2,0.5,1,3,1].

这不同于直接把数组最后一个元素搬到第一个的 [0.5,1,3,1,2]。后者少考虑了“围绕哪个下标反转”的问题。先明确数学定义，再看编程语言的数组倒序操作，不能反过来。

这一段是为后续内容补的铺垫，原 P14 此处只列出对称概念，详细定义还在后面。

回读｜主值窗口、周期取值、时间方向分别检查

读 x((n+m))NRN(n) 时，可以分三遍：

  1. 先看 n+m：原样值将出现在哪个新位置，决定移动方向。
  2. 再看双括号与 N：下标跑出0到 N−1 后按哪个周期折回。
  3. 最后看 RN：只保留主值区间，不把整个无限周期序列都叫成这一个有限数组。

本节的“圆周”发生在整数时间下标上，不是对复数值本身旋转。下一节利用这种按下标绕回的规则定义圆周卷积；再往后，DFT性质会证明它对应怎样的频域相位因子。

自测｜用下标表检查，不靠方向直觉

  1. 对 N=4、x=[10,20,30,40]，求课件约定下 m=1 与 m=−1 的圆周移位。
  2. 对 N=5，−7mod5 是多少？所以 x((−7))5 读的是哪个原样值？
  3. m=N 的圆周左移会怎样？普通线性左移 N 格是否也不变？
  4. 为什么 N=5 时先右移2格再补零，与先补零到6点再按6点右移2格通常不同？
  5. 写出 [10,20,30,40] 的4点圆周反转。它与普通数组倒排是否相同？
答案｜明确每一次读取的是哪个旧位置
  1. m=1 读旧下标 1,2,3,0，得 [20,30,40,10]；m=−1 读 3,0,1,2，得 [40,10,20,30]。
  2. −7=(−2)·5+3，所以余数为3，读取 x(3)。负号不是把该样值的幅度取负。
  3. (n+N)modN=n，所以圆周移位一整圈后不变。普通线性移位会改变各样值在整条时间轴上的位置，一般不保持同一有限序列不变。
  4. 因为边界规则分别按模5与模6折回，参与绕回的最后两个位置不同。零要在决定本次周期数组时就放进去，不能事后补零冒充同一运算。
  5. 读取旧下标 0,3,2,1，得到 [10,40,30,20]；普通数组倒排是 [40,30,20,10]，并不相同。圆周反转把第0个位置留在原处。
