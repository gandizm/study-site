学完能做什么

目标｜不是背六条公式，而是先认出做了什么操作

本节把原2.3 P26–P39重排成一条可检查的路线：先固定同一个 N 点变换，再问时间侧做了什么，最后推算频率侧怎样改变。圆周共轭对称性放在下一节展开，不把性质目录的一行当作已经讲完。

你将完整做教材例2.3.7与2.3.8，分清“把样值位置移动”和“给原位置的样值乘旋转因子”。这两个操作看起来都含指数，结果却分别是频域乘相位与频域移位。

记号｜先固定变换，再辨认每个字母的工作

全节采用原书的旋转因子与归一化：

WN=e−j2π/N,X(k)=∑n=0N−1x(n)WNkn,x(n)=1N∑k=0N−1X(k)WN−kn.
  • n：时间位置。在正变换中是求和哑变量，在逆变换中是要恢复的自由时间索引。
  • k：频点位置。在正变换中是要计算的自由频率索引，在逆变换中是求和哑变量。
  • m：移位定理里是固定的时间移位量；卷积式里则是正在遍历的时间位置。每次出现都应结合是否有求和号判断。
  • l：调制定理里是固定的整数频点移位量；频域卷积里又会用作频点求和哑变量。
  • x((n))N、X((k))N：按 N 周期读取下标；若只讨论主值数组，始终取 0,…,N−1。

原课件在一些式子后乘 RN(n) 或 RN(k)，强调结果只取主值区间。下文已标明主值范围时省去窗口，但回读原式时不要把它当作新的变换。

结论与推导｜线性要求双方真正在同一张频率网格上

若 x1,x2 都做同一个 N 点DFT，则

DFT{ax1(n)+bx2(n)}=aX1(k)+bX2(k).

a,b 可以是复常数。理由是有限求和可逐项分配：

∑n=0N−1[ax1(n)+bx2(n)]WNkn=a∑n=0N−1x1(n)WNkn+b∑n=0N−1x2(n)WNkn.

如果原长度分别为 N1,N2，先选 N≥max(N1,N2)，分别补零到 N 点，再变换。不能把一个3点DFT和一个5点DFT的“第1项”直接相加，说它们已经处于同一个频率：前者频率是 2π/3，后者是 2π/5。

新编小例：两点数组 x1=[1,0]、x2=[0,1] 的变换分别为 [1,1]、[1,−1]。因此 2x1−3x2=[2,−3] 的DFT是 2[1,1]−3[1,−1]=[−1,5]。直接按两点公式求和与相减，也得到 2−3=−1、2+3=5。

推导｜原课件写加号：时间圆周左移 m 格

P29 的原形式是

xm(n)=x((n+m))NRN(n),Xm(k)=WN−mkX(k).

m>0 为左移；别把它不加说明地套进熟悉的“右移乘负指数”口诀。这里

WN−mk=e+j2πmk/N.

为什么是这个号？固定频点 k，令新的时间求和变量 r=n+m，于是 n=r−m：

Xm(k)=∑n=0N−1x((n+m))NWNkn=WN−km∑r=mN−1+mx((r))NWNkr.

求和项关于整数 r 以 N 为周期，因为数组按周期读，且 WNk(r+N)=WNkr。任何连续 N 项求和都一样，故可把区间移回 0 到 N−1，得到 WN−kmX(k)。

回读 P30 的 n′，它就是这里的 r，仍是时间求和变量，不是求导。若改用熟悉的右移量 n0，令 m=−n0，便得到

x((n−n0))N ⟷ WNkn0X(k)=e−j2πkn0/NX(k).

两种形式完全相同，只是“移位量取正代表哪个方向”的约定不同。旋转因子的模为1，所以圆周移位不改变每个频点的幅度；相位加上线性项，按模 2π 理解，原本为零的频点仍没有定义相位。

原例2.3.7｜看到 W 的正幂，不要把指数再反号一次

教材第三版印刷P71给出

x(n)=4δ(n)+3δ(n−1)+2δ(n−2)+δ(n−3),

做6点DFT，且 Y(k)=W64kX(k)。课件P31只列例号，这里依据真实书页补回条件。

先写6点数组，不漏掉两个零：x=[4,3,2,1,0,0]。比较右移定理 WNkn0X(k)，本题 n0=4，所以

y(n)=x((n−4))6R6(n).

逐个读取：

新位置 n (n−4)mod6 读到的样值
0 2 2
1 3 1
2 4 0
3 5 0
4 0 4
5 1 3

因此 y=[2,1,0,0,4,3]，回到原书的单位样值表示为

y(n)=2δ(n)+δ(n−1)+4δ(n−4)+3δ(n−5).

在6点环上右移4与左移2相同；右移4不是把后面两项丢掉，更不是把样值乘4。

推导｜频率左移 l 点，等价于时间逐点乘旋转因子

令 l 是固定的整数，构造

y(n)=WNlnx(n)=e−j2πln/Nx(n).

直接代入正变换：

Y(k)=∑n=0N−1x(n)WNlnWNkn=∑n=0N−1x(n)WN(k+l)n=X((k+l))N.

所以原书印刷P71式(2.3.15)的回读形式是

IDFT{X((k+l))NRN(k)}=WNnlx(n).

这里 n 仍是时间，k 仍是频点，l 是移了多少个频点；WN 自己的定义已含负号，所以 WNnl 展开后是负指数。不要只看上标有无负号，忘记底数的定义。

频率按整数格左移 l 点，对应每个时间样值乘上不同的相位，不是在时间上移动样值的位置。若调制频率不恰是 2πl/N 的整数网格，仍可调制，但通常不能简单写成原DFT数组的整数循环移位。

原例2.3.8｜同一道题，分别做时间移位和频率移位

实际书页为印刷P71–P72。已知

x(n)=δ(n)+2δ(n−5),

采用10点DFT。

第一问，求 X(k)。只有 n=0,5 有贡献：

X(k)=1+2W105k=1+2e−jπk=1+2(−1)k.

因为 k 为整数，偶数频点为3，奇数频点为 −1，所以完整数组为

X=[3,−1,3,−1,3,−1,3,−1,3,−1].

第二问，给 Y(k)=e−j2π3k/10X(k)，求时间数组。指数里是频率索引 k，这是在频率侧乘相位，故时间圆周右移3：

y(n)=x((n−3))10R10(n)=δ(n−3)+2δ(n−8).

完整数组为 [0,0,0,1,0,0,0,0,2,0]。原 n=0 移到3，原 n=5 移到8。

第三问，给 y(n)=e−j2π3n/10x(n)，求频谱。现在指数里是时间索引 n，不是上一问的 k。样值仍只在 n=0,5：

y(0)=1,y(5)=2e−j3π=−2.

所以 y(n)=δ(n)−2δ(n−5)，其DFT为

Y(k)=1−2(−1)k=X((k+3))10.

完整数组为 [−1,3,−1,3,−1,3,−1,3,−1,3]。特别地，k=7,8,9 读取原 X(0),X(1),X(2)，分别为 3,−1,3。把最后三点也算完，才能确认自己真的用了圆周移位。

这三问不需要依赖程序结果。若用软件复核，应让程序里的指数、DFT点数和逆变换 1/N 都与上述定义一致，不能只因画出相似柱状图就判定符号正确。

推导｜时间圆周卷积对应频率逐点乘，不需要额外 1/N

P32–P33 的结论是

y(n)=∑m=0N−1x1(m)x2((n−m))N⟷Y(k)=X1(k)X2(k).

这里 n 是输出时间位置，m 是输入时间求和变量，不再是前面固定的移位量。为证明它，在DFT中展开卷积：

Y(k)=∑m=0N−1x1(m)∑n=0N−1x2((n−m))NWNkn.

固定 m 后令 r=n−m，于是 n=r+m。内层求和变成

WNkm∑r=−mN−1−mx2((r))NWNkr=WNkmX2(k).

最后外层为 X2(k)∑mx1(m)WNkm=X1(k)X2(k)。回读原证明时，换元应能由 r=n−m 反解成 n=r+m；这里的 r 与原来的时间哑变量同角色，不是一个新频率。原P33目前可读展示式的换元行写作“令 m−n=n′”，而紧接的上下限 −m 到 N−1−m 与指数 n′+m 实际对应 n′=n−m。这里采用与后续运算一致的换元；这是对可读展示式前后关系的说明，不把未经原缓存核查的差异扩大为原生公式编辑对象的结论。

N≥max(N1,N2) 足以把两条数组放入同一个 N 点圆周卷积；若目的是得到全部线性卷积且不折回混叠，还要 N≥N1+N2−1。这两条长度条件回答不同问题，不能相互替代。

新编两点核对：x1=[1,2]、x2=[3,4]，DFT分别为 [3,−1]、[7,−1]。乘积为 [21,1]，逆变换得到 [(21+1)/2,(21−1)/2]=[11,10]。直接圆周计算也是 1·3+2·4=11、1·4+2·3=10。线性卷积却是 [3,10,8]，首尾折回才得到 [11,10]。

推导｜时间逐点乘对应频率圆周卷积，这次必须有 1/N

若 y(n)=x1(n)x2(n)，把第一条序列写成逆DFT：

x1(n)=1N∑l=0N−1X1(l)WN−ln.

此处 l 是频点求和哑变量，不再是上一节固定的调制频点数。代入后

Y(k)=1N∑l=0N−1X1(l)∑n=0N−1x2(n)WN(k−l)n=1N∑l=0N−1X1(l)X2((k−l))N.

这就是 P34 的频域圆周卷积定理。1/N 来自刚代入的逆变换，不是凭对称性随意添加。

继续上面的两点数组：时间逐点乘为 [3,8]，其DFT是 [11,−5]。频域圆周卷积为 [3·7+(−1)(−1),3(−1)+(−1)7]=[22,−10]，除以2才是 [11,−5]。如果算到 [22,−10] 就停，是漏了归一化。

推导｜只共轭、只反转、共轭再反转是三个操作

P35–P37 给出

DFT{x*(n)}=X*((−k))N.

原书常写 X*(N−k)，其中 k=0 必须按 X(N)=X(0) 理解；并不是多出第 N 个独立频点。

从定义出发，一步步把共轭提出来：

∑n=0N−1x*(n)WNkn=[∑n=0N−1x(n)WN−kn]*=X*((−k))N.

这里用了 (WNkn)*=WN−kn。也可以从右边开始，展开 X*(N−k) 再取共轭，利用 WNNn=1 回到左边；这对应原P36与P37的两个证明方向，不是两个不同定理。

同样，时间圆周反转对应频率圆周反转，因此

x((−n))N ⟷ X((−k))N,x*((−n))N ⟷ X*(k).

注意圆周反转的顺序是 0,N−1,N−2,…,1，不是从 N−1 一直倒排到0。

一个新编的非对称复数核验：N=4，x=[1,j,0,0]。逐个代入得到

X=[1+j,2,1−j,0].

只取时间共轭得到 [1,−j,0,0]，其DFT为 [1−j,0,1+j,2]，正是按频点 0,3,2,1 读取 X 后再共轭。若时间共轭后再圆周反转，数组变为 [1,0,0,−j]，DFT则为 [1−j,2,1+j,0]=X*。这个例子能检出把“共轭”误写成“频谱原位置直接共轭”的错误。

推导｜Parseval 的 1/N 是这套变换约定带来的

P38 的能量关系是

∑n=0N−1|x(n)|2=1N∑k=0N−1|X(k)|2.

这里 |x|2=xx*，复数不能用普通 x2 代替。将 x*(n) 用逆变换取共轭展开：

x*(n)=1N∑k=0N−1X*(k)WNkn.

于是

∑nx(n)x*(n)=1N∑kX*(k)∑nx(n)WNkn=1N∑kX*(k)X(k).

这里省写的每个求和范围都是0到 N−1。原P39的逐行证明就是“代入逆变换的共轭、交换两个有限求和、认出内层正变换”。有限和不需要另外引入无限级数收敛条件。

对上一复数例，时间能量为 1+1=2，频谱平方模之和为 2+4+2+0=8，除以4等于2。

这是同一段数组在两种坐标下的数值恒等式，不是说任意处理系统都保持能量。若把该数组解释为无限周期延拓，非零周期序列的全时间总能量通常无穷；这里算的是一个代表周期的平方和。若改用另一种DFT归一化，能量公式的系数也必须相应改变。

回读｜看到哪一种操作，就先问哪一个问题

原时间侧操作 频率侧结果 先检查
ax1+bx2 aX1+bX2 是否同一个 N
x((n+m))N WN−mkX(k) 加号表示左移
WNlnx(n) X((k+l))N l 是整数频点数
时间圆周卷积 X1X2 是否误要线性结果
时间逐点乘 频域圆周卷积再除以 N 不能漏 1/N
x*(n) X*((−k))N 共轭同时带频率反转
x*((−n))N X*(k) 反转是圆周反转

自测｜不重算大DFT，也能判断符号与归一化

  1. N=4，x=[1,2,3,4]。原形式 y(n)=x((n+1))4 是什么数组？频谱乘 W4k 还是 W4−k？
  2. N=4，y(n)=e+j2πn/4x(n)。频谱为 X((k+1))4 还是 X((k−1))4？
  3. 两个3点数组的DFT都为 [1,1,1]。它们时间逐点乘的DFT是多少？用频域圆周卷积检查 1/N。
  4. 若 N=4 且 X=[1+j,2,1−j,0]，只将时间序列取共轭，频谱是什么？
  5. x=[1,j,−1,−j] 的时间能量是多少？若DFT只有一个非零值4，Parseval是否吻合？
  6. 在移位证明 r=n+m 中，r 能否改名为 q？能否把自由的 k 一起不加解释地叫作“同一个时间索引”？
答案｜每次都说明变量角色
  1. [2,3,4,1]；这是左移1，频谱乘 W4−k。右移形式的移位量是 n0=−1，两种写法一致。
  2. 指数正号意味着 y=W4−nx，所以频谱为 X((k−1))4，即频率右移1点。
  3. 时间数组都是 [1,0,0]，乘后不变，DFT仍为 [1,1,1]。两个全1频谱的3点圆周卷积为 [3,3,3]，除以3得到结果。
  4. 先按 0,3,2,1 读取，再取共轭，得到 [1−j,0,1+j,2]。
  5. 时间能量为4；频谱平方模和为16，除以 N=4 得4。实际该例非零频点为 k=1，但能量检查本身不负责判定它在哪一格。
  6. 可以把整个求和作用域里的 r 无损改名为 q，并同步修改上下限与被加项。k 在此是固定输出频点，不能因为原资料有时用 k 作时间字母，就把此处的角色也改成时间。
