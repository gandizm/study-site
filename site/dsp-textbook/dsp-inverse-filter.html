原书例 2.6.3：逆滤波为什么会坏掉第一个点

先学：用DFT算线性卷积：为什么补零

学完能做什么

  • 从原系统函数推导逆差分
  • 解释循环首项污染与N−1点保证
  • 区别补零和真实边界信息

目标｜看懂原书只恢复 n=1 到 N−1 的原因

原 PPT 2.4 P11 还引用“例2.6.3（P95）”。实际第3版的题目与解答在印刷页102–103，对应PDF物理页119–120。PPT的95不是这份版本的实际页号。

原题给出一个稳定 LSI 系统的输出 y(n)，系统函数为

H(z)=β1−αz−1,

要求利用 DFT 从输出恢复未知输入 x(n)。这一节要解释原书结论的边界：从一段 N 点输出可以直接恢复哪些输入，为什么循环计算的第一点可能不对，以及补零能否补回缺失的边界信息。

记号｜从系统关系读出需要什么信息

LSI 表示线性移不变，系统关系是 Y(z)=H(z)X(z)。假设 β≠0，逆系统写成

G(z)=H−1(z)=1β(1−αz−1).

G 是逆滤波器，不能把 H−1(z) 读成 H(1/z)。上标 −1 在这里表示函数值的倒数。α,β 是给定系统参数，不是时间/频率下标。

对应的逆滤波器冲激响应为

g(n)=1β[δ(n)−αδ(n−1)].

δ(n) 是单位样本，只有 n=0 时为1。原书说 g 长度 L=2，这次的 L 表示逆滤波器数组长度，不是本次 DFT 点数 N。

若另外假设这是一个因果一阶系统，稳定性通常对应 |α|<1；仅看有理式而不说明收敛域，不能把因果性与稳定性混为一谈。本题下面的有限差分式来自给定输入输出关系，关键是 β≠0 及边界样本是否已知。

推导｜先在时域得到一个最简单的逆公式

将 G(z) 作用于 Y(z)，即 X(z)=G(z)Y(z)。因为乘 z−1 对应延迟一位，

x(n)=y(n)−αy(n−1)β.

也可把卷积写全验证：

x(n)=∑mg(m)y(n−m)=1βy(n)−αβy(n−1).

这里 n 是当前要恢复的输入位置，m 是卷积哑变量；g 只有 m=0,1 两项可能非零。

现在你只拿到 y(0),y(1),…,y(N−1)。对于 n=1,…,N−1，所需的 y(n) 与 y(n−1) 都在这段内；但求 x(0) 需要 y(−1)，它通常没有被给出。信息缺口在边界，不是 FFT 算力不够。

推导｜原书的频域乘法会把最后一点绕到开头

取 N≥2，以便长度2的逆滤波器能放入同一数组。先做 N 点 DFT，记作 Y(k)，此时 k 是频率格点编号。g 补零到 N 点后的 DFT 为

G(k)=1β[1−αWNk],WN=e−j2π/N.

为什么延迟项变成 WNk？因为 g(1) 在正变换中乘 WN1·k。这里仍是原书的负指数正变换约定。

原书构造

V(k)=1β[1−αWNk]Y(k),v(n)=IDFTN{V(k)}.

频域逐点相乘对应 N 点循环卷积，所以

v(n)=1β[y(n)−αy((n−1))N],0≤n<N.

若 n≥1，循环位置 n−1 本来就在记录内，于是 v(n)=x(n)。若 n=0，循环下标 −1 绕到 N−1，得到

v(0)=y(0)−αy(N−1)β,

而真正的首点是 (y(0)−αy(−1))/β。二者差值为

v(0)−x(0)=αβ[y(−1)−y(N−1)].

这就是原书最后保留“n=1,…,N−1 内 x(n)=v(n)”的理由。特殊情况下 α=0 或两个边界值恰好一样，首点也可能正确，但一般不能保证。

例题｜补一个四点数例，把坏点看出来

以下数字是新编教学核验，不是原书额外给定数据。 取 α=1/2、β=1，观测到

y(n)={1,2,3,4},N=4.

对于确定可恢复的三点：

x(1)=2−12×1=1.5,x(2)=3−12×2=2,x(3)=4−12×3=2.5.

四点循环计算在第一点却给 v(0)=1−12×4=−1。若另有题外信息 y(−1)=0，真正的 x(0)=1，因此循环首点错了2；若没有这个额外信息，就不能宣称已经知道真实 x(0) 是多少。

按频域也能核验：Y(k)={10,−2+2j,−2,−2−2j}，逆滤波器四点 DFT 为 {0.5,1+0.5j,1.5,1−0.5j}。相乘得

V(k)={5,−3+j,−3,−3−j},

其 IDFT 是 {−1,1.5,2,2.5}。算法准确地给出了循环卷积，但循环首项没有理由等于未知边界条件下的真实输入首项。

方法｜补零能修循环折叠，不能创造 y(−1)

把已观测的 N 点 y 与长度2的 g 补零到至少 N+1 点，可以无混叠地算出这段截断记录与 g 的线性卷积。但这等于把记录区间外的 y 暂时视为零。

因此补零后的首点是 y(0)/β。它仅在真实 y(−1)=0（或相关项为零）时等于真实 x(0)。最后额外的尾项也不能当成已经恢复真实 x(N)，因为后者需要尚未观测的 y(N)。

如果还能读取前一个真实样本 y(−1)，就可以用有限差分式恢复首点；或者在流式处理中保存上一块的最后一个真实输出样本。缺边界数据与循环卷积折叠是两件事，不能用一个“多补几个零”的口号一起消除。

回读｜原书三步法为什么少承诺一个点

  1. 从 y(n) 取 N 个样本做DFT，得到 Y(k)。
  2. 乘以已知 G(k)=β−1(1−αWNk)，得到 V(k)。
  3. IDFT得到 v(n)，只把 n=1,…,N−1 的值作为一般情况下保证恢复的 x(n)。

原书用 v 而没有一开始就把循环结果全叫 x，是在保留这个区别。看到结果换了函数名，应先问是不是有条件地相等，而不是马上把它当成“老师随便换符号”。

自测｜不要替题目补一个未知初始值

  1. 四点数例中，若 y(−1)=2，真实 x(0) 是多少？循环首点 v(0) 会跟着变吗？
  2. 如果不知 y(−1)，为什么仍能确定 x(2)？
  3. 原 L=2 与 N 各是什么长度？k 与 n 各在什么域？
  4. 补零到8点是否自动保证恢复未知 x(0)？
答案｜核对可恢复的边界
  1. x(0)=1−0.5×2=0；四点循环首值仍为−1，因为它只使用记录内的 y(3)=4。
  2. 只需 y(2) 和 y(1)，两者均已观测。
  3. L 是逆滤波器数组长2，N 是输出记录/DFT点数；k 是频率格点，n 是时间位置。
  4. 不能。补零可避免截断数组之间的循环混叠，但未知真实边界样本并不会因此变成已知零。
