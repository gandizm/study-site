模拟频率变换的书本定位与p/q角色

先读书：3.3.3 模拟滤波器的频率转换——模拟高通、带通及带阻滤波器的设计；书印 P149、P150、P151、P152、P153、P154；PDF P166、P167、P168、P169、P170、P171

依书原型变换组织高/带通/带阻，辨λ/η正频率幅度对应与p/q复变量代换，避免换字母与符号混同。。本页不是第二套必读教材，不新增完成进度。

本节目的：会把高通、带通、带阻的指标先换成低通原型能处理的指标，再把已经设计好的低通函数代换回来。不需要为三种滤波器分别重新发明一套极点设计。

一张角色对照，回到原式时还认得出来

  • G(p)：已经设计或正准备设计的归一化低通原型。p 是它的复变量；沿虚轴检查频响时写成 p=jλ。
  • H(q)：想得到的高通、带通或带阻的归一化形式。q 是这一侧的复变量；沿虚轴写成 q=jη。
  • H(s)：恢复实际频率尺度后的模拟滤波器。s 是实际拉普拉斯变量，沿虚轴 s=jΩ，Ω 的单位是rad/s。

所以 λ 与 η 是两侧不同的无量纲频率坐标，不是同一个时刻变量换字母。书中先用它们比较幅度曲线，再用 p,q,s 做函数代换；这两步不能混成一条“所有字母都相等”的式子。

高通的最小换元检查

书和课件先在正频率幅度图上用倒数对应低端与高端。进入复变量时，以书式3.3.19的代换为准：

p=1q,q=sΩc,H(s)=G(Ωcs).

这里 Ωc>0 是所用原型的频率尺度，要按前面指标和原型设计结果确定，不是只看到下标c就随便把通带边缘代进去。

有一个很容易卡住的符号：当 q=jη 时，1/q=−j/η。正频率幅度图里写倒数对应，并不是声称 jλ=1/(jη) 时还能无条件取 λ=+1/η。对于这里的实系数原型，正负频率幅度相同，画幅度对应图时可以只看绝对值；真正的系统函数仍按复变量代换，不能擅自补一个负号把稳定极点移到右半平面。

【补充检查，不是新增题】若原型 G(p)=1/(p+1)，代换得到 H(s)=s/(s+Ωc)。低频 s=jΩ、Ω→0 时幅度趋于0，高频时趋于1；极点在 −Ωc，仍稳定。这三个小检查就能发现把高通代成低通或多加负号的错误。

带通、带阻抓住书表中的对应关系

不要单背一长串边缘频率符号。先在图3.3.8或3.3.9标清哪两个是通带边缘、哪两个是阻带边缘，再按对应表把它们送回低通坐标。

带通会把中间的通过区域对应到低通的低频区域；带阻则把中间要抑制的区域送到低通的高频区域。中心频率、带宽与归一化参考量以该图和该式的定义为准，不能把前页高通的 Ωc 原样套成这里的带宽。

书要求在映回低通后比较两侧约束；若两边得到的阻带界限不一样，要按书的较严格一侧设计，而不是平均后把困难的一边丢掉。最后代回原目标频率检查通带和阻带，才算完成这一轮变换。
