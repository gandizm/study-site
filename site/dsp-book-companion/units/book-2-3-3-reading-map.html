有限主值与周期延拓

先读书：2.3.3 DFT的隐含周期性；书印 P64、P68、P69；PDF P81、P85、P86

有限主值与周期延拓；已有推导直接指书，只补角色、范围与课件对应。本页不是第二套必读教材，不新增完成进度。

读书哪段即可｜图与范围先于符号

读第3版书印 P68–P69 上部（PDF85–86）的隐含周期性、式(2.3.6)–(2.3.10)，并回看印 P64 的图2.3.1。它们对应课件 2.3 P11、P15；P14只是后续基本概念路线。书的 2.3.3 是“隐含周期性”，不是按课件后面的编号另造同名小节。

对象桥｜把一组值重复使用，不等于原信号本来周期

一个 N 点 DFT 输入数组只给出 0,…,N−1 的数值。把同一有限和公式算到其他整数频点时，结果每隔 N 重复；逆式的指数若延到其他整数时间，也会每隔 N 重复。这是公式带来的周期延拓，不是在断言真实世界的原信号一定每 N 点重复。

书用 x(n) 表示有限主值序列，用 x~(n) 表示延拓后的周期序列；频域也区分 X(k) 与 X~(k)。相同的一周期数值不意味着波浪号可以任意省掉。

记号桥｜双括号取余，与复制求和的条件

当主值只放在 0≤n<N、其他位置为零时，可以写

x~(n)=∑r=−∞∞x(n+rN)=x(((n))N).

书式(2.3.6)用 m 枚举副本，本卡临时换成 r，只为避免与上一卡证明中的输入时间 m 混淆。这里 n 是固定待求时间，r 才是求和变量；((n))N 指 0,…,N−1 中的余数，例如 ((−1))N=N−1。

课件 P15 的可读延拓式左侧写成 x~(k)、右侧却含 n；不要因此把左侧 k 认作频率。左右自由时间索引必须一致。回到书式(2.3.6)便可用同一个 n，再区分枚举副本的变量。

上式的“直接按余数访问主值”需要已明确那组 N 点主值。书例2.3.5还讨论了原序列长于延拓周期时的相加折叠，这不是简单丢掉后面的样值。课件 P18 使用五个样值分别作5点、6点延拓，没有落入这个长于周期的情形；不必把书额外情形当成本页新题，但也不要把条件忘掉。

回读下一步｜先延拓，再移位，最后取主值

从周期序列回到有限主值，书写 x(n)=x~(n)RN(n)；RN(n) 在此承担取窗口的工作。后面的圆周移位就是先在周期对象上移动，再取这一个窗口，因此越过右端的数据会从左端接回来，而不是像线性移位那样直接消失。

本卡只把两种对象接清。课件 P18、P19 的具体移位条件和结果，放在书 2.3.4 的循环移位处对照，避免同一道题重复挂在两节里。
